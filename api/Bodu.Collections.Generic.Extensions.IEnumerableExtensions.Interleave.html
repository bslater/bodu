    Method Interleave

    Interleave<TSource>(IEnumerable<TSource>, params IEnumerable<TSource>[])

    Interleaves the source sequence with one or more additional sequences, taking one element from each sequence in turn and skipping sequences as they are exhausted.

    Declaration
    public static IEnumerable<TSource> Interleave<TSource>(this IEnumerable<TSource> first, params IEnumerable<TSource>[] others)
    Parameters
    Type Name Description
    IEnumerable<TSource> first

    The first sequence, which contributes the first element of each round.
    IEnumerable<TSource>[] others

    The additional sequences to interleave after first. Must not contain null elements.
    Returns
    Type Description
    IEnumerable<TSource>

    A sequence containing every element of every input, ordered in rounds: each round takes one element from each not-yet-exhausted input, starting with first and continuing through others in order. The result length is the sum of the input lengths.
    Type Parameters
    Name Description
    TSource

    The type of elements in the sequences.
    Remarks

    This method uses deferred execution for the elements, but validates its arguments eagerly: a null entry in others throws at the call site, not during iteration. Each input is enumerated exactly once and its enumerator is disposed, including when the result is abandoned early.

    Inputs of unequal length do not truncate the result and do not throw: once an input is exhausted it is skipped and the remaining inputs continue round-robin until all are exhausted. This is the round-robin scheduling shape — fair rotation over the surviving inputs — so no separate RoundRobin operator is provided.

    Examples
    // Rounds continue with the surviving inputs once shorter ones are exhausted.
int[] result = new[] { 1, 2, 3 }.Interleave(new[] { 10, 20 }, new[] { 100 }).ToArray();
// => result == [ 1, 10, 100, 2, 20, 3 ]
    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when first or others is null.
    ArgumentException

    Thrown when others contains a null element.
