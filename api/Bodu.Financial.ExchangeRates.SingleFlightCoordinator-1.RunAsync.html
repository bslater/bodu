    RunAsync(TKey, Func<Task>)

    Runs operation for key, or joins the operation already in flight for that key, then awaits its completion.

    Declaration
    public Task RunAsync(TKey key, Func<Task> operation)
    Parameters
    Type Name Description
    TKey key

    The key that identifies the operation.
    Func<Task> operation

    The asynchronous operation to run when none is in flight for key.
    Returns
    Type Description
    Task

    A task that completes when the operation for key completes.

    Type Condition
    ArgumentNullException

    Thrown when operation is null.

    RunAsync(TKey, Func<CancellationToken, Task>, CancellationToken)

    Runs operation for key, or joins the operation already in flight for that key, then awaits its completion, abandoning this caller's wait when cancellationToken is signalled.

    Declaration
    public Task RunAsync(TKey key, Func<CancellationToken, Task> operation, CancellationToken cancellationToken)
    Parameters
    Type Name Description
    TKey key

    The key that identifies the operation.
    Func<CancellationToken, Task> operation

    The asynchronous operation to run when none is in flight for key, invoked with a token decoupled from any caller.
    CancellationToken cancellationToken

    A token that abandons this caller's wait on the shared result.
    Returns
    Type Description
    Task

    A task that completes when the operation for key completes.
    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when operation is null.
    OperationCanceledException

    Thrown when cancellationToken is signalled before the shared operation completes; the shared operation continues regardless.
