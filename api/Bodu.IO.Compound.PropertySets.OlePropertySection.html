    Class OlePropertySection

    Represents a single section of an OLE property set — a format-identified group of properties keyed by property identifier (PID).

    Remarks

    A property set contains one or two sections. The first carries the well-known properties (such as summary information); an optional second, user-defined section carries custom properties whose human-readable names are held in the section's PropertyNames dictionary.
