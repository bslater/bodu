    Method GetLastDateOfIsoWeek

    GetLastDateOfIsoWeek(int, int)

    Returns a new DateTime representing the last day (Sunday) of the specified ISO 8601 week and year.

    Declaration
    public static DateTime GetLastDateOfIsoWeek(int isoYear, int isoWeek)
    Parameters
    Type Name Description
    int isoYear

    The ISO 8601 year, defined as the year containing the Thursday of the first ISO week. Must be between the Year property values of MinValue and MaxValue, inclusive.
    int isoWeek

    The ISO 8601 week number to evaluate, ranging from 1 to the number of ISO weeks in the supplied year.
    Returns
    Type Description
    DateTime

    An object whose value is set to midnight (00:00:00) on the Sunday that ends the specified ISO 8601 week, using Unspecified.
    Remarks

    This method computes the last day of a given ISO 8601 week by anchoring on January 4 (which always falls in ISO week 1), backtracking to the preceding Monday, advancing by the supplied number of weeks, and adding six days to reach the Sunday of that week.

    The ISO 8601 calendar follows these rules:

    • weeks begin on Monday and end on Sunday;
    • week 1 is the first week containing at least four days of the new year;
    • years contain either 52 or 53 weeks.

    The returned value is normalized to midnight (00:00:00) and uses Unspecified. For the corresponding start of the week, use GetFirstDateOfIsoWeek(int, int).

    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown if isoYear is less than the Year of MinValue or greater than that of MaxValue, -or- isoWeek is less than 1 or greater than the number of ISO weeks in isoYear.
