    Method MapLeft

    MapLeft<TResult>(Func<TLeft, TResult>)

    Projects the left value using the specified selector, passing a right value through untouched.

    Declaration
    public Either<TResult, TRight> MapLeft<TResult>(Func<TLeft, TResult> selector)
    Parameters
    Type Name Description
    Func<TLeft, TResult> selector

    The projection applied to the left value when the left side is active.
    Returns
    Type Description
    Either<TResult, TRight>

    Left(selector(value)) when the left side is active; otherwise a right-carrying either with the original right value.
    Type Parameters
    Name Description
    TResult

    The left type produced by the selector.
    Remarks

    The selector is not invoked when the right side is active. The lift is strict: a null projection result is rejected by the Left(TLeft) factory with ArgumentNullException.

    Examples
    var doubled = Either<int, string>.Left(21).MapLeft(l => l * 2);   // Left(42)
var same = Either<int, string>.Right("text").MapLeft(l => l * 2); // Right(text) — selector not invoked
    Exceptions
    Type Condition
    ArgumentNullException

    selector is null.
    InvalidOperationException

    The either is default(Either<TLeft, TRight>) and carries neither side.
