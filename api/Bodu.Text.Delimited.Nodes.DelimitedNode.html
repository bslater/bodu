    Class DelimitedNode

    Represents a node in a mutable delimited (CSV/TSV) document tree. A delimited document is an array of records, so the tree has three concrete shapes: a DelimitedArray (the document, or a positional record), a DelimitedObject (a header-keyed record), and a DelimitedValue string field.
