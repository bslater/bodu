    Open(Stream, bool, bool)

    Opens an existing compound file over the supplied stream for read-only access, buffering its content into memory by default.

    Declaration
    public static CompoundFile Open(Stream stream, bool leaveOpen = false, bool buffered = true)
    Parameters
    Type Name Description
    Stream stream

    The stream containing the compound file; read from its current position to the end.
    bool leaveOpen

    true to leave stream open when the returned instance is disposed; otherwise false.
    bool buffered

    true (the default) to read the whole file into memory at open time; false to read sectors on demand from the seekable stream, bounding memory for large files. When false, the stream must remain open and unmodified for the lifetime of the returned instance.
    Returns
    Type Description
    CompoundFile

    An open, read-only CompoundFile.
    Examples
    using CompoundFile file = CompoundFile.Open(File.OpenRead("book.xls"));
using FileStream source = File.OpenRead("large.msg");
using CompoundFile streamed = CompoundFile.Open(source, buffered: false);
    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when stream is null.
    ArgumentException

    Thrown when buffered is false and stream is not seekable.
    CompoundFileFormatException

    Thrown when the stream content is not a well-formed compound file.

    Open(Stream, FileMode, FileAccess, bool, bool)

    Opens a compound file over the supplied stream with BCL-style FileMode and FileAccess semantics, mirroring System.IO.Packaging.Package.Open.

    Declaration
    public static CompoundFile Open(Stream stream, FileMode mode, FileAccess access, bool leaveOpen = false, bool buffered = true)
    Parameters
    Type Name Description
    Stream stream

    The stream containing the compound file, or the destination for a writable file.
    FileMode mode

    The file mode. Open with Read opens for reading; a creating mode (Create/CreateNew, or OpenOrCreate over empty content) with write access starts a new file; Open with ReadWrite loads an existing file for editing.
    FileAccess access

    The access level. Mutating an existing file requires ReadWrite; write-only access is supported only for creating modes.
    bool leaveOpen

    true to leave stream open when the returned instance is disposed; otherwise false.
    bool buffered

    true (the default) to read the whole file into memory at open time; false to read sectors on demand from the seekable stream. Ignored for writable files.
    Returns
    Type Description
    CompoundFile

    An open CompoundFile.
    Remarks

    Write access loads the existing content (for Open and a non-empty OpenOrCreate) or starts empty (for Create, CreateNew, and an empty OpenOrCreate) into a staging tree. Edits are written back to stream — which must be writable and seekable — only by Commit(), which rewrites the whole container.

    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when stream is null.
    NotSupportedException

    Thrown when the combination of mode and access is not supported.
    CompoundFileFormatException

    Thrown when the stream content is not a well-formed compound file.

    Open(string, FileMode, FileAccess, FileShare)

    Opens the compound file at the specified path with BCL-style FileMode, FileAccess, and FileShare semantics, mirroring System.IO.Packaging.Package.Open.

    Declaration
    public static CompoundFile Open(string path, FileMode mode, FileAccess access, FileShare share = FileShare.Read)
    Parameters
    Type Name Description
    string path

    The path of the compound file to open or create.
    FileMode mode

    The file mode. Open with Read opens for reading; a creating mode with write access starts a new file; Open with write access loads the existing file for update.
    FileAccess access

    The access level. Write access requires a creating or updating mode.
    FileShare share

    The sharing mode granted to other openers of the file.
    Returns
    Type Description
    CompoundFile

    An open CompoundFile that owns and closes the underlying file when disposed.
    Remarks

    For writable modes the staged edits are written back to the file only by Commit(); disposing without committing leaves the file unchanged.

    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when path is null.
    FileNotFoundException

    Thrown when mode requires an existing file but none exists at path.
    NotSupportedException

    Thrown when the combination of mode and access is not supported.
    CompoundFileFormatException

    Thrown when the existing file content is not a well-formed compound file.
