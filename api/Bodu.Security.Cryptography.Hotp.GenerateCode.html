    Method GenerateCode

    GenerateCode(ReadOnlySpan<byte>, long, int, OtpHashAlgorithm)

    Generates the RFC 4226 HOTP code for the specified secret and counter.

    Declaration
    public static string GenerateCode(ReadOnlySpan<byte> secret, long counter, int digits = 6, OtpHashAlgorithm algorithm = OtpHashAlgorithm.Sha1)
    Parameters
    Type Name Description
    ReadOnlySpan<byte> secret

    The shared secret key, as raw bytes.
    long counter

    The moving counter value, advanced by one on each successful authentication.
    int digits

    The number of decimal digits in the returned code.
    OtpHashAlgorithm algorithm

    The HMAC hash algorithm to use.
    Returns
    Type Description
    string

    The zero-padded decimal code, exactly digits characters long.
    Remarks

    The result is returned as a string rather than an integer because a code's leading zeros are significant — for example a computed value of 84204 is the six-digit code "084204".

    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    digits is less than 6 or greater than 8, or algorithm is not a defined OtpHashAlgorithm value.
