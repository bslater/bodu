    Class TextFilterBuilder

    Provides a fluent builder for assembling the patterns of a TextFilter, in the style of Microsoft.Extensions.FileSystemGlobbing's Matcher.

    Remarks

    Patterns accumulate in the order they are added — the order that becomes significant under LastMatchWins. The builder itself performs only per-pattern validation; grammar and regular-expression compilation errors surface from Build().

    Examples
    var filter = new TextFilterBuilder()
    .AddInclude("error*")
    .AddInclude("{warn,fatal}*")
    .AddExclude("*debug*")
    .Build();
