    WriteStartList()

    Writes the start of a list.

    Declaration
    public readonly void WriteStartList()
    Exceptions
    Type Condition
    InvalidOperationException

    Thrown when the list is opened directly inside a dictionary before a property name has been written, or when a complete root value has already been written and AllowMultipleRootValues is not set.
    BencodeSerializationException

    Thrown when opening the list would exceed the configured maximum nesting depth.
