    Method ThrowIfArrayLengthIsInsufficient

    ThrowIfArrayLengthIsInsufficient(Array?, int, string?)

    Throws an exception if the specified array has fewer than minimumLength elements.

    Declaration
    public static void ThrowIfArrayLengthIsInsufficient(Array? array, int minimumLength, string? paramName = null)
    Parameters
    Type Name Description
    Array array

    The array to validate. Must not be null.
    int minimumLength

    The minimum number of elements that array must contain.
    string paramName

    The name of the array parameter. Supplied automatically by the compiler via CallerArgumentExpressionAttribute.
    Remarks

    Use this overload when the caller may supply a larger array than required and the excess elements are simply ignored — for example, a buffer that must hold at least a full cipher block but may be larger. When the length must be exact, use ThrowIfArrayLengthIsNotEqualTo(Array?, int, string?) instead.

    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when array is null.
    ArgumentException

    Thrown when array.Length is less than minimumLength.

    ThrowIfArrayLengthIsInsufficient(Array?, int, int, string?, string?)

    Throws an ArgumentNullException if the array is null, an ArgumentOutOfRangeException if index is negative, or an ArgumentException if array does not have enough room from index to accommodate requiredLength elements.

    Declaration
    public static void ThrowIfArrayLengthIsInsufficient(Array? array, int index, int requiredLength, string? paramName = null, string? indexParamName = null)
    Parameters
    Type Name Description
    Array array

    The array to validate. Must not be null.
    int index

    The zero-based starting index within the array.
    int requiredLength

    The number of elements required starting from index.
    string paramName

    The name of the array parameter. Supplied automatically by the compiler via CallerArgumentExpressionAttribute.
    string indexParamName

    The name of the index parameter. Supplied automatically by the compiler via CallerArgumentExpressionAttribute.
    Remarks

    The available room is computed by subtraction (array.Length - index) rather than by adding index and requiredLength, so the check cannot be defeated by an integer overflow when either operand is large.

    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when array is null.
    ArgumentOutOfRangeException

    Thrown when index is negative.
    ArgumentException

    Thrown when array.Length - index is less than requiredLength.
