    Properties

    Name Description
    BlockCacheSize

    Gets the decoded page/block cache budget of the underlying container session, in entries.
    DecompressRtf

    Gets a value indicating whether the compressed RTF body (PidTagRtfCompressed) is decompressed when read through the body conveniences.
    MaxDecompressedRtfBytes

    Gets the largest decompressed RTF body, in bytes, the reader produces.
    MaxEmbeddedMessageDepth

    Gets the deepest embedded-message nesting the reader opens: a folder-level message is depth zero, a message opened from one of its attachments is depth one, and so on.
    MaxInlineAttachmentBytes

    Gets the largest by-value attachment payload, in bytes, that is decoded into the attachment's Properties; a larger PidTagAttachDataBinary is left in the store and served only through OpenContentStream().
    MaxNodeDataLength

    Gets the largest node payload, in bytes, the underlying container materializes in memory — the ceiling on any single property value, attachment payload, or table the store decodes at once.
    ValidationLevel

    Gets how strictly the container's structures and checksums are validated.
