    Enum DequeOverflowPolicy

    Specifies how a fixed-capacity Deque<T> responds when an add operation is attempted while the deque is already full.

    Namespace: Bodu.Collections.Generic
    Assembly: Bodu.Collections.dll
    Syntax
    public enum DequeOverflowPolicy
    Remarks

    The policy is consulted only when AllowGrow is false and Count equals Capacity. When AllowGrow is true the backing array grows instead, so the policy has no effect.

    EvictOpposite is the double-ended counterpart of the overwrite-on-full mode selected by AllowOverwrite, and matches the semantics of Python's collections.deque(maxlen=N).

    Fields

    Name Description
    Reject

    Adds to a full deque are rejected: AddFirst(T) and AddLast(T) throw InvalidOperationException, while TryAddFirst(T) and TryAddLast(T) return false without modifying state. This is the default and preserves the historical fixed-capacity behavior.
    EvictOpposite

    Adds to a full deque silently discard the element at the opposite end to make room — the tail element for AddFirst(T), the head element for AddLast(T) — so Count stays at Capacity and the Try* variants return true. This mirrors Python's collections.deque(maxlen=N) bounded-deque semantics.
