    Interface INotableDateService

    Resolves notable-date occurrences — public holidays, observances, and other named dates — for a requested territory and a single day or an inclusive date range.

    Namespace: Bodu.Globalization.Calendar
    Assembly: Bodu.Globalization.Calendar.dll
    Syntax
    public interface INotableDateService
    Remarks

    An implementation draws its occurrences from a loaded NotableDateResource and applies the resource's resolution policy: it calculates each rule's actual date, places any observed (substitute) date, resolves same-day collisions, and emits the surviving NotableDate occurrences. The canonical implementation is NotableDateService.

    Territory. The territory argument is a country code (US) or a subdivision ( CA-ON, AU-NSW). A subdivision sees both its own rules and the broader rules of its parent country, with the most specific rule winning for a shared concept.

    Inclusion by emitted date. An occurrence is included when its emitted (observed) date falls on the requested day or within the requested range, so a single-day query and a range query covering the same dates return consistent results.

    When to use. Resolve a service from a data pack (for example the AmericasCalendarData bundle) or from a document loaded with NotableDateResourceLoader, then query it directly; or call the working-day extension methods in Bodu.Extensions (such as IsWorkingDay / NextWorkingDay), which delegate to this surface.

    Examples
    // Resolve a service over a country's bundled rules.
INotableDateService service = AmericasCalendarData.CreateService("US");

// Every notable date emitted on a single day.
IReadOnlyList<NotableDate> newYear = service.Resolve(new DateOnly(2026, 1, 1), "US");

// Non-working public holidays across a whole year, restricted by a filter.
NotableDateFilter holidays = NotableDateFilter
    .ForCategory(NotableDateCategory.PublicHoliday)
    .And(NotableDateFilter.IsNonWorkingDay());

DateRange year = new(new DateOnly(2026, 1, 1), new DateOnly(2026, 12, 31));
IReadOnlyList<NotableDate> publicHolidays = service.Resolve(year, "US", holidays);
