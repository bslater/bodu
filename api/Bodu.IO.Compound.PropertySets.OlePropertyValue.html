    Remarks

    The decoded CLR value is exposed through Value and the strongly-typed accessor methods. Scalar values are boxed to their natural CLR type (for example int, string, or DateTimeOffset); vector values (IsVector) are exposed as an object array of element values. A Windows FILETIME is stored as its raw 100-nanosecond tick count, so it can be read either as a DateTimeOffset (a point in time) or a TimeSpan (an elapsed duration, as used by the total-edit-time property).
