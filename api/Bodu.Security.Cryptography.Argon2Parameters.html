    Class Argon2Parameters

    Specifies the cost and auxiliary inputs for an Argon2 key-derivation or password-hashing operation, as defined by RFC 9106.

    Remarks

    The three cost parameters — MemoryKiB, Iterations, and Parallelism — have no universally safe defaults and must be chosen for the deployment. RFC 9106, Section 4 gives recommended settings; a common starting point for interactive password hashing is 64 MiB of memory, three iterations, and a parallelism of four.

    The optional Secret (a server-side "pepper") and AssociatedData are folded into the pre-hashing digest. They are not stored in the PHC encoded string and must be supplied again at verification time.

    Properties

    Name Description
    AssociatedData

    Gets the optional associated data X, or null when none is used.
    Iterations

    Gets the number of passes over memory (the RFC 9106 parameter t).
    MemoryKiB

    Gets the amount of memory to fill, in kibibytes (the RFC 9106 parameter m).
    Parallelism

    Gets the degree of parallelism — the number of independent lanes (the RFC 9106 parameter p).
    Secret

    Gets the optional secret key K (a server-side pepper), or null when none is used.
    TagLength

    Gets the length of the derived tag, in bytes (the RFC 9106 parameter T).
    Version

    Gets the Argon2 version code folded into the pre-hashing digest.
