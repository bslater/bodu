    Method HashCore

    HashCore(ReadOnlySpan<byte>)

    Consumes the supplied input span using the deferred-final-block buffering rule. At the start of every iteration of the inner loop, if the residual buffer is already full and the caller has supplied at least one more byte, the held block is compressed with isFinal: false and the counter is advanced before the new byte is copied in. Compression of a block that fills the buffer exactly is otherwise deferred to HashFinal() so that isFinal: true may be raised on it.
