    Method WriteTo

    WriteTo(Utf8TomlWriter)

    Writes the normalized TOML encoding of this node to the supplied writer.

    Declaration
    public abstract void WriteTo(Utf8TomlWriter writer)
    Parameters
    Type Name Description
    Utf8TomlWriter writer

    The destination writer.
    Remarks

    Because a TOML document's root must be a table, the writer produces a document only when the outermost node is a TomlObject. Writing a node whose root is a scalar or array yields no document; use ToUtf8Bytes() to obtain the normalized bytes, which validates the table-root rule.

    Exceptions
    Type Condition
    TomlSerializationException

    Thrown when the subtree rooted at this node contains a null entry, which has no TOML representation.
