## Consolidation recommendations (ranked by value / effort)

**1. Extract `Bodu.Text.Serialization` core — highest value, medium-high effort.** The Bencode/Toml evidence shows the bulk of the serializer is format-agnostic. Concrete extraction boundary:

- **Move to the core (format-agnostic):** the metadata layer (`MetadataResolver`/`TypeMetadata`/`PropertyMetadata`), the whole attribute family (Converter/Ignore/Include/PropertyName/PropertyOrder/Required/ExtensionData/Constructor/NamingPolicy/ObjectCreationHandling/UnmappedMemberHandling/StringEnumMemberName), the naming policies (`CamelCase`/`Separator`/base `NamingPolicy` — already byte-identical), the `IgnoreCondition`/`ObjectCreationHandling`/`UnmappedMemberHandling` enums, the `On(De)Serializ*` callback interfaces, the converter-factory *pattern* (`Collection`/`Dictionary`/`Nullable`/`Enum`/`Integer`/`Object` factories — most already identical), `SerializerEngine`, and `WriteStack`. Parameterize the format seam via a generic writer/reader abstraction and an injected scalar-converter set.
- **Stays format-specific:** the `Utf8*Reader`/`Utf8*Writer` token layer, scalar/value converters (`StringConverter`, `ByteArrayConverter`, and the token-touching bodies of `Object`/`Dictionary`/`Collection` converters, Toml's date-time/decimal/float converters), `*Limits`/`*SpecVersion`, and the format exception types.
- Blast radius: 3 packages (Bencode, Toml, Yaml) + their test projects; net deletion of ~20 near-duplicate files per format. Do Bencode+Toml first (they already share the shape), then migrate Yaml (folds in #4).

**2. FX cache-scaffolding convergence — high value, low effort.** Add a generic `IByteCache<TKey>`/`NullByteCache<TKey>` to core; delete the three per-provider scaffolding trios; keep the thin `FileSystem<X>Cache` `GetFileName` overrides (or fold them into a keyed generic). Mechanical; blast radius = 3 provider packages + their DI registrations + tests.

**3. Yaml resx migration — medium value, very low effort.** Move the 5 string literals into `YamlResourceStrings`. Self-contained; ~1 hour.

**4. Shared serialization `ThrowHelper` — low-medium value.** Best folded into refactor #1.

**5. Docs + resx-placement housekeeping — low value, trivial.** Add Yaml and `Simd.Test` to the CLAUDE.md table; normalize the resx placement convention.

Highest value-to-effort: **#2 (FX caches)** and **#3 (Yaml resx)** are quick wins; **#1 (serializer core)** is the strategic refactor that eliminates the largest duplication surface in the solution.
