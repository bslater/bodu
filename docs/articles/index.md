# Contributing

These pages are for people who work on Bodu itself rather than with it. To use the packages, start with the [introduction](../docs/introduction.md) and the [package matrix](../docs/package-matrix.md).

- **[Code coverage strategy](code-coverage.md)** - how coverage is collected and merged across the test projects, the corrections the coverage matrix applies (shared source, hardware-gated SIMD paths, stale paths), and the per-package ratchet floors.
- **[Coverage baseline](coverage-baseline.md)** - the per-package line and branch coverage of the last full collection, generated by `tools/New-CoverageMatrix.ps1`.

How to build, test, and propose a change is in [CONTRIBUTING.md](https://github.com/bslater/bodu/blob/master/CONTRIBUTING.md) in the repository.
