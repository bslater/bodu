    Method Age

    Age(DateOnly)

    Returns the age in full calendar years between the specified date and today's date.

    Declaration
    public static int Age(this DateOnly date)
    Parameters
    Type Name Description
    DateOnly date

    The earlier date to calculate from, typically representing a birth date or other reference point.
    Returns
    Type Description
    int

    The number of full calendar years that have elapsed between date and today. Returns 0 if date occurs after today.
    Remarks

    This overload determines the number of full years that have passed by comparing the year, month, and day components. If the month and day of date have not yet occurred in the current year, the result is decremented by one.

    If date is February 29 in a leap year and today is not a leap year, the comparison is performed as if the date were February 28.

    The result is clamped to 0 to avoid returning negative values when date is in the future.

    Returns the age in full calendar years between the specified date and a supplied reference date.

    Declaration
    public static int Age(this DateOnly date, DateOnly asAtDate)
    Parameters
    Type Name Description
    DateOnly date

    The earlier date to calculate from, typically representing a birth date or other reference point.
    DateOnly asAtDate

    The later date to calculate to, representing the point in time at which the age is evaluated.
    Returns
    Type Description
    int

    The number of full calendar years that have elapsed between date and asAtDate. Returns 0 if asAtDate occurs before date.
    Remarks

    This overload determines the number of full years that have passed by comparing the year, month, and day components. If the month and day of date have not yet occurred in the year of asAtDate, the result is decremented by one.

    If date is February 29 in a leap year and asAtDate is in a non-leap year, the comparison is performed as if the date were February 28.

    The result is clamped to 0 to avoid returning negative values when date is after asAtDate.
