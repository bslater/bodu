    Enum CommonNotableDateCatalog

    Enumerates the shared, reusable notable-date catalogues bundled with the library, providing a strongly-typed name for each so callers can resolve a catalogue through Resolve(CommonNotableDateCatalog) without spelling its raw resource name.

    Namespace: Bodu.Globalization.Calendar
    Assembly: Bodu.Globalization.Calendar.dll
    Syntax
    public enum CommonNotableDateCatalog
    Remarks

    Each member maps one-to-one to an embedded catalogue whose bare resource name is its kebab-case equivalent (for example GlobalCore maps to global-core and ChristianWestern to christian-western). Use GetResourceName(CommonNotableDateCatalog) to obtain the raw name for an Import directive.
