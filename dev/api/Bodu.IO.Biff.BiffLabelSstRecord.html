    Remarks

    The record identifier is LabelSst. The payload is ten bytes: the cell prefix and the 32-bit index into the shared string table that BiffSstReader materializes. The record exists only in BIFF8; the writer rejects it under BIFF5, and the reader decodes it by layout in either version.
