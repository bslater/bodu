DelimitedDocument.cs

Provides a read-only, forward-parsed view over a delimited (CSV/TSV) document, shaped after System.Text.Json's JsonDocument. The document is an array of records.

Remarks

The document owns a flat store of decoded rows and must be disposed when no longer needed; every DelimitedElement obtained from it becomes invalid once the document is disposed.
