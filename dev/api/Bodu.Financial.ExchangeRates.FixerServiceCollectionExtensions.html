AddFixerExchangeRates(IServiceCollection, IConfiguration?, string, Action<FixerRateProviderOptions>?)

Registers the core Bodu.Financial services and the Fixer exchange-rate provider.

public static IFinancialServiceBuilder AddFixerExchangeRates(this IServiceCollection services, IConfiguration? configuration = null, string sectionName = "Financial:Fixer", Action<FixerRateProviderOptions>? configure = null)

Parameters

services IServiceCollection

The service collection to register into.

configuration IConfiguration

An optional configuration root. When supplied, FinancialOptions is bound from the Financial section and FixerRateProviderOptions from sectionName.

sectionName string

The Fixer configuration section name. Defaults to Financial:Fixer.

configure Action<FixerRateProviderOptions>

An optional callback applied after Fixer configuration binding.

Returns

IFinancialServiceBuilder

An IFinancialServiceBuilder for further composition.

Examples

IServiceCollection services = new ServiceCollection();

services.AddFixerExchangeRates(configuration, configure: options => options.ApiKey = "…");

ServiceProvider provider = services.BuildServiceProvider();
var rates = provider.GetRequiredService<IDatedRateProvider>();

Exceptions

ArgumentNullException

Thrown when services is null.

ArgumentException

Thrown when sectionName is empty or white space.
