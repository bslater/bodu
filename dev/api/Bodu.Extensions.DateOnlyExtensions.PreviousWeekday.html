    Method PreviousWeekday

    PreviousWeekday(DateOnly, WorkingDaysOfWeek)

    Returns a new DateOnly representing the previous calendar weekday before the specified date, based on the supplied workingWeek pattern.

    Declaration
    public static DateOnly PreviousWeekday(this DateOnly date, WorkingDaysOfWeek workingWeek)
    Parameters
    Type Name Description
    DateOnly date

    The starting date value from which to search backward.
    WorkingDaysOfWeek workingWeek

    The WorkingDaysOfWeek that determines which days are treated as working days.
    Returns
    Type Description
    DateOnly

    A DateOnly value set to the first calendar day before date that is a working day under the specified workingWeek rule.
    Remarks

    The method evaluates each preceding day until it finds one that is selected as a working day by the specified rule. The original date is never returned, even if it already falls on a working day.

    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown if workingWeek is not a defined value of the WorkingDaysOfWeek enumeration.

    PreviousWeekday(DateOnly, WorkingDaysOfWeek, IWeekendDefinitionProvider?)

    Returns a new DateOnly representing the previous calendar weekday before the specified date, using the supplied workingWeek pattern and an optional custom provider.

    Declaration
    public static DateOnly PreviousWeekday(this DateOnly date, WorkingDaysOfWeek workingWeek, IWeekendDefinitionProvider? provider)
    Parameters
    Type Name Description
    DateOnly date

    The starting date value from which to search backward.
    WorkingDaysOfWeek workingWeek

    The WorkingDaysOfWeek that determines which days are treated as working days.
    IWeekendDefinitionProvider provider

    An optional IWeekendDefinitionProvider that supplies custom weekend logic when workingWeek is Custom. If null, the default behavior for the supplied workingWeek applies.
    Returns
    Type Description
    DateOnly

    A DateOnly value set to the first calendar day before date that is a working day under the specified workingWeek rule and the logic of provider.
    Remarks

    The method evaluates each preceding day prior to date until it finds one that is a working day, either by the supplied workingWeek pattern or by the custom logic of provider.

    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown if workingWeek is not a defined value of the WorkingDaysOfWeek enumeration.
