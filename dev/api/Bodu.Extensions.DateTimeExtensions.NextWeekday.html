    Method NextWeekday

    NextWeekday(DateTime, WorkingDaysOfWeek)

    Returns a new DateTime representing the next calendar weekday after the specified dateTime, based on the supplied workingWeek pattern.

    Declaration
    public static DateTime NextWeekday(this DateTime dateTime, WorkingDaysOfWeek workingWeek)
    Parameters
    Type Name Description
    DateTime dateTime

    The starting date and time value from which to search forward.
    WorkingDaysOfWeek workingWeek

    The WorkingDaysOfWeek that determines which days are treated as working days.
    Returns
    Type Description
    DateTime

    An object whose value is set to the first calendar day after dateTime that is a working day under the specified workingWeek rule, with the original time-of-day and Kind preserved.
    Remarks

    The method evaluates each successive day until it finds one that is selected as a working day by the specified rule. The original dateTime is never returned, even if it already falls on a working day.

    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown if workingWeek is not a defined value of the WorkingDaysOfWeek enumeration.

    NextWeekday(DateTime, WorkingDaysOfWeek, IWeekendDefinitionProvider?)

    Returns a new DateTime representing the next calendar weekday after the specified dateTime, using the supplied workingWeek pattern and an optional custom provider.

    Declaration
    public static DateTime NextWeekday(this DateTime dateTime, WorkingDaysOfWeek workingWeek, IWeekendDefinitionProvider? provider)
    Parameters
    Type Name Description
    DateTime dateTime

    The starting date and time value from which to search forward.
    WorkingDaysOfWeek workingWeek

    The WorkingDaysOfWeek that determines which days are treated as working days.
    IWeekendDefinitionProvider provider

    An optional IWeekendDefinitionProvider that supplies custom weekend logic when workingWeek is Custom. If null, the default behavior for the supplied workingWeek applies.
    Returns
    Type Description
    DateTime

    An object whose value is set to the first calendar day after dateTime that is a working day under the specified workingWeek rule and the logic of provider, with the original time-of-day and Kind preserved.
    Remarks

    The method evaluates each successive day following dateTime until it finds one that is a working day, either by the supplied workingWeek pattern or by the custom logic of provider.

    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown if workingWeek is not a defined value of the WorkingDaysOfWeek enumeration.

    NextWeekday(DateTime, WeekPattern)

    Returns a new DateTime representing the next day after dateTime whose DayOfWeek is selected in the supplied workingWeek.

    Declaration
    public static DateTime NextWeekday(this DateTime dateTime, WeekPattern workingWeek)
    Parameters
    Type Name Description
    DateTime dateTime

    The starting date and time value from which to search forward.
    WeekPattern workingWeek

    The working-week pattern that determines which days are considered working days.
    Returns
    Type Description
    DateTime

    The first calendar day strictly after dateTime whose day-of-week is selected in workingWeek, with the original time-of-day and Kind preserved.
    Remarks

    The walk is bounded by the seven distinct DayOfWeek values; when workingWeek has no days selected (Empty) the method will overrun MaxValue rather than loop indefinitely. Callers must ensure the supplied pattern selects at least one day.

    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown when workingWeek is Empty.
