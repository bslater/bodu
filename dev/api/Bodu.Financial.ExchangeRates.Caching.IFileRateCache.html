    Interface IFileRateCache

    Specializes IRateCache for caches that persist rates as files, exposing the storage directory and the file or directory a pair resolves to under the configured layout.

    public interface IFileRateCache : IRateCache
    Remarks

    This is the file-storage seam of the caching design. Other storage kinds define their own specialization of IRateCache (for example a database cache exposing a table or connection name); consumers that only need the storage-agnostic contract continue to depend on IRateCache.
