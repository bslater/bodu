Fields

DecimalDigits = 0

ASCII decimal digits only ('0' to '9').

AlphanumericUppercase = 1

ASCII decimal digits ('0' to '9') and uppercase Latin letters ('A' to 'Z').

Code39 = 2

The Code 39 alphabet: ASCII decimal digits ('0' to '9'), uppercase Latin letters ('A' to 'Z'), and the seven symbols '-', '.', space, '$', '/', '+', and '%'.

CrockfordBase32 = 3

The Crockford Base32 alphabet: the thirty-two encoding symbols ('0'-'9' and 'A'-'Z' excluding 'I', 'L', 'O', and 'U'). Decoding is case-insensitive and accepts the aliases 'I'/'L' for 1 and 'O' for 0.

Remarks

Consumed by AlphanumericCheckDigitAlgorithm and MultiCharCheckDigitAlgorithm so that test harnesses and diagnostic surfaces can reason about the valid input set without inspecting the concrete algorithm.
