Provides a strategy with access to the surrounding resource so that referential strategies (such as OffsetFromRuleStrategy) can resolve the occurrence of another rule for the same year.

Remarks

The context maintains an in-progress set keyed by rule identity so that a circular reference between offset rules resolves to null rather than recursing without end.

Returns

Remarks

A non-Gregorian anchor's short lunar month and day can recur twice in one Gregorian year, so a referential strategy that projects each anchor occurrence must resolve through this member rather than ResolveReference(string, string?, int), which yields only the year's first occurrence.
