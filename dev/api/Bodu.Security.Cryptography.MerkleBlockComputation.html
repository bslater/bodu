Represents the result of one block-mode Merkle computation: the tree's root, the shape of the input it was taken over, and the ordered leaf hashes an authentication path is built from.

Remarks

This type exists so that a caller which has just streamed a large input past itself receives both the root and the leaf hashes from the same pass. Generating an authentication path needs the leaf hashes; without them the caller would have to stream the input a second time.

The leaf hashes cost leafCount × hashLength bytes to retain - for a 512 MiB input at one-mebibyte blocks that is 512 hashes, or 16 KiB. A caller that needs only the root and not a path should use ComputeRootOfBlocks(Stream, int, MerkleTreeDiagnostics?, CancellationToken), which folds the tree as it reads and never holds more than a logarithmic number of hashes.

The leaf hashes in block order, which is empty for a zero-length input because such an input has zero blocks rather than one empty block.

Remarks

Pass this list to AuthenticationPath(IReadOnlyList<byte[]>, long) to produce an authentication path without re-reading the input.

byte[]

The root, which is the hash of zero bytes when InputLength is zero, and the sole leaf's hash when the input produced exactly one block.

Remarks

To publish a commitment that also pins the input's length, pass this value and InputLength to BindRoot(ReadOnlySpan<byte>, long).
