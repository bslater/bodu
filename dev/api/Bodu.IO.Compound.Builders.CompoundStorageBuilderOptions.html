    Remarks

    The OLE2 / Compound File Binary format treats entry names case-insensitively, so by default the model keys names with the shared compound-file name relationship — the same comparison the reader and builder use, so an in-memory duplicate is detected exactly as the serialized container would collapse it. Set NameComparisonCaseSensitive to true only when a case-sensitive in-memory model is explicitly required.
