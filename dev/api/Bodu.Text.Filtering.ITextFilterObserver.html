Remarks

Attach an implementation via Observer to see exactly which values matched, which were rejected, and by which pattern - for diagnostics, sampling, or audit logging. When no observer is attached the filter's evaluation path pays only a single null check.

The callback runs synchronously on the evaluating thread, once per evaluated value; exceptions it throws propagate to the caller of the evaluating member. Implementations should be fast and must not re-enter the filter.
