    Enum Base85Variant

    Identifies the Base85 alphabet and framing rules used by Base85.

    Namespace: Bodu.Text.Encoding
    Assembly: Bodu.Text.Encoding.dll
    Syntax
    public enum Base85Variant : byte
    Remarks

    Base85 encodes four bytes as five characters using radix 85. Variants differ in alphabet, alphabet ordering, the availability of the all-zero shortcut z, and whether partial trailing groups are permitted.

    byte[] payload = "data"u8.ToArray();

var ascii85 = Base85.Encode(payload);                            // Adobe Ascii85
var z85 = Base85.Encode(payload, Base85Variant.Z85);             // ZeroMQ string-safe
var git = Base85.Encode(payload, Base85Variant.GitCompact);      // git binary patches

    Fields

    Name Description
    Ascii85

    The Adobe Ascii85 alphabet, used by PDF and PostScript. Uses ASCII characters ! (0x21) through u (0x75). The character z is recognised as a shortcut for four zero bytes. Partial trailing groups of one, two, or three bytes are permitted; output length grows by one character per byte plus one.
    Z85

    The Z85 alphabet defined by ZeroMQ (RFC 32 / "ZMTP/2.0"). Uses a shell-safe alphabet that avoids quote, slash, semicolon, and backslash. No z shortcut is recognised, and the input length must be a multiple of four bytes (output length is then a multiple of five characters).
    GitCompact

    The Git binary-patch Base85 alphabet with compact, self-delimiting partial-tail framing.
