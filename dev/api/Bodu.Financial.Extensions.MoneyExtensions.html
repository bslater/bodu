Remarks

Each member is a thin projection over Amount and the public arithmetic surface, carrying no state of its own. Splitting them into this extension surface keeps Money focused on construction, arithmetic, equality, and formatting.

When compiled with a tool-chain that supports C# 14 extension members the helpers are exposed as extension properties (for example money.IsZero); otherwise they compile as classic extension methods (for example money.IsZero()).
