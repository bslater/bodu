    Constructor RateLookupResult

    RateLookupResult(ExchangeRate, DateOnly, RateDateResolution, int, RateProvenance)

    Represents the outcome of a successful exchange-rate lookup, carrying both the resolved rate and the metadata that describes how it was selected.

    Declaration
    public RateLookupResult(ExchangeRate Rate, DateOnly RequestedDate, RateDateResolution Resolution, int OffsetDays, RateProvenance Provenance)
    Parameters
    Type Name Description
    ExchangeRate Rate

    The resolved exchange rate, including its source provider and inversion flag.
    DateOnly RequestedDate

    The calendar date the caller originally requested.
    RateDateResolution Resolution

    The fallback policy that was applied during the lookup.
    int OffsetDays

    The absolute distance, in days, between RequestedDate and the date carried by Rate.
    RateProvenance Provenance

    The lineage of the resolved rate: where it came from and, for a cache serve, how old it is.
    Remarks

    Returning this metadata alongside the rate gives the caller everything required to explain which observed value was selected (provider, date, inversion direction, distance from the requested date, and policy applied) without having to re-query the underlying table.

    Provenance is always populated. A rate resolved directly by a provider carries Live with a null Backend, CachedAtUtc, and Age. A rate served from a cache carries Cache with the serving backend, the instant the served data was cached, and the age it had at the lookup instant.
