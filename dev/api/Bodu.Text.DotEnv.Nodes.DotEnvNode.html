Class DotEnvNode

Namespace
Bodu.Text.DotEnv.Nodes
Assembly
Bodu.Text.DotEnv.dll

Represents a node in a mutable DotEnv document tree. A DotEnv document is a flat, ordered object of string-valued keys, so the tree has exactly two concrete shapes: a DotEnvObject root and the DotEnvValue string leaves it contains.
