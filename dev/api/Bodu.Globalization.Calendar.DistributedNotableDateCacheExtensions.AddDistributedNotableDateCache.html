    Method AddDistributedNotableDateCache

    AddDistributedNotableDateCache(IServiceCollection, IConfiguration?, string, Action<DistributedNotableDateCacheOptions>?)

    Registers a DistributedNotableDateCache over the IDistributedCache already registered in the container, as the INotableDateCache used by the caching notable-date service.

    Declaration
    public static IServiceCollection AddDistributedNotableDateCache(this IServiceCollection services, IConfiguration? configuration = null, string sectionName = "Calendar:NotableDateCache:Distributed", Action<DistributedNotableDateCacheOptions>? configure = null)
    Parameters
    Type Name Description
    IServiceCollection services

    The service collection to add the registration to.
    IConfiguration configuration

    An optional configuration root or section bound into DistributedNotableDateCacheOptions.
    string sectionName

    The configuration section name. Defaults to Calendar:NotableDateCache:Distributed.
    Action<DistributedNotableDateCacheOptions> configure

    An optional callback applied after configuration binding.
    Returns
    Type Description
    IServiceCollection

    The same service collection, to allow chaining.
    Remarks

    The caller is responsible for registering an IDistributedCache (for example via AddStackExchangeRedisCache or AddDistributedMemoryCache); use AddRedisNotableDateCache(IServiceCollection, Action<RedisCacheOptions>, IConfiguration?, string, Action<DistributedNotableDateCacheOptions>?) to register a Redis cache and the notable-date cache together. Compose it with the caching service by resolving the registered cache, for example AddCachedNotableDateService(cacheFactory: sp => sp.GetRequiredService<INotableDateCache>()).

    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when services is null.
    ArgumentException

    Thrown when sectionName is empty or white space.
