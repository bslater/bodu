    Class Cusip

    Computes the check digit of a 9-character Committee on Uniform Securities Identification Procedures (CUSIP) identifier using the Luhn-style weighted modulus-10 scheme specified by the American Bankers Association. This class cannot be inherited.

    Remarks

    CUSIP body characters are drawn from the decimal digits ('0'–'9'), uppercase Latin letters ('A' –'Z', with values 10–35), and the historical sentinels '*'=36, '@'=37 and '#'=38. The body is eight characters; the ninth character is the check digit.

    Each body character's numeric value is multiplied by a positional weight (1 at even left-to-right indices, 2 at odd indices). The resulting product is split into its tens and units digits, which are summed before being added to the running total. The check digit is chosen so that the total is a multiple of ten.

    Worked example. For the body "03783310" — Apple Inc. — the computed check digit is '0', and the resulting CUSIP "037833100" is therefore valid.

    important

    This algorithm is not cryptographically secure and should not be used for password hashing, digital signatures, or integrity validation in security-sensitive applications.

    Examples
    // Apple Inc. — CUSIP body "03783310".
char check = Cusip.Compute("03783310");   // '0'

// Full-sequence validation.
bool ok = Cusip.IsValid("037833100");     // true

// Streaming use when the body is built up incrementally.
var algo = new Cusip();
algo.Append("03783310");
char d = algo.GetCurrentCheckDigit();     // '0'
