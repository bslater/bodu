Provides a read-only, forward-parsed view over a DotEnv document, shaped after System.Text.Json's JsonDocument. The document is a flat object of string-valued keys; comment trivia is not retained.

Remarks

The document owns a flat store of decoded entries and must be disposed when no longer needed; every DotEnvElement obtained from it becomes invalid once the document is disposed.
