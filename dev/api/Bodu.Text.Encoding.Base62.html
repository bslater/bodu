    Class Base62

    Remarks

    Base62 is a non-power-of-two radix (radix 62) commonly used for compact, URL-safe identifiers and short links. Because the radix is not a power of two, encoding is performed with big-integer arithmetic rather than the bit-stream technique used by Base16, Base32, and Base64.

    The alphabet orders digits first, then upper-case letters, then lower-case letters — the convention used by the GNU Multiple Precision library and most base-x implementations. Leading zero bytes in the input are encoded as leading 0 characters so that the byte-level and character-level forms preserve a meaningful prefix.

    Base62 has no padding character and no standard decorations. Only IgnoreWhitespace affects decoding.

    Examples
    byte[] data = { 0x00, 0xDE, 0xAD, 0xBE, 0xEF };
string encoded = Base62.Encode(data);          // leading zero byte -> leading '0'
byte[] roundtrip = Base62.Decode(encoded);
