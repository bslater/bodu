    Enum HpkeMode

    Identifies the HPKE establishment mode, which controls whether a pre-shared key and/or sender authentication contribute to the key schedule, per RFC 9180 §5.1.

    Namespace: Bodu.Security.Cryptography
    Assembly: Bodu.Security.Cryptography.dll
    Syntax
    public enum HpkeMode : byte

    Fields

    Name Description
    Base

    Base mode (mode_base, 0x00) — encryption to a public key with no additional authentication.
    Psk

    PSK mode (mode_psk, 0x01) — augments base mode with a pre-shared key held by both parties.
    Auth

    Auth mode (mode_auth, 0x02) — authenticates the sender using its static private key.
    AuthPsk

    AuthPSK mode (mode_auth_psk, 0x03) — combines sender authentication with a pre-shared key.
