Properties

EntryExpirationMargin

Gets or sets the margin added to the time-to-live when deriving each written territory blob's server-side absolute expiration, or null to write entries without any server-side expiration.

public TimeSpan? EntryExpirationMargin { get; set; }

Property Value

TimeSpan?

The expiration margin; defaults to one hour.

Remarks

Every entry this cache serves must already be fresh under the per-call time-to-live, so a blob evicted server-side at ttl + margin would in any case have been filtered on read — served results are unchanged in any normal configuration, while a territory that stops being queried self-evicts from the backing store instead of lingering forever. A deployment that stores under one time-to-live and later reads under a longer one could observe a server-side eviction where it previously saw a hit; set the margin to null to opt out and restore unbounded server-side lifetime.
