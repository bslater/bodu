    Method HashCore

    HashCore(byte[], int, int)

    Processes a segment of the input byte array and feeds it into the CubeHash hashing algorithm. This method updates the internal state by processing cbSize bytes starting at the specified ibStart offset.

    Declaration
    protected override void HashCore(byte[] array, int ibStart, int cbSize)
    Parameters
    Type Name Description
    byte[] array

    The input byte array containing the data to hash.
    int ibStart

    The zero-based index in array at which to begin reading data.
    int cbSize

    The number of bytes to process from array.
    Overrides
    HashAlgorithm.HashCore(byte[], int, int)
    Exceptions
    Type Condition
    ArgumentNullException

    array is null.
    ArgumentOutOfRangeException

    ibStart is less than 0.

    -or-

    cbSize is less than 0.

    ArgumentException

    ibStart and cbSize specify a range that exceeds the length of array.
    CryptographicUnexpectedOperationException

    The hash algorithm has already been finalized and cannot accept more input data.

    HashCore(ReadOnlySpan<byte>)

    Processes the entirety of the input source and feeds it into the CubeHash hashing algorithm. This method updates the internal hash state accordingly by consuming the entire input span.
