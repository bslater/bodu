Remarks

The policy reads PublicKeyToken — the lowercase-hexadecimal token the loader extracts from the assembly manifest — and compares it case-insensitively against the allowlist. An assembly that is not strong-named (no token) is always rejected.

This verifies the token value declared in the manifest; it does not cryptographically verify the strong-name signature. For byte-level tamper resistance, compose it with a FileHashPluginTrustPolicy through a CompositePluginTrustPolicy.
