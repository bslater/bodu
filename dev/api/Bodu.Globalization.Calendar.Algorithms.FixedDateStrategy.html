Calculates a notable date that falls on a fixed month and day every year, optionally expressed in a non-Gregorian calendar system such as the Islamic, Hebrew, Persian, or Chinese lunisolar calendar.

Remarks

For the Gregorian calendar the month and day are used directly. For a non-Gregorian system the month and day are interpreted in that system and projected onto the requested Gregorian year by Bodu.Globalization.Calendar.CalendarSystems, using a calendar-year sweep (for lunar and lunisolar systems whose year does not align with the Gregorian year) or a leap-month skip (for the Chinese lunisolar calendar). 

// The rule shape this strategy realizes - a fixed civil date, authored via the builder
// (or <Fixed month="December" day="25" /> in the XML document form):
NotableDateResource resource = NotableDateDocumentBuilder.Create("demo")
    .AddNotableDate("christmas", "Christmas Day", NotableDateCategory.PublicHoliday, c => c
        .AddRule("default", r => r.Fixed(12, 25)))
    .Build();
