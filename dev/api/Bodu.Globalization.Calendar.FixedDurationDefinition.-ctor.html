    Constructor FixedDurationDefinition

    FixedDurationDefinition(int)

    Represents a fixed occurrence duration expressed as a number of calendar days, inclusive of the occurrence start date.

    Declaration
    public FixedDurationDefinition(int Days)
    Parameters
    Type Name Description
    int Days

    The number of calendar days the occurrence spans, inclusive of the first day.
    Remarks

    A fixed duration of one day is a single-day occurrence. The resolved end date is Date + Days - 1. Values below one are clamped to one at resolution time.
