    Method Min

    Min(DateOnly, DateOnly)

    Returns the earlier of two specified DateOnly values.

    Declaration
    public static DateOnly Min(DateOnly first, DateOnly second)
    Parameters
    Type Name Description
    DateOnly first

    The first DateOnly value to compare.
    DateOnly second

    The second DateOnly value to compare.
    Returns
    Type Description
    DateOnly

    The earlier of the two DateOnly values. If both values are equal, first is returned.
    Remarks

    This method compares the two values using the less-than-or-equal-to (<=) operator, which is equivalent to CompareTo(DateOnly).

    Min(DateOnly?, DateOnly?)

    Returns the earlier of two specified nullable DateOnly values.

    Declaration
    public static DateOnly? Min(DateOnly? first, DateOnly? second)
    Parameters
    Type Name Description
    DateOnly? first

    The first nullable DateOnly value to compare.
    DateOnly? second

    The second nullable DateOnly value to compare.
    Returns
    Type Description
    DateOnly?

    The earlier non-null DateOnly value, or null if both values are null.
    Remarks

    If both values are non-null, they are compared using the less-than-or-equal-to (<=) operator. If only one value is non-null, that value is returned. If both are null, the result is null.
