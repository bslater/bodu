    Convert(ExchangeRate, MonetaryContext?)

    Converts this amount using an auditable ExchangeRate quote, rounding to the target currency under context.

    Declaration
    public Money Convert(ExchangeRate rate, MonetaryContext? context = null)
    Parameters
    Type Name Description
    ExchangeRate rate

    The exchange-rate quote whose source currency must match this value's currency.
    MonetaryContext context

    The monetary context governing rounding; null selects Default.
    Returns
    Type Description
    Money

    The converted Money in the rate's target currency.
    Remarks

    Prefer this quote-first overload over the raw-decimal Convert(string, decimal, MidpointRounding) surface: it preserves the rate's direction, date, provider, and inversion metadata for downstream audit, and the companion ConvertWithResult(ExchangeRate, MonetaryContext?) returns that metadata alongside the rounding adjustment.

    Exceptions
    Type Condition
    InvalidOperationException

    The rate's source currency does not match this value's Code.
