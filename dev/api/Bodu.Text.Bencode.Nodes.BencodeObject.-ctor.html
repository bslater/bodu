    Parameters
    Type Name Description
    BencodeNodeOptions options

    The node options controlling property-name case sensitivity.
    Remarks

    When PropertyNameCaseInsensitive is true, in-memory property-name lookups use OrdinalIgnoreCase; otherwise they use Ordinal. The option does not affect serialization.
