    Remarks

    Each operation mirrors its synchronous counterpart — MapAsync pairs with Map<TResult>(Func<T, TResult>), BindAsync with Bind<TResult>(Func<T, Option<TResult>>), and MatchAsync with Match<TResult>(Func<T, TResult>, Func<TResult>) — so an asynchronous pipeline over Task<Option<T>> composes exactly like its synchronous equivalent.

    Argument validation runs synchronously, so a null source task or delegate faults at the call site rather than on the returned task.

    The combinators accept no CancellationToken: they perform no I/O of their own, so cancellation belongs to the caller's delegates, which can close over their own tokens.
