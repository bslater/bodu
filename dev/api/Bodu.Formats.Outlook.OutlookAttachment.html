Represents one attachment of an OutlookMessage: a typed view over the attachment storage's decoded properties, with access to the by-value payload or the nested attached message.

Remarks

The conveniences return null when the underlying property is absent; every attachment property remains reachable through Properties. Content access is method-specific: OpenContentStream() serves a by-value payload and OpenMessage() serves an embedded message - each throws NotSupportedException for every other method kind.

Remarks

A by-value payload (PidTagAttachDataBinary) larger than MaxInlineAttachmentBytes is not decoded: the property is present with a null value and the content is served by OpenContentStream() directly from the container.

Property Value

long?

The PidTagAttachSize value the writer recorded; when absent, the length of the by-value content stream; null when neither is available.

Remarks

The stream length comes from the container directory, so a deferred payload is never read to measure it.

Methods

OpenContentStream()

Opens the by-value content payload as a read-only stream.

public Stream OpenContentStream()

Returns

Stream

The content stream; dispose it when reading is complete.

Remarks

A payload decoded inline (at or below MaxInlineAttachmentBytes) is served from the decoded bytes without copying. A larger payload is opened from the container: under Streaming it is read sector by sector on demand, and a container fault during a read surfaces as OutlookMsgFormatException.

Exceptions

ObjectDisposedException

The owning session has been disposed.

NotSupportedException

The attachment's Method is not ByValue - a referenced, embedded, or OLE attachment carries no byte payload in the message.

OutlookMsgFormatException

The by-value content stream is missing, or the container is malformed.
