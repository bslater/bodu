Remarks

A DiscreteInterval<T> is canonically a closed integer interval, so it serializes through the continuous Interval<T> converter over its ToInterval() projection and is read back with FromInterval(Interval<T>), which snaps any open bounds inward to the contained integers. The wire shape therefore matches IntervalJsonConverter<T> under the same NumericsJsonPolicy - the Compact form of [1, 5], the object form for Strict / Lenient, the unbounded markers, and the empty-set representation.
