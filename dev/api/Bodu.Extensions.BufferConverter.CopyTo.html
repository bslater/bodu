    Method CopyTo

    CopyTo<T>(byte[], int, T[], int, int)

    Copies a specified number of elements of type T from a byte array into a target array.

    Declaration
    public static void CopyTo<T>(this byte[] sourceArray, int sourceIndex, T[] targetArray, int targetIndex, int count) where T : unmanaged
    Parameters
    Type Name Description
    byte[] sourceArray

    The source byte array.
    int sourceIndex

    The starting index in the sourceArray.
    T[] targetArray

    The target array to receive the elements.
    int targetIndex

    The starting index in the targetArray.
    int count

    The number of elements of type T to copy.
    Type Parameters
    Name Description
    T

    The unmanaged type to copy to.
    Remarks

    The method assumes that the byte array represents elements of type T using platform-native endianness.

    Exceptions
    Type Condition
    ArgumentNullException

    sourceArray or targetArray is null.
    ArgumentOutOfRangeException

    sourceIndex, targetIndex, or count is out of range.
    ArgumentException

    The specified range exceeds the bounds of the source or target arrays.
