Describes the used range of a worksheet as declared by its DIMENSIONS record: the half-open span of rows and columns that bounds the sheet's populated cells.

Remarks

The used range covers rows [FirstRowIndex, FirstRowIndex + RowCount) and columns [FirstColumnIndex, FirstColumnIndex + ColumnCount). Excel records the extent it has allocated, which may be larger than the region that actually holds values, so this range is an upper bound rather than a tight fit.

A worksheet with no DIMENSIONS record yields the default value, whose counts are zero.
