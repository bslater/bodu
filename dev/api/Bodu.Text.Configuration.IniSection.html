    Class IniSection

    Represents a single [section] block in an INI-style configuration document, exposing its ordered entries and providing O(1) key lookup with optional typed value conversion.

    Remarks

    The global section (keys that appear before any named section header) is also represented as an IniSection whose Name is the empty string.

    Key lookup uses the comparer implied by CaseSensitive at parse time.

    Examples
    IniSection db = doc.GetSection("database")!;

// TryGetValue + typed accessors for optional keys.
int port = db.TryGetValue("port", out int parsed) ? parsed : 5432;
if (db.TryGetValue("password", out string? password))
    Console.WriteLine($"Password length: {password.Length}");

// Walk the entries in source order.
foreach (IniEntry entry in db.Entries)
    Console.WriteLine($"{entry.Key} = {entry.Value}");
