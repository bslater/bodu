Remarks

The core Interval<T> type carries no JsonConverterAttribute so that Bodu.Numerics stays serialization-agnostic; register this factory through AddNumericsJsonConverters(JsonSerializerOptions, NumericsJsonPolicy) (which registers a coherent set for every numeric type) or add it directly to Converters.
