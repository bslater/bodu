Provides bit-level and byte-level transformations over the integral primitive types - endian conversion, byte and word swaps, bit reversal and rotation, and unchecked arithmetic helpers - for hashing, serialization, and protocol code.

Remarks

Hash algorithms, network protocols, and binary file formats routinely require operations that the BCL either does not expose (bit reversal, word swap), exposes only on a single type ( BinaryPrimitives covers endianness but not rotation), or hides behind generic-math abstractions. This class collects those operations as a single, type-overloaded surface so the same call site can target byte, ushort, uint, or ulong without wrapping the value in a generic helper.

The API surface is grouped into: byte-order conversion (GetBytes, ReverseBytes), within-value rearrangement (ReverseWords, ReverseBits), bit rotation (RotateBitsLeft, RotateBitsRight ), and unchecked arithmetic helpers under Unchecked. ReverseBits additionally accepts a bitLength overload for callers reversing only the low-order portion of a value, and GetBytes accepts a flag to control endianness explicitly rather than depending on host order.

All operations are pure, branch-light, allocation-free for the value-typed overloads, and deterministic. Where a byte[] is returned (for example, GetBytes or ReverseBits(byte[])) a fresh array is allocated each call - callers wanting buffer reuse should slice into a pre-allocated Span<T> via the BCL primitives instead. 

// Swap byte order for big-endian wire encoding.
uint host = 0x11_22_33_44u;
uint network = host.ReverseBytes(); // => 0x44_33_22_11

// Bit reversal - useful in CRC and DSP code.
byte mask = 0b1011_0001;
byte mirrored = mask.ReverseBits(); // => 0b1000_1101

// Cyclic bit rotation - common in hashing primitives.
uint rotated = 0x0000_00FFu.RotateBitsLeft(8); // => 0x0000_FF00

GetBytes<T>(T, bool)

Returns a byte array representing the binary encoding of the specified numeric value, in the requested byte order.

public static byte[] GetBytes<T>(this T value, bool asBigEndian = false) where T : INumberBase<T>

Parameters

value T

The numeric value to convert.

asBigEndian bool

true to return bytes in big-endian order (most significant byte first); false to return bytes in little-endian order (least significant byte first). Defaults to false.

Returns

byte[]

A byte array containing the binary representation of value in the specified byte order.

Type Parameters

T

The numeric type to convert.

Remarks

BitConverter is used to obtain the binary representation of each value in the system's native byte order. The resulting array is reversed when the requested byte order differs from the platform's native endianness.

Supported types are byte, sbyte, short , ushort, int, uint, long, ulong, float, and double.

For float and double, the encoding follows the IEEE 754 standard.

The INumberBase<TSelf> constraint rejects non-numeric types (such as reference types) at compile time. Numeric types that BitConverter does not support - for example decimal, Int128, or BigInteger - still satisfy the constraint and fail at run time with InvalidOperationException.

Exceptions

InvalidOperationException

T is a numeric type outside the fixed set supported by BitConverter.

The number of positions to rotate. Must be in the range [0, 64]. A count of 0 or 64 is a no-op.

Returns

ulong

A ulong with the bits of value rotated right by count positions.

Remarks

Delegates to RotateRight(ulong, int) after validation, allowing the JIT to lower the rotation to a single CPU instruction on supported platforms.

Exceptions

ArgumentOutOfRangeException

count is less than 0 or greater than 64.

RoundToSignificantDigits(decimal, int)

Rounds a decimal to the specified number of significant decimal digits.

public static decimal RoundToSignificantDigits(this decimal value, int digits)

Parameters

value decimal

The value to round.

digits int

The number of significant digits to retain. Must be between 1 and 28, inclusive (the precision limit of decimal).

Returns

decimal

value rounded to digits significant digits. Returns value unchanged when it is zero.

Remarks

The computation is performed entirely in decimal arithmetic so the full 28-digit precision is preserved; no intermediate double conversion occurs.

Exceptions

ArgumentOutOfRangeException

digits is less than 1 or greater than 28.

OverflowException

Rounding away from zero pushes the result beyond MaxValue or MinValue (possible only for values within one rounding step of the range limit).

RoundToSignificantDigits(double, int)

Rounds a double to the specified number of significant decimal digits.

public static double RoundToSignificantDigits(this double value, int digits)

Parameters

value double

The value to round.

digits int

The number of significant digits to retain. Must be between 1 and 15, inclusive (the practical precision limit of double).

Returns

double

value rounded to digits significant digits. Returns value unchanged when it is zero, NaN, or infinite.

Examples

12345.6789.RoundToSignificantDigits(3); // => 12300
0.0012345.RoundToSignificantDigits(2); // => 0.0012

Remarks

Unlike Round(double, int), which rounds to a fixed number of fractional digits, this method scales the rounding magnitude to the order of magnitude of value. Negative values are handled symmetrically.

Exceptions

ArgumentOutOfRangeException

digits is less than 1 or greater than 15.
