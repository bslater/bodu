    Enum CrcStandards

    Identifies a CRC parameter set defined in the CRC RevEng catalogue. Pass to Get(CrcStandards) to materialise the corresponding CrcStandard on demand.

    Namespace: Bodu.IO.Hashing.Checksums
    Assembly: Bodu.IO.Hashing.dll
    Syntax
    public enum CrcStandards
    Remarks

    The enum covers only canonical names. Published aliases (for example CRC-32 or PKZIP) are not separate values — they resolve to their canonical instance through FromName(string). Standards whose width exceeds 64 bits (currently only CRC-82/DARC) are omitted because they cannot be represented in a ulong.
