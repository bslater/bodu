    Deserialize<T>(Stream, YamlSerializerOptions?)

    Deserializes a value of type T by reading a stream of UTF-8 YAML bytes to its end.

    Declaration
    [RequiresUnreferencedCode("Reflection-based YAML deserialization may require types that trimming cannot statically determine.")]
public static T? Deserialize<T>(Stream source, YamlSerializerOptions? options = null)
    Parameters
    Type Name Description
    Stream source

    The readable stream containing the UTF-8 YAML bytes.
    YamlSerializerOptions options

    The serializer options, or null for the defaults.
    Returns
    Type Description
    T

    The deserialized value.
    Type Parameters
    Name Description
    T

    The target type.
    Remarks

    The stream is read to its end into an in-memory buffer before parsing begins: the method buffers the complete input rather than parsing incrementally, so peak memory includes the entire document.

    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when source is null.
    ArgumentException

    Thrown when source does not support reading.
    YamlFormatException

    The stream contents are not valid YAML.
