Remarks

The writer aims to be round-trip preserving by default: PreserveComments and WriteInlineComments retain commentary from the original document, and InsertBlankLineBetweenSections keeps section blocks visually separated. Override these when emitting a freshly built document, or when generating a minimized variant for transport.

Profile selects the default formatting envelope (Bodu, EditorConfig-compatible, or strict). The remaining properties override individual aspects of that envelope without abandoning the rest of its defaults.

Encoding defaults to UTF-8 without a byte-order mark to match the EditorConfig file convention; supply an alternative explicitly when interoperating with a host that expects a BOM or a different code page. NewLine defaults to a single LF — switch to "\r\n" for hosts that require CRLF on output. Every property is init-only, so instances are safe to cache and share across threads. 

ConfigurationDocument.Save(document, "team.boduconfig", new ConfigurationWriteOptions
{
    KeyValueSeparator = " = ",
    PreserveComments = true,
    InsertBlankLineBetweenSections = true,
});
