Remarks

The Bank of England publishes each currency's daily spot rate as a separate IADB series — for example, XUDLUSS is the US dollar into Sterling rate. Each series value is the number of units of the quote currency per one pound, so the provider treats it as a GBP-based rate. The default catalogue is exposed through Default and can be overridden or extended through the provider options.
