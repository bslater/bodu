Remarks

This object isolates the network-facing settings from the behavioural options on BoeRateProviderOptions, so the host, query path, transport timeout, and request identity can be pointed at a mirror or proxy of the IADB — or simply tuned — without touching caching or series configuration. A range request is composed from BaseUrl, QueryPath, the requested series codes, and the inclusive date range through BuildRequestUrl(IReadOnlyList<string>, DateOnly, DateOnly).

Every member carries a working default, so the object binds cleanly through Microsoft.Extensions.Options and requires no configuration for the common case.
