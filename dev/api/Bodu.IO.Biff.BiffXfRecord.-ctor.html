    Constructor BiffXfRecord

    BiffXfRecord(ushort, ushort, ushort)

    Represents the leading fields of a decoded XF (extended format) record: the font and number-format indices and the protection and style flags. Alignment, border, and fill fields that follow are not interpreted.

    Declaration
    public BiffXfRecord(ushort FontIndex, ushort FormatIndex, ushort TypeField)
    Parameters
    Type Name Description
    ushort FontIndex

    The index of the cell's font in the FONT record sequence.
    ushort FormatIndex

    The index of the cell's number format.
    ushort TypeField

    The raw type-and-protection word: locked (bit 0), hidden (bit 1), style (bit 2), parent style index (bits 4–15).
    Remarks

    The first six bytes are laid out identically in BIFF5 (16-byte record) and BIFF8 (20-byte record).
