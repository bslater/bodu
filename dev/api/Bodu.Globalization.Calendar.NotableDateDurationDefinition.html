Represents how long a resolved notable-date occurrence lasts: either a fixed number of calendar days or a span whose end date is independently calculated.

Remarks

A rule declares at most one duration definition. A null duration means the rule inherits the parent concept's DefaultDurationDays. The two concrete kinds - FixedDurationDefinition and CalculatedEndDateDurationDefinition - are mutually exclusive by construction, so a rule can never declare both a fixed day count and a calculated end date.
