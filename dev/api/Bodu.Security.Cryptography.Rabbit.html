Examples

using Bodu.Security.Cryptography;
using Bodu.Security.Cryptography.Extensions;

using var rabbit = new Rabbit();
rabbit.GenerateKey(); // 128-bit
rabbit.GenerateNonce(); // 64-bit IV
byte[] ciphertext = rabbit.Encrypt(plaintext);
byte[] roundTrip  = rabbit.Decrypt(ciphertext);

Remarks

Rabbit is a high-speed additive stream cipher and an eSTREAM software-portfolio finalist. It uses a 128-bit key and a 64-bit IV to drive an evolving internal state that emits a keystream XORed with the plaintext. This class exposes the raw, confidentiality-only cipher with no authentication; for new designs prefer an AEAD construction.

Like the other stream ciphers in this library it is self-inverse: CreateEncryptor() and CreateDecryptor() are interchangeable. The IV is supplied through the Nonce property.

Parameters at a glance.

  • Key size: 128 bits (16 bytes).
  • Nonce (IV) size: 64 bits (8 bytes).

Nonce reuse is catastrophic. A given (key, IV) pair must encrypt at most one message; reusing it reveals the XOR of the plaintexts. Rabbit has no seekable counter, so a message is encrypted as one forward keystream sequence.
