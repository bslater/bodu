    Remarks

    The converter shape is selected by NumericsJsonPolicy:

    • Strict — canonical object form { "numerator": 3, "denominator": 4 }; rejects duplicate properties and non-object tokens. Property values may be either JSON numbers or numeric strings, so BigInteger-backed values survive without precision loss.
    • Lenient — same object shape as Strict, but a top-level JSON string token is accepted and routed through Parse(ReadOnlySpan<char>, IFormatProvider?) as a tolerant fallback.
    • Compact — string form "3/4"; reads delegate to TryParse(ReadOnlySpan<char>, IFormatProvider?, out Fraction<T>) and writes call ToString(string?, IFormatProvider?) with the invariant culture.
