Fields

None = 0

No token has been read, or the reader has reached the end of the document.

StartArray = 1

The start of the document array, emitted before the first record.

EndArray = 2

The end of the document array, emitted after the last record.

StartObject = 3

The start of a record object (header mode).

EndObject = 4

The end of a record object (header mode).

PropertyName = 5

A field name, emitted before its value (header mode).

String = 6

A field value.

Remarks

A delimited document is an array of homogeneous records. With a header row each record is surfaced as an object keyed by header name (StartObject … EndObject); without a header each record is a positional array of string fields (StartArray … EndArray). Field values are always String.
