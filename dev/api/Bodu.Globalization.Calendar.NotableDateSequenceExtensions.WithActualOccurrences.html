    Method WithActualOccurrences

    WithActualOccurrences(IReadOnlyList<NotableDate>)

    Returns the occurrences together with a synthesized actual occurrence for every observed occurrence whose originally calculated date is absent from the sequence.

    Declaration
    public static IReadOnlyList<NotableDate> WithActualOccurrences(this IReadOnlyList<NotableDate> occurrences)
    Parameters
    Type Name Description
    IReadOnlyList<NotableDate> occurrences

    The resolved occurrences to expand.
    Returns
    Type Description
    IReadOnlyList<NotableDate>

    The occurrences plus the synthesized actual occurrences, ordered by date, then notable-date id, then rule id (ordinal) — the same ordering contract as Resolve(DateRange, string). When no occurrence requires expansion, the input instance is returned unchanged.
    Remarks

    An occurrence is expanded when IsObserved is true and ActualDate is non-null and differs from Date. The synthesized occurrence matches the shape the resolution engine emits for the actual half of ActualAndObserved: it is dated on the calculated date with ActualDate equal to that date, IsObserved is false, and AdjustmentPolicyId and AdjustmentReason are cleared; all other fields, including DisplayName, carry over unchanged.

    Synthesis is skipped when the sequence already contains an occurrence with the same Identity on the calculated date, so the method is idempotent and is a no-op for results produced under ActualAndObserved.

    A synthesized date can precede the range the sequence was resolved for (an observed occurrence inside the range may have been calculated before it). Apply InDateRange(DateOnly, DateOnly) to the result when strict range containment is required. The expansion is a pure sequence transform: the source resource's same-day collision policy is not re-applied to the synthesized occurrences.
