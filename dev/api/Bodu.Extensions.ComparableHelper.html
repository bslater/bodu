ComparableHelper.Coalesce.cs

Provides null-tolerant ordering helpers - Min, Max, and Coalesce - for pairs of operands. Min and Max require IComparable<T> operands (reference types may be null); Coalesce is unconstrained and additionally accepts Nullable<T> value types.

Examples

string? a = "alpha";
string? b = null;

string? larger  = ComparableHelper.Max(a, b);       // "alpha"
string? smaller = ComparableHelper.Min(a, b);       // "alpha" (null is skipped)
string? either  = ComparableHelper.Coalesce(b, a);  // "alpha"

// Coalesce alone is unconstrained, so it also accepts nullable value types.
int? first = ComparableHelper.Coalesce((int?)null, 5); // 5

// Custom comparer for case-insensitive string ordering.
string? winner = ComparableHelper.Max("alpha", "Beta", StringComparer.OrdinalIgnoreCase); // "Beta"

Remarks

The helpers are designed for the common case in which one or both operands may be null and the caller wants the non-null value to win rather than to throw. Coalesce returns the first non-null operand and is equivalent to the null-coalescing operator over reference and nullable value types. Min and Max return the smaller or larger operand respectively; when one operand is null the other is returned unchanged, and when both are null the result is null.

Each method accepts an optional IComparer<T> override; when omitted, Default is used. Because the ordering call only occurs when both operands are non-null, callers can supply comparers that throw on null input without guarding separately.

These helpers complement ComparableExtensions, which provides instance-style comparison predicates ( IsBetween, IsGreaterThan, and so on). ComparableHelper is the static surface for combining two operands; ComparableExtensions is the surface for testing a single operand against bounds.
