    Method AppendRange

    AppendRange(IEnumerable<T>)

    Appends a sequence of elements from the specified IEnumerable<T> source, growing the buffer as needed.

    Declaration
    public void AppendRange(IEnumerable<T> source)
    Parameters
    Type Name Description
    IEnumerable<T> source

    The sequence of elements to append. Must not be null.
    Remarks

    When source implements ICollection<T>, a single bulk copy is performed instead of element-by-element iteration.

    Exceptions
    Type Condition
    ArgumentNullException

    Thrown if source is null.
    ObjectDisposedException

    Thrown if the instance has been disposed.

    AppendRange(ReadOnlySpan<T>)

    Appends all elements from the specified ReadOnlySpan<T> to the buffer, growing the internal array if necessary.

    Declaration
    public void AppendRange(ReadOnlySpan<T> source)
    Parameters
    Type Name Description
    ReadOnlySpan<T> source

    The span of elements to append.
    Remarks

    source may alias the builder's own storage (for example a span obtained from WrittenSpan or DangerousGetArray()): when a growth is required, the previous rented array is returned to the pool only after the source elements have been copied, so a self-aliasing source remains valid throughout the append.

    Exceptions
    Type Condition
    ObjectDisposedException

    Thrown if the instance has been disposed.
