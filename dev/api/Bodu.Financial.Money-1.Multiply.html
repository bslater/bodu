    Multiply(decimal, MidpointRounding)

    Multiplies this amount by multiplier and rounds the result to the currency's minor-unit precision using the supplied rule.

    Declaration
    public Money<TCurrency> Multiply(decimal multiplier, MidpointRounding rounding)
    Parameters
    Type Name Description
    decimal multiplier

    The scalar multiplier.
    MidpointRounding rounding

    The midpoint-rounding rule applied to the product.
    Returns
    Type Description
    Money<TCurrency>

    The product, rounded to TCurrency.MinorUnits using rounding.
    Remarks

    Use this overload when a non-default rounding rule (for example, AwayFromZero for retail-tax workflows) must be applied. The * operator forces banker's rounding because operator signatures cannot accept a rounding-mode parameter.

    Examples
    using Bodu.Financial;
using Bodu.Financial.Currencies;

var price = new Money<USD>(2.125m);   // stored as 2.12 (banker's rounding)

// Apply a retail-style 8.25% tax, rounding the product away from zero.
Money<USD> tax = price.Multiply(0.0825m, MidpointRounding.AwayFromZero);
    Exceptions
    Type Condition
    OverflowException

    The product falls outside the range of decimal.

    Multiply(decimal, MonetaryContext)

    Multiplies this amount by multiplier and rounds the result to the currency's minor-unit precision using context's rounding strategy.

    Declaration
    public Money<TCurrency> Multiply(decimal multiplier, MonetaryContext context)
    Parameters
    Type Name Description
    decimal multiplier

    The scalar multiplier.
    MonetaryContext context

    The monetary context whose rounding strategy is applied at the settlement boundary.
    Returns
    Type Description
    Money<TCurrency>

    The product, rounded to TCurrency.MinorUnits using context.
    Remarks

    Because Money<TCurrency> is a settlement value, only the context's rounding strategy is honoured; the scale is fixed to the currency's minor units. For deferred-rounding chains use a high-precision calculation value and round once at the end.

    Exceptions
    Type Condition
    ArgumentNullException

    context is null.
    OverflowException

    The product falls outside the range of decimal.
