    Struct DelimitedReaderOptions

    Provides configuration for a Utf8DelimitedReader, controlling the delimiter, quoting, header handling, and the field-count and duplicate-header policies.

    Remarks

    The options are an immutable value type. Because the default value of a char is '\0', the delimiter, quote, and comment characters fall back to their RFC 4180 defaults (',', '"', '#') when left unset, and headers are read by default (set NoHeader to disable).

    Properties

    Name Description
    AllowComments

    Gets a value indicating whether lines beginning with the comment character are skipped.
    CommentChar

    Gets the comment character, or '\0' to use the default '#'.
    Default

    Gets the default reader options (comma delimiter, double-quote quoting, header row present).
    Delimiter

    Gets the field delimiter, or '\0' to use the default comma.
    DuplicateHeaderBehavior

    Gets the policy applied to a header row that repeats a column name.
    FieldCountBehavior

    Gets the policy applied to a record whose field count differs from the header's.
    MalformedRecordBehavior

    Gets the policy applied to a record that violates the field-count policy.
    NoHeader

    Gets a value indicating whether the first record is treated as data rather than a header row.
    Quote

    Gets the quote character, or '\0' to use the default double quote.
    TrimFields

    Gets a value indicating whether surrounding whitespace is trimmed from unquoted fields.
