Examples

// Single-call computation against the 6-character body (consonants and digits only).
char check = Sedol.Compute("B0WNLY");   // '7'

// Full-sequence validation.
bool ok = Sedol.IsValid("B0WNLY7");     // true

// Streaming use when the body is built up incrementally.
var algo = new Sedol();
algo.Append("B0WNLY");
char d = algo.GetCurrentCheckDigit();   // '7'

Remarks

SEDOL identifiers comprise six body characters followed by a single numeric check digit. Body characters are drawn from the decimal digits and the uppercase Latin consonants - vowels (A, E, I, O, U) are not permitted in any body position and will cause input-validation exceptions.

The weight pattern {1, 3, 1, 7, 3, 9} is applied from left to right across the six body characters; each character's numeric value (digits: 0-9; letters: A=10 … Z=35) is multiplied by its position weight. The check digit is chosen so the weighted sum is a multiple of ten.

Worked example. For the body "B0WNLY", the computed check digit is '7', and the resulting SEDOL "B0WNLY7" is therefore valid.

important

This algorithm is not cryptographically secure and should not be used for password hashing, digital signatures, or integrity validation in security-sensitive applications.
