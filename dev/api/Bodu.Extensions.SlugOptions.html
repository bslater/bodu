MaxLength

Gets the maximum slug length, or zero for an unbounded slug.

public int MaxLength { get; init; }

Property Value

int

Defaults to 0 (unlimited). When greater than zero, the slug is truncated at a separator boundary so the result never exceeds the limit and never ends with a dangling separator.

NormalizeDiacritics

Gets a value indicating whether diacritical marks are stripped and transliterated before slugging.

public bool NormalizeDiacritics { get; init; }

Property Value

bool

Defaults to true. When set, combining marks are removed and the German sharp-s (ß) is transliterated to ss.
