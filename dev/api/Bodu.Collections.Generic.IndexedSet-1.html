Represents an index-addressable unique list - an insertion-ordered collection of unique elements that exposes the full IList<T> contract.

public sealed class IndexedSet<T> : IList<T>, ICollection<T>, IReadOnlyList<T>, IReadOnlyCollection<T>, IEnumerable<T>, IEnumerable where T : notnull

Examples

// Build a deduplicated playlist that can still be reordered by index.
var playlist = new IndexedSet<string>(StringComparer.OrdinalIgnoreCase);

playlist.Add("Intro");
playlist.Add("Verse");
playlist.Add("Chorus");
bool added = playlist.Add("verse"); // false - already present under case-insensitive comparer

playlist.Insert(0, "Cold Open");    // positional insertion preserves uniqueness
playlist.Move(oldIndex: 1, newIndex: 3);

int chorusIndex = playlist.IndexOf("Chorus"); // O(1) lookup via the hash index
string second   = playlist[1];                // O(1) positional read

Remarks

IndexedSet<T> shares its backing storage with OrderedSet<T> via the internal Bodu.Collections.Generic.OrderedSetStorage<T> engine: a contiguous element array for deterministic index order plus an open-addressing hash table for O(1) Contains(T) and IndexOf(T). No BCL collection types are used as backing storage.

Use IndexedSet<T> when callers need positional mutation - Insert(int, T), RemoveAt(int), Move(int, int), or the indexer setter. Use OrderedSet<T> when the public surface is conceptually a set and indices exist only as a read-only view onto insertion order.

This type is not thread-safe.
