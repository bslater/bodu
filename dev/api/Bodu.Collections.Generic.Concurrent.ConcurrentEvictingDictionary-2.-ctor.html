    Constructor ConcurrentEvictingDictionary

    ConcurrentEvictingDictionary()

    Initializes a new instance of the ConcurrentEvictingDictionary<TKey, TValue> class, with the default capacity and eviction policy.

    Declaration
    public ConcurrentEvictingDictionary()
    Remarks

    Creates an empty dictionary with a capacity of Bodu.Collections.Generic.Concurrent.ConcurrentEvictingDictionary<TKey, TValue>.DefaultCapacity items, using Bodu.Collections.Generic.Concurrent.ConcurrentEvictingDictionary<TKey, TValue>.DefaultPolicy for eviction when capacity is exceeded, and the default key comparer ( Default).
