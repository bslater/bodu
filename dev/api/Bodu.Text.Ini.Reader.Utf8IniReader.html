Provides a high-performance, forward-only, source-order reader for INI bytes. The reader is a ref struct, so it lives on the stack and cannot be boxed or captured.

Remarks

A call to Read() advances to the next token and reports it through TokenType: a SectionHeader begins a section, each entry surfaces a PropertyName followed by a String value, and comment lines appear as Comment tokens. Keys read before the first section header belong to the global section.

The reader surfaces raw text in source order; it does not resolve duplicate sections/keys, apply case rules, or strip inline comments. A value retains everything after the assignment to the end of the line.
