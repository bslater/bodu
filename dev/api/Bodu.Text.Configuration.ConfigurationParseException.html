    Class ConfigurationParseException

    The exception raised when a configuration document cannot be parsed. Exposes the originating diagnostic ( Diagnostic) together with any additional diagnostics gathered before the failure.

    Remarks

    In Throw mode the parser raises this exception on the first recoverable error it encounters. In Collect mode this exception is raised only for non-recoverable errors (such as a truncated stream); recoverable errors surface instead on the Diagnostics list.

    The exception always provides a non-default Diagnostics array; when a single diagnostic triggered the failure it also appears as Diagnostic. Location forwards to the primary diagnostic's location and falls back to None when no diagnostic is attached.

    Examples
    try
{
    IniDocument doc = ConfigurationDocument.Parse(text);
}
catch (ConfigurationParseException ex)
{
    // The primary diagnostic includes a source location that points back into the document.
    Console.WriteLine($"Parse failed at {ex.Location}: {ex.Message}");

    // Every diagnostic gathered before the failure is preserved.
    foreach (ConfigurationDiagnostic d in ex.Diagnostics)
        Console.WriteLine($"  {d}");
}
