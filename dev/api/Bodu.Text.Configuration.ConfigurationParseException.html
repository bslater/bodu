The exception raised when a configuration document cannot be parsed or resolved. Exposes the diagnostic that stopped the operation as Diagnostic; the library raises it with that diagnostic alone.

Examples

try
{
    ConfigurationDocument doc = ConfigurationDocument.Parse(text);
}
catch (ConfigurationParseException ex)
{
    // The primary diagnostic includes a source location that points back into the document.
    Console.WriteLine($"Parse failed at {ex.Location}: {ex.Message}");

    // Diagnostics holds the diagnostic that stopped the parse.
    foreach (ConfigurationDiagnostic d in ex.Diagnostics)
        Console.WriteLine($"  {d}");
}

Remarks

In Throw mode the parser raises this exception on the first recoverable error it encounters. In Collect and Ignore modes parsing never raises it: errors surface on the Diagnostics list or are dropped, and an I/O error from the source propagates unchanged. Resolving a document raises it too, when a section name is not a valid glob (see Compile(string, StringComparison)).

Every exception the library raises carries exactly one diagnostic, the error that stopped the operation, as Diagnostic and as the single entry of Diagnostics; warnings the parser reported before the error are not attached. Diagnostics holds more than one entry only when a caller constructs the exception from a list with ConfigurationParseException(IReadOnlyList<ConfigurationDiagnostic>), and is empty, but never default, when it is constructed from a message alone. Location forwards to the primary diagnostic's location and falls back to None when no diagnostic is attached.
