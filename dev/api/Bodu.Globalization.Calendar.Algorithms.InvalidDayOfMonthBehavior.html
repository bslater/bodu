    Enum InvalidDayOfMonthBehavior

    Specifies how a monthly day-of-month recurrence handles a month that does not contain the requested day, such as the 31st in February.

    Namespace: Bodu.Globalization.Calendar.Algorithms
    Assembly: Bodu.Globalization.Calendar.dll
    Syntax
    public enum InvalidDayOfMonthBehavior

    Fields

    Name Description
    Skip

    A month that does not contain the requested day emits no occurrence.
    UseLastDayOfMonth

    A month that does not contain the requested day emits its last calendar day instead.
