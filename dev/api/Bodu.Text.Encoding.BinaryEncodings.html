Examples

// Pre-bound singleton - no allocation per call.
IBinaryEncoding hex    = BinaryEncodings.Base16Upper;
IBinaryEncoding jwt    = BinaryEncodings.Base64UrlSafe;
IBinaryEncoding bitcoin = BinaryEncodings.Base58;

string encoded = jwt.Encode(payload);
byte[] decoded = jwt.Decode(encoded);

// Look up by name - accepts canonical names and well-known aliases.
IBinaryEncoding fromConfig = BinaryEncodings.Get(appConfig["encoding"] ?? "base64");
IBinaryEncoding fromAlias  = BinaryEncodings.Get("hex");           // same as Base16Lower

Remarks

Each property returns a thread-safe singleton bound to a specific variant. The pattern is analogous to System.Text.Encoding.UTF8: a constant instance that can be passed around, stored in configuration, or used through IBinaryEncoding by code that must remain agnostic to the concrete encoding.

Code that knows the encoding at compile time should prefer the static methods on Base16, Base32, Base64, Base58, or Base85 - they are slightly faster (no virtual dispatch) and surface variant-specific options (line breaks, padding control, alternate variants) that the unified interface intentionally hides.

Returns the encoding for the supplied case-insensitive name.
