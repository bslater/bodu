    Class Lei

    Computes the two-digit check sequence of a Legal Entity Identifier (LEI) as specified by ISO 17442. This class cannot be inherited.

    Remarks

    A Legal Entity Identifier is a twenty-character alphanumeric code comprising an eighteen-character body followed by a two-digit check. The check is evaluated using ISO 7064 MOD 97-10 directly over the body, without the IBAN-style rearrangement: letters are expanded by value 'A'=10 … 'Z'=35, the resulting decimal string is folded through modulus ninety-seven, and the check is chosen so that the running remainder of the complete twenty-character sequence equals 1.

    Worked example. For the body "54930084UKLVMY22DS", the computed check is "16", and the resulting LEI "54930084UKLVMY22DS16" is therefore valid.

    important

    This algorithm is not cryptographically secure and should not be used for password hashing, digital signatures, or integrity validation in security-sensitive applications.

    Examples
    // Single-call computation against the 18-character body.
string check = Lei.Compute("54930084UKLVMY22DS");   // "16"

// Full-sequence validation.
bool ok = Lei.IsValid("54930084UKLVMY22DS16");      // true

// Streaming use when the body is built up incrementally.
var algo = new Lei();
algo.Append("54930084UKLVMY22DS");
string code = algo.GetCurrentCheckDigits();         // "16"
