    AddEdge(T, T, double)

    Adds or updates a weighted edge between the specified vertices, creating either vertex if it does not already exist.

    Declaration
    public void AddEdge(T from, T to, double weight)
    Parameters
    Type Name Description
    T from

    The source vertex.
    T to

    The destination vertex.
    double weight

    The finite, non-negative edge weight.
    Remarks

    On an undirected graph, a self-loop (from equals to under Comparer) is stored as a single adjacency entry, so it contributes 1 to Degree(T) — diverging from the classical graph-theory convention, in which an undirected self-loop counts twice toward its vertex's degree.

    Exceptions
    Type Condition
    ArgumentNullException

    Either vertex is null.
    ArgumentOutOfRangeException

    weight is not a finite, non-negative number (it is NaN, infinite, or negative).
