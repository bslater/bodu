DotEnvReaderOptions

DisallowExportPrefix

Gets a value indicating whether a leading export keyword before a key is recognized and stripped.

public bool DisallowExportPrefix { get; init; }

Property Value

bool

true to accept the export prefix; otherwise false.

Remarks

The property is inverted so the parameterless Default enables the prefix.

DisallowInlineComments

Gets a value indicating whether a # preceded by whitespace terminates an unquoted value as an inline comment.

public bool DisallowInlineComments { get; init; }

Property Value

bool

true to disable inline comments; otherwise false.

Remarks

The property is inverted so the parameterless Default enables inline comments.

SkipComments

Gets a value indicating whether comment lines are surfaced as Comment tokens.

public bool SkipComments { get; init; }

Property Value

bool

true to skip comment tokens; otherwise false.

Remarks

The property is inverted so the parameterless Default preserves comments.
