    Remarks

    MOD 97-10 is the pure ISO 7064 system that uses modulus ninety-seven with radix ten. It underpins the International Bank Account Number (IBAN, ISO 13616), the Legal Entity Identifier (LEI, ISO 17442), and the Committee on Uniform Securities Identification Procedures (CUSIP) check computation used for Legal-Entity Identifier issuance. Letters in the body are expanded by value 'A'=10 … 'Z'=35 before being absorbed.

    The running remainder r is initialized to zero. Each body character is absorbed as r ← (r·10 + a) mod 97 for a decimal digit or r ← (r·100 + a) mod 97 for an uppercase letter (whose value is two decimal digits). The two-digit check code is (98 - (r · 100) mod 97) mod 97, formatted as two ASCII decimal digits; the complete sequence body + check is valid when its running remainder, including the check code, equals 1.

    Worked example. For the body "794", the computed check code is "44", and the resulting sequence "79444" is therefore valid under MOD 97-10.

    important

    This algorithm is not cryptographically secure and should not be used for password hashing, digital signatures, or integrity validation in security-sensitive applications.

    Examples
    // Single-call computation — returns the two-digit check as a string.
string check = Iso7064Mod97_10.Compute("794");   // "44"

// Full-sequence validation.
bool ok = Iso7064Mod97_10.IsValid("79444");      // true

// Streaming use when the body is built up incrementally.
var algo = new Iso7064Mod97_10();
algo.Append("794");
string code = algo.GetCurrentCheckDigits();      // "44"
