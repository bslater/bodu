Remarks

The options bag is a profile-grouped set of init-only properties. Start from a named preset that matches the hosting flavour — Bodu for the default Bodu Text Configuration semantics, EditorConfigCompatible for strict EditorConfig parity, Strict for fail-fast behaviour, or Relaxed for lenient parsing — and override the specific properties that need to differ. Use For(ConfigurationProfile) when the profile is data-driven (for example, read from configuration).

DiagnosticMode is the most consequential knob. In Throw the reader raises ConfigurationParseException on the first recoverable error; in Collect the parser drives through the document and reports every recoverable issue via the parse result's Diagnostics list. Pair the latter with ParseWithDiagnostics(string, ConfigurationParseOptions?).

Key shape is delegated to KeyOptions. Sharing one configured ConfigurationKeyOptions instance between parse and ConfigurationResolveOptions keeps the parsed model and the resolved view's lookups consistent. Instances are safe to cache and share across threads because every property is init-only. 

// Strict structure, but collect every diagnostic instead of failing fast.
var options = new ConfigurationParseOptions
{
    Profile        = ConfigurationProfile.Strict,
    DiagnosticMode = ConfigurationDiagnosticMode.Collect,
};

ConfigurationParseResult result = ConfigurationDocument.ParseWithDiagnostics(text, options);
foreach (ConfigurationDiagnostic d in result.Diagnostics)
    Console.WriteLine(d);
