Fields

UnresolvableReference = 0

The value's reference into the container does not resolve: it names a heap item, or a subnode, that the container does not hold, or a fixed-width value is shorter than its type. Such a value is omitted only when OmitUnresolvableValues is set; otherwise it raises PstFileFormatException.

UndecodableValue = 1

The value resolves but cannot be decoded as its MAPI property type, for example a multi-valued value too short for its count. Such a value is omitted under Compatible and Minimal; under Strict it raises OutlookPstFormatException.
