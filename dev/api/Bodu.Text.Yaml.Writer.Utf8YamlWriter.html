    Struct Utf8YamlWriter

    Provides a forward-only writer that emits a YAML document in block style to a UTF-8 buffer, in the manner of Utf8JsonWriter.

    Remarks

    The writer emits block mappings and sequences with configurable indentation, choosing the most compact safe scalar presentation for each value (plain when unambiguous, otherwise double-quoted). Empty mappings and sequences are emitted in the flow forms {} and [] so they round-trip as empty collections rather than null.

    The writer is a ref struct and cannot be boxed, stored on the heap, or captured by a lambda. Its mutable state lives behind a single shared reference, so passing the writer by value hands the callee the same in-progress document rather than an independent copy.
