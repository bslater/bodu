Produces a converter that serializes the enumeration TEnum as a YAML integer scalar carrying its underlying numeric value.

Examples

public sealed class WorkItem
{
    [Converter(typeof(YamlNumberEnumConverter<Priority>))]
    public Priority Priority { get; set; }
}

// Priority.High (underlying value 2) serializes as: Priority: 2

Remarks

Reference the factory from a ConverterAttribute on a member, property, or the enumeration itself, or register it on Converters. It exposes a public parameterless constructor so it can be used through the converter attribute. The produced converter writes the numeric value regardless of WriteEnumsAsStrings.
