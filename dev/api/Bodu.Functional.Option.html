    Class Option

    Provides factory methods for creating Option<T> values with type inference at the call site.

    Remarks

    The members mirror the static surface of Option<T> so callers can write Option.Some(3) instead of Option<int>.Some(3), and add FromNullable<T>(T?) — the Nullable<T> lift that the implicit conversion on the generic type cannot express.

    Methods

    Name Description
    FromNullable<T>(T?)

    Converts a nullable value type to an option, mapping null to None.
    None<T>()

    Returns the option of the specified type that carries no value.
    Some<T>(T)

    Creates an option carrying the specified non-null value.
