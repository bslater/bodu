Remarks

BiffReader parses a header for every record it frames and exposes the current one as Header; the type is public so a caller framing records itself — a stream scanner skipping payloads, for example — shares the same layout. Length is the declared payload length, which a conformant writer keeps within GetMaxPayloadLength(BiffVersion).
