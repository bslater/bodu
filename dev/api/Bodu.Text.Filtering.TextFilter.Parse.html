    Parse(IEnumerable<string>)

    Builds a filter from raw pattern lines using the gitignore file conventions, with default options.

    Declaration
    public static TextFilter Parse(IEnumerable<string> lines)
    Parameters
    Type Name Description
    IEnumerable<string> lines

    The lines to parse. Must not be null or contain null entries.
    Returns
    Type Description
    TextFilter

    The compiled filter.
    Remarks

    Each line is trimmed and parsed as a wildcard pattern: blank lines and lines starting with # are skipped, a leading ! makes the pattern an exclude, and ! / # escape a literal leading ! or #. Regular-expression patterns cannot be expressed in line form — declare them via TextFilterPattern or TextFilterBuilder.

    Exceptions
    Type Condition
    ArgumentNullException

    lines is null.
    ArgumentException

    lines contains a null entry, or a parsed pattern is empty or malformed.

    Remarks

    Each line is trimmed and parsed as a wildcard pattern: blank lines and lines starting with # are skipped, a leading ! makes the pattern an exclude, and ! / # escape a literal leading ! or #. Combine with LastMatchWins for gitignore-faithful ordered-rule semantics.
