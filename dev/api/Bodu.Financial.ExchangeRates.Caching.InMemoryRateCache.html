    Class InMemoryRateCache

    An IRateCache that stores a single provider's rates in memory for the lifetime of the instance, expiring them through the same freshness mechanism as the file caches.

    Remarks

    Rates expire by caching duration rather than by storage: the shared RateCacheBase<TOptions> filters stale rows on read and prunes them on write, so a cached rate is served only while it remains fresh under the duration supplied by the caching provider (see DefaultExpiry and ProviderExpiry). Nothing is persisted, so the cache starts empty on each process and is a drop-in alternative to TomlFileRateCache when on-disk files are unwanted.

    Reads and writes are individually thread-safe. As with every IRateCache, a concurrent store-after-store for the same pair resolves last-write-wins, which is acceptable for a best-effort cache.

    Examples
    // An in-memory caching provider: read-through caching with no on-disk files.
var options = new CachingRateOptions { DefaultExpiry = TimeSpan.FromMinutes(15) };
IDatedRateProvider cached = new CachingRateProvider(rba, new InMemoryRateCache("RBA"), options);
