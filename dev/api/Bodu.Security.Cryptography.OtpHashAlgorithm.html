Remarks

The three members correspond exactly to the algorithms admitted by RFC 6238 and to the algorithm label used in the otpauth:// provisioning URI (SHA1, SHA256, SHA512). No other hash algorithm is valid for one-time passwords, so — unlike HashAlgorithmName — this closed enumeration cannot express an unsupported choice.

Sha1 is the default because RFC 4226 mandates HMAC-SHA-1 and it remains the algorithm most widely interoperable with authenticator applications; its use here is a message-authentication construction, not a collision-resistance one, so SHA-1 carries no practical weakness in this role.
