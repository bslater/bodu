    Encrypt(SymmetricStreamAlgorithm, byte[])

    Encrypts the entire contents of a byte array using the specified stream cipher.

    Declaration

    Parameters
    Type Name Description
    SymmetricStreamAlgorithm algorithm

    The stream cipher to use. Must not be null.
    byte[] array

    The input byte array to encrypt. Must not be null.
    Returns
