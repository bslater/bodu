    Method GetPreviousOccurrence

    GetPreviousOccurrence(DateTime, bool)

    Returns the last occurrence of the set that falls before the specified instant.

    Declaration
    public DateTime? GetPreviousOccurrence(DateTime before, bool inclusive = false)
    Parameters
    Type Name Description
    DateTime before

    The instant the returned occurrence must precede.
    bool inclusive

    true to allow an occurrence exactly equal to before; otherwise the occurrence must be strictly earlier.
    Returns
    Type Description
    DateTime?

    The previous occurrence, or null when none precedes before.
    Remarks

    Due-ness evaluation is a previous-occurrence comparison — typically lastCompleted < GetPreviousOccurrence(now, inclusive: true) — so missed occurrences coalesce structurally: the answer is a single instant, never a backlog.

    Exceptions
    Type Condition
    NotSupportedException

    Thrown when a contributing rule uses a sub-daily frequency.

    GetPreviousOccurrence(DateTimeOffset, bool)

    Returns the last occurrence of the set that falls before the specified instant, preserving its offset.

    Declaration
    public DateTimeOffset? GetPreviousOccurrence(DateTimeOffset before, bool inclusive = false)
    Parameters
    Type Name Description
    DateTimeOffset before

    The instant the returned occurrence must precede.
    bool inclusive

    true to allow an occurrence exactly equal to before; otherwise the occurrence must be strictly earlier.
    Returns
    Type Description
    DateTimeOffset?

    The previous occurrence carrying the offset of before, or null when none precedes it.
    Remarks

    The set's start and dates are wall-clock values; the query interprets them in the offset of before and performs no other offset conversion.

    Exceptions
    Type Condition
    NotSupportedException

    Thrown when a contributing rule uses a sub-daily frequency.
