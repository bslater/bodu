    Method TransformAsync

    TransformAsync(ICryptoTransform, Stream, Stream, int, CancellationToken)

    Asynchronously applies a cryptographic transformation to data read from a source stream and writes the transformed output to a target stream.

    Declaration
    public static Task TransformAsync(this ICryptoTransform transform, Stream sourceStream, Stream targetStream, int bufferSize, CancellationToken cancellationToken = default)
    Parameters
    Type Name Description
    ICryptoTransform transform

    The cryptographic transform to apply. Must not be null.
    Stream sourceStream

    The stream to read untransformed data from. Must not be null.
    Stream targetStream

    The stream to write transformed data to. Must not be null.
    int bufferSize

    The buffer size, in bytes, used for streaming. Must be greater than zero.
    CancellationToken cancellationToken

    A token that may be used to cancel the operation before or during processing, including prior to finalization.
    Returns
    Type Description
    Task

    A Task representing the asynchronous transformation operation.
    Remarks

    Cancellation is checked before the final block is flushed. If cancellation is requested after the last successful read but before finalization, an OperationCanceledException is thrown and finalization is skipped, leaving targetStream in a partial state.

    Neither sourceStream nor targetStream is disposed by this method.

    Examples
    using var aes = Aes.Create();
using var input = File.OpenRead("input.bin");
using var output = File.Create("encrypted.bin");
await aes.CreateEncryptor().TransformAsync(input, output, 81920);
    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when transform, sourceStream, or targetStream is null.
    ArgumentOutOfRangeException

    Thrown when bufferSize is less than or equal to zero.
    OperationCanceledException

    Thrown when the operation is canceled via cancellationToken.
    TaskCanceledException

    Thrown when the operation is canceled via the supplied cancellation token.

    TransformAsync(ICryptoTransform, ReadOnlyMemory<byte>, Memory<byte>, CancellationToken)

    Asynchronously applies a cryptographic transformation to a memory region and writes the transformed result into a destination memory region.

    Declaration
    public static Task<int> TransformAsync(this ICryptoTransform transform, ReadOnlyMemory<byte> input, Memory<byte> destination, CancellationToken cancellationToken = default)
    Parameters
    Type Name Description
    ICryptoTransform transform

    The cryptographic transform to apply. Must not be null.
    ReadOnlyMemory<byte> input

    The memory region containing the input data.
    Memory<byte> destination

    The memory region to receive the transformed output.
    CancellationToken cancellationToken

    A token that may be used to cancel the operation before finalization.
    Returns
    Type Description
    Task<int>

    A Task<TResult> whose result is the number of bytes written to destination.
    Remarks

    Cancellation is checked before finalization. If cancellation is requested, an OperationCanceledException is thrown and the content of destination is undefined.

    Examples
    using var aes = Aes.Create();
using var encryptor = aes.CreateEncryptor();

byte[] input = { 0x01, 0x02, 0x03 };
byte[] buffer = new byte[64];

int written = await encryptor.TransformAsync(input, buffer);
    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when transform is null.
    ArgumentException

    Thrown when destination is too small to hold the transformed output. A safe minimum size is input.Length + transform.OutputBlockSize.
    OperationCanceledException

    Thrown when the operation is canceled via cancellationToken.
    InvalidOperationException

    Thrown if the internal transformed data buffer cannot be accessed after finalization.
