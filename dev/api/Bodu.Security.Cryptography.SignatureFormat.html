    Enum SignatureFormat

    Specifies the wire encoding of a digital-signature value.

    Namespace: Bodu.Security.Cryptography
    Assembly: Bodu.Security.Cryptography.dll
    Syntax
    public enum SignatureFormat
    Remarks

    The same mathematical signature can be serialized in incompatible ways — most notably ECDSA signatures, which circulate both as ASN.1 DER SEQUENCE structures and as fixed-width IEEE P1363 r || s concatenations. Carrying the format alongside the bytes prevents a signature produced in one encoding from being verified, stored, or transmitted as if it were the other.

    Fields

    Name Description
    Unknown

    The encoding is unknown or unspecified.
    Raw

    The raw signature bytes of the algorithm, with no additional framing (for example an EdDSA signature).
    Der

    An ASN.1 DER-encoded structure (for example the ECDSA SEQUENCE { r INTEGER, s INTEGER } form used by X.509 and CMS).
    P1363

    The fixed-width IEEE P1363 concatenation (for example the ECDSA r || s form used by JOSE/COSE and the .NET ECDsa.SignData default).
