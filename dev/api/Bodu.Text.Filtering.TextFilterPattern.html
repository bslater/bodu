Remarks

Patterns do not match values on their own; they are compiled - together with the other patterns of a rule set - into a TextFilter via Build(IEnumerable<TextFilterPattern>). Wildcard grammar errors and regular-expression syntax errors are reported at that point, not by this constructor.

The constructor validates only shape-independent rules: the pattern text must be non-empty, must not consist solely of white space, and must not exceed Bodu.Text.Filtering.TextFilterPattern.MaxPatternLength characters (a guard against pathological patterns, mirroring the limits used elsewhere in the Bodu libraries).
