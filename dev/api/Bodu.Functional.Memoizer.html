Provides factory methods that wrap a function with a thread-safe cache, so each distinct argument is computed at most once and subsequent calls return the stored result.

Remarks

Results are cached in a ConcurrentDictionary<TKey, TValue>. Only successful results are stored: if the underlying function throws, nothing is cached and the next call retries. A null result is a valid cached value. For sequential use the function runs exactly once per distinct argument; under concurrent first access for the same argument the function may run more than once, but only one result is published.

Arguments are constrained to non-nullable types because they are used as dictionary keys. Memoizing a recursive function requires the function to call the memoized delegate for its recursive step.

The cache is unbounded and never evicts: every distinct argument's result is retained for the lifetime of the memoized delegate. Memoizing a function over an unbounded argument domain therefore grows memory without limit; for bounded caching with eviction, use EvictingDictionary<TKey, TValue> from the Bodu.Collections package instead.

var lengthOf = Memoizer.Memoize<string, int>(s => s.Length, StringComparer.OrdinalIgnoreCase);

int x = lengthOf("Hello"); // computed
int y = lengthOf("HELLO"); // cache hit
