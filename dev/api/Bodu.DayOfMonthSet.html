Examples

var selected = new DayOfMonthSet(1, 15);
DayOfMonthSet parsed = DayOfMonthSet.Parse("1,15");

bool due = selected.Contains(DateTime.Today.Day);
bool same = selected == parsed; // true

Remarks

A DayOfMonthSet holds one bit per day, so it never allocates, and testing, adding or removing a day, or combining two sets with |, &, ^ and ~, is a single bitwise operation. Contains(int) answers false for any value outside 1 to 31 rather than throwing, which keeps a membership test against Day to a comparison and a bit test.

The values are day numbers and do not depend on the length of a month: a set that contains 31 contains it whatever the month, so a date in a 30-day month never matches it. Days counted back from the end of a month are a separate question, which a caller answers by testing DateTime.DaysInMonth(year, month) - day + 1 against a second set.

The text form lists the days in ascending order, separated by commas, each run of two or more consecutive days written as an inclusive range, so "1,15" selects the 1st and the 15th. The empty set is the empty string. Parse(string) reads any list of values and ranges in that form, in any order, and ToString() writes the canonical one. ToString(string?) also writes every day without ranges, or a binary form with one character per day, and Parse(string) and ParseExact(string, string) read them back. TryFormat(Span<char>, out int, ReadOnlySpan<char>, IFormatProvider?) writes the same text into a span of characters, its other overload into a span of UTF-8 bytes, and the span and UTF-8 overloads of Parse, TryParse, ParseExact and TryParseExact read it.

ToUInt64() and FromUInt64(ulong) expose the bits directly: bit n selects day 1 + n.

Remarks

A text of exactly 31 characters, each 0 or 1, is the binary form, day 1 first. Any other text is a comma-separated list of days and inclusive ranges: whitespace around the list and around each value is ignored, an empty or blank string is the empty set, values are unsigned decimal integers, a range a-b needs a no greater than b, and values may repeat or overlap.

The binary test comes first and reads the text as given, so text made only of 0 and 1 is a list only when it is not 31 characters long. ParseExact(string, string) with the "G" format reads any text as a list.

Exceptions

ArgumentNullException

Thrown when s is null.

FormatException

Thrown when s is neither the binary form nor a list of values and ranges from 1 to 31.
