    Method SwapEndian

    SwapEndian<T>(Span<T>)

    Swaps the byte order (endianness) of each element of type T in the specified span.

    Declaration
    public static void SwapEndian<T>(this Span<T> span) where T : unmanaged
    Parameters
    Type Name Description
    Span<T> span

    The span containing elements to swap in place.
    Type Parameters
    Name Description
    T

    The unmanaged type whose byte order will be swapped.
    Remarks

    This method reverses the byte order of each element in the span individually, performing the operation in place without allocating memory. No operation is performed for types with a size of one byte or less. The swap assumes platform-native layout of T. The operation is safe for empty spans and spans containing only one element.

    SwapEndian(ReadOnlySpan<byte>, Span<byte>, int)

    Copies data from a source span to a destination span, swapping the byte order (endianness) of each element of size elementSize bytes.

    Declaration
    public static void SwapEndian(ReadOnlySpan<byte> source, Span<byte> destination, int elementSize)
    Parameters
    Type Name Description
    ReadOnlySpan<byte> source

    The source span of bytes.
    Span<byte> destination

    The destination span of bytes to receive the endian-swapped elements.
    int elementSize

    The size, in bytes, of each element whose byte order should be swapped.
    Remarks

    This method reverses the byte order of each element individually while copying from source to destination. It assumes platform-native layout and performs the swap without allocating additional memory.

    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown if elementSize is less than or equal to 1.
    ArgumentException

    Thrown if the source or destination spans do not have a length that is a multiple of elementSize, or if the destination is too small to receive the swapped data.
