BiffBoundSheetRecord.cs

Represents a decoded BOUNDSHEET record: one entry of the sheet directory in the workbook globals, giving a sheet's name, visibility, kind, and the absolute stream offset of its substream.

Remarks

The name is an 8-bit-length string in both versions - a Unicode string in BIFF8, a code-page byte string in BIFF5.
