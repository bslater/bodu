    ReplaceAll<TSource>(IList<TSource>, TSource, TSource)

    Replaces every occurrence of oldItem in the IList<T> with newItem, using Default to compare elements.

    Declaration

    Parameters
    Type Name Description
    IList<TSource> list

    The list to modify in place. Must not be null.
    TSource oldItem

    The value to locate and replace.
    TSource newItem

    The replacement value.
    Returns
    Type Description
    int

    The number of elements that were replaced.
    Type Parameters
    Name Description
    TSource

    The type of the elements in the list.
    Remarks

    Elements are assigned in place through the list's indexer; no insertions or removals are performed, so the list size and the relative position of every element are preserved.

    ReplaceAll<TSource>(IList<TSource>, TSource, Func<TSource, bool>)

    Replaces every element in the IList<T> that satisfies the specified predicate with newItem.

    Declaration
    public static int ReplaceAll<TSource>(this IList<TSource> list, TSource newItem, Func<TSource, bool> predicate)
    Parameters
    Type Name Description
    IList<TSource> list

    The list to modify in place. Must not be null.
    TSource newItem

    The replacement value to assign to every matching slot.
    Func<TSource, bool> predicate

    A function that defines the conditions of the elements to replace.
    Returns
    Type Description
    int

    The number of elements that were replaced.
    Type Parameters
    Name Description
    TSource

    The type of the elements in the list.
    Remarks

    The list is walked once with a fixed length captured before iteration begins. Predicate matches against newItem do not cause additional passes or infinite recursion: a slot is tested exactly once.

    Exceptions
    Type Condition
    ArgumentNullException

    list or predicate is null.
