Examples

// Diagnostic introspection: locate the Bodu stream provider after the configuration root has been built.
IConfigurationRoot root = builder.Build();
TextStreamConfigurationProvider? bodu = root.Providers
    .OfType<TextStreamConfigurationProvider>()
    .FirstOrDefault();

if (bodu is not null)
{
    Console.WriteLine($"Target path: {bodu.TextSource.TargetPath ?? "<none>"}");
}

Remarks

Stream-backed providers are one-shot: the stream is consumed during the initial Load(Stream) call and no reload-on-change machinery is attached. For file-backed loading with reload support, use TextConfigurationProvider instead. The Parse → Resolve → flatten pipeline is shared with TextConfigurationProvider via Bodu.Extensions.Configuration.Text.TextConfigurationLoader.

Consumers do not construct this type directly — it is materialized by Build(IConfigurationBuilder) when an IConfigurationBuilder is built. The typed TextSource accessor exists for diagnostic scenarios where a host needs to inspect the source that produced a given IConfigurationProvider.
