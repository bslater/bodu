    Interface IQuarterDefinitionProvider

    Defines a provider interface for custom quarter calculation logic based on DateTime or DateOnly values.

    Namespace: Bodu.Extensions
    Assembly: Bodu.Core.dll
    Syntax
    public interface IQuarterDefinitionProvider
    Remarks

    Implementations describe a recurring quarter rule — a fiscal or logical calendar definition that is independent of any single year. Year-specific values, such as quarter start and end dates or whether a fiscal year contains a 53rd week, are derived on demand from the DateTime or DateOnly input, or from an explicit fiscalYear argument.

    Example use cases include 4–4–5 calendars, academic terms, retail fiscal calendars, or historical reporting quarters that do not align with calendar or standard financial quarters.

    Methods that support this interface include:

    • Quarter(DateTime, IQuarterDefinitionProvider)
    • FirstDateOfQuarter(DateTime, IQuarterDefinitionProvider)
    • LastDateOfQuarter(DateTime, IQuarterDefinitionProvider)
    • IsFirstDateOfQuarter(DateTime, IQuarterDefinitionProvider)
    • IsLastDateOfQuarter(DateTime, IQuarterDefinitionProvider)
    • Quarter(DateOnly, IQuarterDefinitionProvider)
    • FirstDateOfQuarter(DateOnly, IQuarterDefinitionProvider)
    • LastDateOfQuarter(DateOnly, IQuarterDefinitionProvider)
    • IsFirstDateOfQuarter(DateOnly, IQuarterDefinitionProvider)
    • IsLastDateOfQuarter(DateOnly, IQuarterDefinitionProvider)
