Provides Base32 encoding and decoding of binary data across multiple variants (RFC 4648 standard and hex-extended, Crockford, z-base-32), with optional padding control and whitespace tolerance during parsing.

Examples

byte[] data = "hello"u8.ToArray();

// RFC 4648 Standard Base32 (default).
string standard = Base32.Encode(data);                                      // "NBSWY3DP"

// Crockford Base32 - human-friendly alphabet, no padding.
string crockford = Base32.Encode(data, Base32Variant.Crockford);

// RFC 4648 base32hex - preserves sort order with binary keys.
string base32hex = Base32.Encode(data, Base32Variant.HexExtended);

// Round-trip.
byte[] roundtrip = Base32.Decode(standard);

Remarks

Each variant uses 5 bits per character (radix 32) and groups input bytes into five-byte blocks that map to eight output characters. The padding character = is appended on encode when the input is not a multiple of five bytes; whether padding is emitted by default depends on the variant.

The UpperCase, IncludePrefix, and InsertSpacing flags have no effect on Base32 - each variant emits its canonical alphabet case and there is no standard prefix. The AllowPrefix flag is also ignored on decode for the same reason.
