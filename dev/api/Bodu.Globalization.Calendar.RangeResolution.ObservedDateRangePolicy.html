Fields

ObservedOccurrenceControlsInclusion = 0

The emitted (observed) occurrence date controls inclusion.

ActualOccurrenceControlsInclusion = 1

The originally calculated (actual) occurrence date controls inclusion.

BothOccurrencesControlInclusion = 2

Either the actual or the observed occurrence date controls inclusion.

Remarks

The recommended default is ObservedOccurrenceControlsInclusion, which guarantees that a single-day query and a range query return consistent results: an occurrence is included when its emitted (observed) date falls inside the requested window.
