Class BencodeConfigurationProvider

Namespace

A read-only IConfigurationProvider that consumes Bencode through the Bodu.Text.Bencode read-only document model and flattens it into the colon-delimited configuration key model. Because the provider exposes no mutation surface, Set(string, string?) is rejected.

Remarks

The provider implements IConfigurationProvider directly rather than deriving from ConfigurationProvider: omitting the mutable base keeps the configuration bridge on the read-only half of the contract, so configuration loaded from Bencode cannot be mutated back through the provider. 

// Built by BencodeConfigurationSource; flattens Bencode dictionaries into
// colon-separated configuration keys.
IConfiguration configuration = new ConfigurationBuilder()
    .AddBencodeFile("appsettings.bencode")
    .Build();

var level = configuration["logging:level"];
