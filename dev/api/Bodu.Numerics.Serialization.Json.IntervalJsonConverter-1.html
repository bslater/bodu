Remarks

The converter shape is selected by NumericsJsonPolicy:

  • Strict - canonical object form { "lower": 1, "upper": 5, "lowerInclusive": true, "upperInclusive": true }; the empty interval emits as the single-property object { "empty": true }. A bounded side requires its endpoint value and inclusion flag; an unbounded side emits the marker "lowerUnbounded": true / "upperUnbounded": true in place of both (for example { "lower": 1, "upperUnbounded": true, "lowerInclusive": true } for [1, +∞), or { "lowerUnbounded": true, "upperUnbounded": true } for the whole line). Duplicate properties are rejected, and an "empty": true marker rejects any sibling endpoint or unbounded property.
  • Lenient - same object shape as Strict, with additional tolerance: "min" and "max" are accepted as aliases for "lower" and "upper", missing endpoint-inclusion flags default to closed (true), and a top-level JSON string is accepted and routed through TryParse(string?, IFormatProvider?, out Interval<T>) as a fallback.
  • Compact - string form in ISO 31-11 bracket notation (for example "[1, 5)") or the empty-set glyph "∅". Reads delegate to TryParse(string?, IFormatProvider?, out Interval<T>) and writes call ToString(string?, IFormatProvider?) with the invariant culture.
