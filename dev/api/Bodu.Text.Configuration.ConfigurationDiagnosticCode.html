Identifies a specific class of ConfigurationDiagnostic. Codes are stable so that consumers may suppress, filter, or test for particular conditions without inspecting the message text.

None = 0

No specific code is associated with the diagnostic.

MissingEquals = 1

A property line did not contain a key/value separator (=).

EmptyKey = 2

A property declared an empty key.

DuplicateKey = 3

A duplicate key was encountered when Disallowed was active.

UnterminatedSectionHeader = 4

A section header opened with [ but did not close with ].

EmptySectionHeader = 5

A section header contained no characters between [ and ].

UnbalancedBrace = 6

A glob expression contained an opening brace with no matching close.

UnbalancedBracket = 7

A glob expression contained an opening bracket with no matching close.

InvalidKeyCharacter = 8

A property key included an illegal character.

InvalidEscape = 9

Reserved; not currently emitted. The reader decodes no escape sequence: a backslash only keeps the character after it from being read as =, # or ; and stays in the text, so no value can hold a malformed one.

LineTooLong = 10

A configuration line was longer than the configured maximum.

KeyTooLong = 11

A configuration property key was longer than the configured maximum.

DuplicateSection = 12

A duplicate section header was encountered when Disallowed was active.

NumericRangeTooLarge = 13

A glob expression's numeric range ({n1..n2}) would expand to more alternatives than the parser permits.

TrailingContentAfterSectionHeader = 14

A configuration section header contained non-whitespace content after the closing ] when the configured section-header mode did not permit trailing content.

BraceNestingTooDeep = 15

A glob expression contained brace alternations nested deeper than the parser permits, guarding against pathological patterns whose recursion or expansion would exhaust resources.

PatternTooLong = 16

A glob expression exceeded the maximum length the parser is willing to compile, guarding against pathological inputs that would allocate a multi-megabyte regex source.
