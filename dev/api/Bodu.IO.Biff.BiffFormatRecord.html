Represents a decoded FORMAT record: a number-format index and its format code. The code is a 16-bit-length Unicode string in BIFF8 and an 8-bit-length code-page byte string in BIFF5.

Remarks

The record identifier is Format. The payload is the 16-bit format index followed by the code. Indices below 164 are Excel's built-in formats and are normally not written to the stream; an FormatIndex resolves against these records first and the built-in table otherwise.
