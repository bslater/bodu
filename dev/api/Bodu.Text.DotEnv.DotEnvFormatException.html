Remarks

Raised by the DotEnv reader — and therefore surfaced by DotEnvSerializer while deserializing — when the source text cannot be interpreted as a valid DotEnv document: for example, an invalid key name, a missing assignment, or an unterminated quoted value. The error is signalled through the FormatException hierarchy so callers can catch it alongside other parse failures.

Because DotEnv is a line-oriented format, the exception records its position as a LineNumber and ColumnNumber in addition to the absolute byte Offset. Each is null when the error is not associated with a specific location.
