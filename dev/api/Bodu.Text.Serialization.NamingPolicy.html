    Class NamingPolicy

    Determines how a member's CLR name is translated to the key used in serialized output, exposing the common casing conventions as ready-made policies.

    Remarks

    A naming policy applies only when a member does not carry an explicit PropertyNameAttribute, which always wins.

    Examples
    // A MaxRetryCount property serializes under the key "max_retry_count".
var key = NamingPolicy.SnakeCaseLower.ConvertName("MaxRetryCount");
