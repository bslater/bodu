    Method PadBlock

    PadBlock(ReadOnlySpan<byte>, ulong, Span<byte>)

    Satisfies the PadBlock(ReadOnlySpan<byte>, ulong) contract, but is not used by the Skein implementation.

    Declaration
    protected override int PadBlock(ReadOnlySpan<byte> block, ulong messageLength, Span<byte> destination)
    Parameters
    Type Name Description
    ReadOnlySpan<byte> block

    The final partial block supplied by the base pipeline. Skein does not consume this value here because final block processing is performed by the UBI chaining path.
    ulong messageLength

    The total message length supplied by the base pipeline. Skein does not consume this value here because UBI encodes position and final-block state in the tweak field.
    Span<byte> destination

    The span receiving the padded block or blocks; at least two blocks long.
    Returns
    Type Description
    int

    This method never returns because Skein bypasses the base padding pipeline.
    Overrides
    BlockHashAlgorithm.PadBlock(ReadOnlySpan<byte>, ulong, Span<byte>)
    Exceptions
    Type Condition
    InvalidOperationException

    Always thrown because Skein performs finalization through UBI rather than PadBlock(ReadOnlySpan<byte>, ulong).
