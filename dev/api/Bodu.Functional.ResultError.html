Represents the error carried by a failed Result or Result<T>: a human-readable message, an optional machine-readable code, and an optional originating exception.

Remarks

Create errors with FromMessage(string, string?) or FromException(Exception, string?), or lift a plain message through the implicit conversion from string. default(ResultError) is valid and total: Message returns Empty while Code and Exception are null.

Equality compares Code and Message ordinally and Exception by reference; the hash code is computed from Code and Message only, so two errors that differ solely by exception instance hash identically but compare unequal.
