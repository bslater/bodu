Remarks

This record is the managed counterpart of the COM STATSTG structure: it carries the name, kind, payload size, class identifier, state bits, and time stamps that the directory stores for each entry, without exposing the underlying sector layout.

The CreationTime and LastModifiedTime values are meaningful for storage and root-storage entries; stream entries conventionally record zero, which is surfaced as null.
