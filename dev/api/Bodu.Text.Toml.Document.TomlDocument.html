Examples

// The document owns a flat row store; dispose it (here via 'using') when finished.
// Every element view obtained from it is valid only until the document is disposed.
using TomlDocument document = TomlDocument.Parse("name = \"app\"\nport = 8080\n");
TomlElement root = document.RootElement;

string name = root.GetProperty("name").GetString();   // "app"
long port = root.GetProperty("port").GetInt64();       // 8080

Remarks

A TomlDocument holds the flat row store produced directly by the structural parser, so parsing materializes neither an intermediate node tree nor a token list. Value-type scalars are decoded into the row, while a string scalar is decoded on demand from the UTF-8 source the document retains, so a string is materialized only when read. Every TomlElement, enumerator, and TomlProperty obtained from a document is valid only until the document is disposed.

Call Dispose() when finished to invalidate the document and the TomlElement views taken from it; after disposal, any operation on such an element throws ObjectDisposedException. A parsed document rents its retained source from the shared array pool, so disposal returns that buffer as well as dropping the row store; neglecting to dispose leaks the buffer back to the garbage collector rather than the pool.

The root value of a TOML document is always a table, so for a document produced by Parse(string) or its overloads RootElement always reports Table. A document produced internally over a single value subtree may root any value kind.

Remarks

Disposal is idempotent: calling it more than once has no further effect. A parsed document returns its pooled source buffer to the shared array pool; a subtree view shares a garbage-collected copy and returns nothing. After disposal, every element, enumerator, and property obtained from the document throws ObjectDisposedException.
