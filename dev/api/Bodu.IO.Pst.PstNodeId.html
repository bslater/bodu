Represents a 32-bit node identifier: five type bits in the low positions and a 27-bit index above them (MS-PST §2.2.2.1).

Remarks

A handful of fixed identifiers anchor every file - MessageStore (0x21), NameToIdMap (0x61), and RootFolder (0x122) - and are exposed here as well-known values.
