    Enum AsyncDebouncerExecutionPolicy

    Specifies how an AsyncDebouncer behaves when a debounced run becomes due while a previous callback invocation is still in flight.

    Namespace: Bodu.Threading
    Assembly: Bodu.Core.dll
    Syntax
    public enum AsyncDebouncerExecutionPolicy

    Fields

    Name Description
    QueueOneTrailingRun

    Coalesces overlapping runs into exactly one trailing run: while a callback is in flight, at most one additional run is queued and executed once the in-flight callback completes. This is the default and never overlaps callbacks.
    DropWhileRunning

    Drops the due run: while a callback is in flight, a newly due run is discarded. A subsequent run requires a fresh trigger that becomes due after the in-flight callback completes. Never overlaps callbacks.
    CancelAndRestart

    Cancels the in-flight callback through its token and immediately starts a new callback. Briefly, the canceled callback may still be winding down while the replacement runs.
    AllowOverlap

    Starts the due run concurrently with any in-flight callbacks, allowing callbacks to overlap.
