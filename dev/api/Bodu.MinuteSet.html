Examples

var selected = new MinuteSet(0, 15, 30, 45);
MinuteSet parsed = MinuteSet.Parse("0,15,30,45");

bool due = selected.Contains(DateTime.Now.Minute);
bool same = selected == parsed; // true

Remarks

A MinuteSet holds one bit per minute, so it never allocates, and testing, adding or removing a minute, or combining two sets with |, &, ^ and ~, is a single bitwise operation. Contains(int) answers false for any value outside 0 to 59 rather than throwing, which keeps a membership test against Minute to a comparison and a bit test.

The text form lists the minutes in ascending order, separated by commas, each run of two or more consecutive minutes written as an inclusive range, so "0,15,30,45" selects every quarter hour. The empty set is the empty string. Parse(string) reads any list of values and ranges in that form, in any order, and ToString() writes the canonical one.

ToUInt64() and FromUInt64(ulong) expose the bits directly: bit n selects minute n.

Remarks

Whitespace around the list and around each value is ignored, and an empty or blank string is the empty set. Values are unsigned decimal integers, a range a-b needs a no greater than b, and values may repeat or overlap.
