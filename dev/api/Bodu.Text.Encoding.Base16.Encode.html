    Encode(ReadOnlySpan<byte>, IBufferWriter<char>, BaseFormattingOptions)

    Encodes source as hexadecimal characters into writer, suitable for use in pipelines and other IBufferWriter<T>-based scenarios.

    Declaration
    public static int Encode(ReadOnlySpan<byte> source, IBufferWriter<char> writer, BaseFormattingOptions options = BaseFormattingOptions.None)
    Parameters
    Type Name Description
    ReadOnlySpan<byte> source

    The bytes to encode.
    IBufferWriter<char> writer

    The buffer writer that receives the encoded characters.
    BaseFormattingOptions options

    Formatting options. Only UpperCase is supported on this overload — formatted output (spacing, prefix, line breaks) is not compatible with the writer's contiguous span contract. For decorated output, call Encode(ReadOnlySpan<byte>, BaseFormattingOptions) and write the resulting string explicitly.
    Returns
    Type Description
    int

    The number of characters written to writer.
    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when writer is null.
    ArgumentException

    Thrown when options contains any flag other than UpperCase.

    Encode(ReadOnlySpan<byte>, BaseFormattingOptions)

    Encodes a read-only span of bytes into a formatted hexadecimal string.

    Declaration
    public static string Encode(ReadOnlySpan<byte> bytes, BaseFormattingOptions options = BaseFormattingOptions.None)
    Parameters
    Type Name Description
    ReadOnlySpan<byte> bytes

    The bytes to encode.
    BaseFormattingOptions options

    Formatting options to apply, such as upper case, spacing, prefix, or line breaks.
    Returns
    Type Description
    string

    A Base16 encoded string. When bytes is empty and IncludePrefix is set, the result is the prefix string alone; otherwise the result is Empty.
    Remarks

    Provides the optimal allocation profile when no formatting flags beyond UpperCase are specified. When spacing, prefix, or line break flags are requested, the implementation falls back to a StringBuilder-backed writer.

    Encode(Guid, BaseFormattingOptions)

    Encodes the byte representation of value as a hexadecimal string.

    Declaration
    public static string Encode(Guid value, BaseFormattingOptions options = BaseFormattingOptions.None)
    Parameters
    Type Name Description
    Guid value

    The Guid to encode.
    BaseFormattingOptions options

    Formatting options applied to the hex output (case, prefix, spacing, line breaks).
    Returns
    Type Description
    string

    A Base16 string of the Guid's 16 underlying bytes (mixed-endian, matching TryWriteBytes(Span<byte>)).
    Remarks

    The encoding uses the GUID's native byte layout — the first three fields are little-endian, the fourth is big-endian. This matches ToByteArray() and TryWriteBytes(Span<byte>), so the result of DecodeGuid(ReadOnlySpan<char>, BaseFormatStyles) reconstructs the original Guid exactly.
