    Class RateCachePartitionStrategy

    Decides how a pair's cached rows are split across files by date: a single file for the whole pair, or one file per calendar year, month, or day, or a caller-supplied scheme.

    Remarks

    A strategy maps each rate's Date to a path-safe partition key (the file name stem) and reports the inclusive date range that key spans. The file cache uses the key to route each row to its file and the range to split a recorded coverage window at partition boundaries, so a window that crosses, say, a month boundary is stored as one sub-window per month and re-merged losslessly on read.

    Use the built-in Single, Yearly, Monthly, and Daily strategies, or Custom(Func<DateOnly, string>, Func<DateOnly, (DateOnly Start, DateOnly End)>) to supply your own keying and ranging — for example fortnightly or fiscal-quarter partitions.
