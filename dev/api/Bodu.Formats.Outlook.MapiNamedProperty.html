Remarks

Named properties occupy the tag identifier range at or above 0x8000; the identifier a given name maps to is file-specific, so the durable identity is the (PropertySetId, Id or Name) pair this type carries. Exactly one of Id and Name is set, mirroring the two kinds defined by MS-OXCDATA §2.6.1.
