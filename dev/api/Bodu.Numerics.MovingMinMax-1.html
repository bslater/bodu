    Class MovingMinMax<T>

    Maintains the minimum and maximum of the most recent N samples of a stream, updating in amortized O(1) as each new sample displaces the oldest.

    Remarks

    This is the sliding-window extrema idiom: the window covers the last Capacity samples, Minimum and Maximum always describe exactly those samples, and until the window fills (IsFull) they describe the samples received so far. Both extrema are tracked exactly in T using the classic pair of monotonic deques, so each sample is pushed and popped at most once per deque — amortized O(1) per Add(T) with no per-sample allocation.

    Samples must be finite: NaN and infinite values are rejected by Add(T). For the sum and mean over the same window, pair this type with MovingSum<T>; for whole-stream extrema use RunningStatistics<T>.

    Examples
    var window = new MovingMinMax<int>(3);
window.Add(5);   // window: {5}          Min = 5, Max = 5
window.Add(1);   // window: {5, 1}       Min = 1, Max = 5
window.Add(4);   // window: {5, 1, 4}    Min = 1, Max = 5
window.Add(2);   // window: {1, 4, 2}    Min = 1, Max = 4
