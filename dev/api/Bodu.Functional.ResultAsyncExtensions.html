    Class ResultAsyncExtensions

    Provides Task-based asynchronous companions to the Result<T> and non-generic Result railway combinators.

    Remarks

    Each operation mirrors its synchronous counterpart — MapAsync pairs with Map<TResult>(Func<T, TResult>), BindAsync with Bind<TResult>(Func<T, Result<TResult>>), MatchAsync with Match<TResult>(Func<T, TResult>, Func<ResultError, TResult>), and TapAsync / TapErrorAsync with Tap(Action<T>) and TapError(Action<ResultError>) — so an asynchronous pipeline over Task<Result<T>> composes exactly like its synchronous equivalent, with the error propagating untouched past every combinator.

    Argument validation runs synchronously, so a null source task or delegate faults at the call site rather than on the returned task.

    The combinators accept no CancellationToken: they perform no I/O of their own, so cancellation belongs to the caller's delegates, which can close over their own tokens.
