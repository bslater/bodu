Provides Task-based asynchronous companions to the Result<T> and non-generic Result railway combinators.

Remarks

Each operation mirrors its synchronous counterpart - MapAsync pairs with Map<TResult>(Func<T, TResult>), BindAsync with Bind<TResult>(Func<T, Result<TResult>>), MatchAsync with Match<TResult>(Func<T, TResult>, Func<ResultError, TResult>), and TapAsync / TapErrorAsync with Tap(Action<T>) and TapError(Action<ResultError>) - so an asynchronous pipeline over Task<Result<T>> composes exactly like its synchronous equivalent, with the error propagating untouched past every combinator.

Argument validation runs synchronously, so a null source task or delegate faults at the call site rather than on the returned task.

The combinators accept no CancellationToken: they perform no I/O of their own, so cancellation belongs to the caller's delegates, which can close over their own tokens.

Asynchronously projects the carried value into another result using the specified asynchronous result-returning selector.

public static Task<Result<TResult>> BindAsync<T, TResult>(this Result<T> source, Func<T, Task<Result<TResult>>> selector)

Parameters

source Result<T>

The result to project.

selector Func<T, Task<Result<TResult>>>

The asynchronous result-returning projection applied to the carried value.

Returns

Task<Result<TResult>>

A task that completes with the result produced by the awaited selector when the result represents success; otherwise a failure carrying the original error.

Type Parameters

T

The value type of the source result.

TResult

The value type of the resulting result.

Remarks

The selector is not invoked when the result is a failure. Argument validation runs synchronously, so a null selector faults at the call site rather than on the returned task.

Exceptions

ArgumentNullException

selector is null.
