Bodu.Collections Namespace

Purpose

Bodu.Collections is a namespace root: it holds no types of its own. Its namespaces span two packages:

  • Bodu.Collections.Generic - the specialized generic collections (Bodu.Collections), with the thread-safe variants in Bodu.Collections.Generic.Concurrent (Bodu.Collections.Concurrent) and the collection extension methods in Bodu.Collections.Generic.Extensions (Bodu.Core).
  • Bodu.Collections.Specialized - special-purpose collections such as the packed bit set (Bodu.Collections).
  • Bodu.Collections.Probabilistic - approximate sketches: Bloom filter, count-min sketch, HyperLogLog (Bodu.Collections).
  • Bodu.Collections.Extensions - non-generic enumerable extension methods (Bodu.Core).
