    Class NotableDateDefinition

    Represents a single notable-date concept: its stable identity, presentation metadata, inherited defaults, and one or more calculation rules.

    Remarks

    A concept owns multiple rules so that territory-specific variants — for example a national and a regional rule that merely share a display name — coexist as distinct, independently addressable rules rather than collapsing.
