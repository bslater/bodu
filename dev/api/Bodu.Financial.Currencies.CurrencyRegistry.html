    Class CurrencyRegistry

    Read-only catalogue of CurrencyInfo entries keyed by ISO 4217 alphabetic code. Supports lookup by code and enumeration of every shipped currency.

    Remarks

    The catalogue is populated from the source-generated Bodu.Financial.Currencies.GeneratedCurrencyRegistration list at first access — no runtime reflection scans the assembly. It covers the full active and historic ISO 4217 set; every entry has a corresponding CurrencyCode member.

    Lookups are thread-safe because the backing FrozenDictionary<TKey, TValue> is immutable.
