    Class IniNode

    Represents a node in a mutable INI document tree. An INI document is a two-level object-of-objects: the root IniObject maps global keys to IniValue leaves and section names to section IniObject instances, and each section maps key names to IniValue leaves.

    Remarks

    Unlike the other quartet DOMs, this tree deliberately bears comment trivia so that authoring and round-tripping are faithful: LeadingComments holds the comment lines that precede a node, and each IniObject additionally holds the trailing comment block at the end of its scope. Inline comments are not modeled — the reader dialect keeps everything after the assignment as part of the value, so an emitted inline comment would be re-read as value text.
