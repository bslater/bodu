Remarks

Structurally identical to TomlNotableDateCache but serialized with System.Text.Json: the territory, an Entries array of per-year metadata, and a flat Occurrences array. Malformed content is treated as an empty result, and all file-level resilience is provided by FileNotableDateCacheBase.
