Remarks

The generated factory maps the type's public read/write instance properties in declaration order, honouring PropertyNameAttribute for column names and skipping members annotated with IgnoreAttribute. Scalar values convert with the invariant culture, in the forms the reflection binder of DelimitedSerializer uses, so the two paths write the same text and read it alike: temporal values in their round-trip forms, and null for a nullable member whose field is empty or white space, except a nullable char, which takes only an empty field as null.

The annotated type must be declared partial so the generator can add the factory to it. Passing the generated factory to the DelimitedSerializer factory overloads avoids the reflection binder entirely, making the serialization path trimming- and AOT-safe.
