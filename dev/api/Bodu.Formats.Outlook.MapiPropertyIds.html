    Provides curated well-known MAPI property identifiers (the PidTag* constants of MS-OXPROPS).

    Remarks

    This is a deliberately small subset — the identifiers the Outlook readers' convenience surfaces and common consumer scenarios need. Every property of a message remains reachable through MapiPropertyCollection by raw identifier regardless of whether it is listed here.
