    Method MatchAsync

    MatchAsync<T, TResult>(Task<Option<T>>, Func<T, TResult>, Func<TResult>)

    Asynchronously collapses the awaited option to a single value by invoking the matching branch.

    Declaration
    public static Task<TResult> MatchAsync<T, TResult>(this Task<Option<T>> source, Func<T, TResult> onSome, Func<TResult> onNone)
    Parameters
    Type Name Description
    Task<Option<T>> source

    The task producing the option to collapse. Must not be null.
    Func<T, TResult> onSome

    The projection invoked with the contained value when one is present.
    Func<TResult> onNone

    The factory invoked when no value is present.
    Returns
    Type Description
    Task<TResult>

    A task that completes with the value produced by the invoked branch.
    Type Parameters
    Name Description
    T

    The value type of the source option.
    TResult

    The type produced by both branches.
    Remarks

    Exactly one branch is invoked. Argument validation runs synchronously, so a null argument faults at the call site rather than on the returned task.

    Exceptions
    Type Condition
    ArgumentNullException

    source, onSome, or onNone is null.
