Remarks

The reader is source-order and does not itself resolve duplicate sections/keys or apply case rules — those are document-model concerns. Inline comments are deliberately not recognized: a value retains everything after the assignment to the end of the line, matching the safer configparser dialect and avoiding the classic value ; not-a-comment footgun.
