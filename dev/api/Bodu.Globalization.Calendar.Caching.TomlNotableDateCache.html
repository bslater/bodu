Remarks

Each file records the territory as a top-level key, an array of tables under Entries - one table per cached civil year with its version and computed instant - and an array of tables under Occurrences, one flat table per emitted occurrence carrying its year and version so it associates back to its entry. Dates and instants use TOML's native RFC 3339 forms.

Malformed content is treated as an empty result, and all file-level resilience - including atomic temp-and-move writes and the parse memo - is provided by FileNotableDateCacheBase.
