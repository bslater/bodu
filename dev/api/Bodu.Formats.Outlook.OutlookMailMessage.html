Remarks

Message views are bound to their owning OutlookMailStore session and decode their property context once, on first access. Every property remains reachable through Properties; the conveniences return null when the underlying property is absent.

Gets the message's attachments, in attachment-table order.

public IReadOnlyList<OutlookMailAttachment> Attachments { get; }

Property Value

IReadOnlyList<OutlookMailAttachment>

The attachment views, built once on first access; empty when the message has no attachment table.

Remarks

Each attachment-table row's identifier is the attachment object's subnode identifier; a row that references no attachment subnode is skipped under the tolerant levels.

Exceptions

ObjectDisposedException

The owning session has been disposed.

PstFileException

The container is malformed.

OutlookPstFormatException

Under strict validation, an attachment-table row does not reference a valid attachment object subnode.
