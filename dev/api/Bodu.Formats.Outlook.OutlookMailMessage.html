    Class OutlookMailMessage

    Represents one message of a mail store: its decoded properties with typed conveniences over the well-known scalars.

    Remarks

    Message views are bound to their owning OutlookMailStore session and decode their property context once, on first access. Every property remains reachable through Properties; the conveniences return null when the underlying property is absent.
