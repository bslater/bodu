    Method Map

    Map<TResult>(Func<T, TResult>)

    Projects the contained value into a new option using the specified selector.

    Declaration
    public Option<TResult> Map<TResult>(Func<T, TResult> selector)
    Parameters
    Type Name Description
    Func<T, TResult> selector

    The projection applied to the contained value.
    Returns
    Type Description
    Option<TResult>

    Some(selector(value)) when a value is present and the projection is non-null; otherwise None.
    Type Parameters
    Name Description
    TResult

    The type produced by the selector.
    Remarks

    The selector is not invoked when this option is None. A null projection result maps to None (the lenient lift), so a mapping chain can never produce a present null.

    Examples
    var length = Option<string>.Some("railway").Map(s => s.Length); // Some(7)
var none = Option<string>.None.Map(s => s.Length);              // None — selector not invoked
    Exceptions
    Type Condition
    ArgumentNullException

    selector is null.
