    Method ComputeBlocked

    ComputeBlocked(Stream, int, MerkleTreeDiagnostics?, CancellationToken)

    Computes the root over fixed-size blocks of a stream and returns it together with the ordered leaf hashes, so one pass serves both publishing a root and answering authentication paths.

    Declaration
    public MerkleBlockComputation ComputeBlocked(Stream source, int blockSize, MerkleTreeDiagnostics? diagnostics = null, CancellationToken cancellationToken = default)
    Parameters
    Type Name Description
    Stream source

    The stream to read to its end. Must be readable.
    int blockSize

    The size, in bytes, of each block — the chunk one leaf covers.
    MerkleTreeDiagnostics diagnostics

    The recorder that receives the tree's nodes as they are produced, or null to record nothing.
    CancellationToken cancellationToken

    A token observed between blocks.
    Returns
    Type Description
    MerkleBlockComputation

    The computation's root, input length, block size and leaf hashes.
    Remarks

    The stream is read once, forward only, and never buffered in full. Retaining the leaf hashes costs leafCount × HashLength bytes — 16 KiB for a 512 MiB input at one-mebibyte blocks. When only the root is wanted, prefer ComputeRootOfBlocks(Stream, int, MerkleTreeDiagnostics?, CancellationToken), which holds a logarithmic number of hashes instead.

    A zero-length stream yields zero leaves and the empty tree's root, not one empty leaf. A final short block is hashed at its actual length and never padded.

    Exceptions
    Type Condition
    ArgumentNullException

    source is null.
    ArgumentOutOfRangeException

    blockSize is less than or equal to zero.
    OperationCanceledException

    cancellationToken was cancelled.

    ComputeBlocked(ReadOnlyMemory<byte>, int, MerkleTreeDiagnostics?, CancellationToken)

    Computes the root over fixed-size blocks of a buffer already in memory, together with its leaf hashes.

    Declaration
    public MerkleBlockComputation ComputeBlocked(ReadOnlyMemory<byte> source, int blockSize, MerkleTreeDiagnostics? diagnostics = null, CancellationToken cancellationToken = default)
    Parameters
    Type Name Description
    ReadOnlyMemory<byte> source

    The bytes to divide into blocks.
    int blockSize

    The size, in bytes, of each block.
    MerkleTreeDiagnostics diagnostics

    The recorder that receives the tree's nodes as they are produced, or null to record nothing.
    CancellationToken cancellationToken

    A token observed while hashing.
    Returns
    Type Description
    MerkleBlockComputation

    The computation's root, input length, block size and leaf hashes.
    Remarks

    The overload to prefer on a parallel instance when the bytes are already in memory: every block is sliced and hashed inside its own worker, so nothing is copied and the whole per-block cost parallelizes.
