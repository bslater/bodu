    Remarks

    This record is the runtime counterpart of an ICurrency tag type. The runtime-tagged Money and the MoneyBag aggregate operate against CurrencyRegistry entries of this shape so they can handle currencies the consumer learns about at runtime (for example, from a deserialised JSON payload).

    Properties

    Name Description
    AlternativeSymbols

    Gets alternative symbols that may also denote the currency.
    CashRoundingIncrement

    The smallest physical cash denomination in the major unit, or 0m when no special cash rounding is required beyond MinorUnits.
    DemonetizedOn

    The date the currency was withdrawn from circulation, when known.
    EnglishName

    The currency's English-language name in singular Title Case (for example, "United States Dollar"), or an empty string when no name is supplied.
    InternationalSymbol

    Gets the currency's internationally disambiguated symbol (for example, "US$" or "R$"), or an empty string when none is supplied.
    IsHistoric

    Whether the currency has been demonetized.
    IsoCode

    The ISO 4217 three-letter alphabetic code.
    MinorUnits

    The number of fractional digits in the currency's minor unit.
    NativeName

    Gets the currency's name in its primary native language, or an empty string when none is supplied.
    NumericCode

    The ISO 4217 three-digit numeric code (for example, 840 for USD, 36 for AUD), or 0 when the currency is custom or the numeric code is unknown.
    RegionCodes

    Gets the ISO 3166 region codes in which the currency is used.
    SuccessorIsoCode

    The ISO 4217 code of the currency that replaced this one, when defined.
    Symbol

    Gets the currency's primary symbol (for example, "$" or "€"), or an empty string when none is supplied.
