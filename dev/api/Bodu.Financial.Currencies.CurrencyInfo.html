Remarks

This record is the runtime counterpart of an ICurrency tag type. The runtime-tagged Money and the MoneyBag aggregate operate against CurrencyRegistry entries of this shape so they can handle currencies the consumer learns about at runtime (for example, from a deserialised JSON payload).

The smallest physical cash denomination in the major unit, or 0m when no special cash rounding is required beyond MinorUnits.

Whether the currency has been demonetized.

DemonetizedOn DateOnly?

The date the currency was withdrawn from circulation, when known.

The currency's English-language name in singular Title Case (for example, "United States Dollar"), or an empty string when no name is supplied.

NumericCode int

The ISO 4217 three-digit numeric code (for example, 840 for USD, 36 for AUD), or 0 when the currency is custom or the numeric code is unknown.
