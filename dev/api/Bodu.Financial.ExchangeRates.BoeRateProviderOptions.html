Remarks

This type derives from WebRateProviderOptions, which supplies the endpoint base address, the HTTP contract (timeout, user agent and response-size cap), the synchronous-access, look-back and refresh behavior, the advertised history, the currency-alias map, and the per-concern log levels. The constructor points BaseAddress at the Interactive Statistical Database (IADB), identifies the requests with a Bodu user agent, sets a ten-day DefaultLookback, and floors the advertised history at 2 January 1975. The members declared here are Bank of England-specific: the Series catalogue, the IADB QueryPath, and the on-disk cache settings.

A range request is composed from BaseAddress, QueryPath, the catalogue's series codes, and the inclusive date range. The inherited RefreshInterval governs both the in-memory ranges and the on-disk cache: a cached range response older than the interval is downloaded again, and in memory a loaded range keeps for good every day before the day it was downloaded and every later day it returned a rate for, while its other days are downloaded again by a request that reaches them once the interval has passed.

The IADB names series, not currencies, so CurrencyAliases applies to the quote label of each BoeSeries in the catalogue: a label found among the keys is replaced by its value, which must be the ISO 4217 code the provider serves the series under. Every member carries a working default, so the options bind cleanly through Microsoft.Extensions.Options; the dependency-injection registration binds this type from configuration and a configure delegate.

Remarks

The IADB daily spot series (XUDL*) begin on 2 January 1975 for the longest-running currencies; some series start later (the euro series begins 4 January 1999, with the launch of the euro). The advertised history is advisory - it bounds the earliest date worth requesting for the default Series catalogue, not a per-series guarantee - so narrow HistoryAvailability when the catalogue is restricted to later-inception series.
