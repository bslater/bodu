Remarks

default(QuotedPrintableEncodingOptions) behaves as Binary with a 76-character line limit and a CRLF newline: a zero MaxLineLength is normalized to 76 and a null NewLine to "\r\n". A zero line length therefore means the RFC default, not unlimited output.

Remarks

Only "\r\n" and "\n" are accepted. CRLF is the MIME canonical line ending; "\n" is a non-canonical convenience profile for local text processing and should not be used for MIME transport. Output using "\n" round-trips only when decoded with AllowBareLineFeed.
