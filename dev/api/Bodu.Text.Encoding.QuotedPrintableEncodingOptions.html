    Struct QuotedPrintableEncodingOptions

    Configures how QuotedPrintable produces Quoted-Printable output: the line-break treatment, the soft line-wrap column, and the newline sequence.

    Remarks

    default(QuotedPrintableEncodingOptions) behaves as Binary with a 76-character line limit and a CRLF newline: a zero MaxLineLength is normalized to 76 and a null NewLine to "\r\n". A zero line length therefore means the RFC default, not unlimited output.
