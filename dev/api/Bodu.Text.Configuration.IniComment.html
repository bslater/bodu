Remarks

Each IniComment records the prefix character that introduced the line (either '#' or ';'), the trimmed text, and the 1-based source line at which it appeared.

Pending comments are attached to the next entry or section in source order: comments authored before a property line appear in LeadingComments; comments authored before a section header appear in LeadingComments.
