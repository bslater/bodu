Represents one attachment of an OutlookMailMessage: a typed view over the attachment object's decoded properties, with access to the by-value payload or the nested attached message.

Remarks

The conveniences return null when the underlying property is absent; every attachment property remains reachable through Properties. Content access is method-specific: OpenContentStream() serves a by-value payload and OpenMessage() serves an embedded message — each throws NotSupportedException for the other method kinds.

Remarks

A by-value payload (PidTagAttachDataBinary) larger than MaxInlineAttachmentBytes is not decoded: the property is present with a null value and the content is served by OpenContentStream() directly from the store.

Remarks

Methods

OpenContentStream()

Opens the by-value content payload as a read-only stream.

public Stream OpenContentStream()

Returns

Stream

The content stream; dispose it when reading is complete.

Remarks

A payload decoded inline (at or below MaxInlineAttachmentBytes) is served from the decoded bytes without copying; a larger payload is streamed from the store block by block and is never held in memory in full. The stream is bound to the owning session.

Exceptions

NotSupportedException

The attachment's Method is EmbeddedMessage or Ole — the payload is an object, not a byte stream.

OutlookPstFormatException

The by-value content payload is missing.

OpenMessage()

Opens the nested attached message.

public OutlookMailMessage OpenMessage()

Returns

OutlookMailMessage

The nested message view. It is bound to the owning session and becomes unusable when the session is disposed.

Remarks

The nested message is the message-typed subnode of the attachment object (MS-PST §2.4.6.3); its code-page strings inherit the attachment's encoding.

Exceptions

NotSupportedException

The attachment's Method is not EmbeddedMessage.

OutlookPstFormatException

The attachment carries no nested message subnode, or the nested message would sit deeper than MaxEmbeddedMessageDepth.
