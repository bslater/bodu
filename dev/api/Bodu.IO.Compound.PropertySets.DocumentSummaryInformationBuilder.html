    Class DocumentSummaryInformationBuilder

    Authors a document-summary-information property set, producing an OlePropertySet that can be embedded as the \x05DocumentSummaryInformation stream of a compound file, including an optional user-defined section of custom named properties.

    Remarks

    Each property is optional; only the properties that are set are written. The result reads back through DocumentSummaryInformation.
