    Class MapiProperty

    Represents a single decoded MAPI property: a MapiPropertyTag paired with its CLR value.

    Remarks

    The value's CLR type follows the tag's MapiPropertyType: string for Unicode and String8, short / int / long for the integer codes, float / double for the floating-point codes, decimal for Currency, bool for Boolean, DateTimeOffset for SystemTime, Guid for Guid, and byte[] for Binary. A multi-valued property carries the corresponding array type.

    A null value is permitted — it represents a property whose payload is absent or, as for Object, not representable inline.
