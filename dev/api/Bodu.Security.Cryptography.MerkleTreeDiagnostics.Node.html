Parameters

Level int

The zero-based level of this node within the tree. Level 0 contains leaf nodes derived directly from input entries or blocks; higher levels contain internal nodes derived by combining groups of child hashes.

Index long

The zero-based position of this node within its level.

IsLeaf bool

true if this node is a leaf; false if it is an internal node. Leaf nodes have no child hashes.

Hash byte[]

The hash value computed for this node.

ChildHashes IReadOnlyList<byte[]>

The child hash values whose concatenation was hashed to produce Hash. Empty for leaf nodes.
