    Method LastIndexOf

    LastIndexOf<TSource>(IList<TSource>, Func<TSource, bool>)

    Returns the zero-based index of the last element in the entire IList<T> that satisfies the specified predicate, searching backwards from the end of the list.

    Declaration

    Parameters
    Type Name Description
    IList<TSource> list

    The list to search. Must not be null.
    Func<TSource, bool> predicate

    A function that defines the conditions of the element to search for.
    Returns
    Type Description
    int

    The zero-based index of the last matching element, or -1 if no element satisfies predicate (including the empty-list case).

    LastIndexOf<TSource>(IList<TSource>, Func<TSource, bool>, int, int)

    Returns the zero-based index of the last element that satisfies the specified predicate within the range of elements in the IList<T> that contains the specified number of elements and ends at the specified index.

    Declaration
    public static int LastIndexOf<TSource>(this IList<TSource> list, Func<TSource, bool> predicate, int startIndex, int count)
    Parameters
    Type Name Description
    IList<TSource> list

    The list to search. Must not be null.
    Func<TSource, bool> predicate

    A function that defines the conditions of the element to search for.
    int startIndex

    The zero-based starting index of the backward search. For a non-empty list this must be in the range [0, Count - 1]; for an empty list the only valid value is -1.
    int count

    The number of elements to examine. Must be non-negative and must not extend before the start of the list relative to startIndex.
    Returns
    Type Description
    int

    The zero-based index of the last matching element in the range, or -1 if no element satisfies predicate.
    Type Parameters
    Name Description
    TSource

    The type of the elements in the list.
    Exceptions
    Type Condition
    ArgumentNullException

    list or predicate is null.
    ArgumentOutOfRangeException

    startIndex falls outside the valid range for the current list size, or count is negative, or the range described by startIndex and count extends past the beginning of the list.
