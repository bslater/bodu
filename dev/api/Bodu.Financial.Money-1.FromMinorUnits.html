    Method FromMinorUnits

    FromMinorUnits(long)

    Creates a Money<TCurrency> from an exact integer count of minor units (cents, yen, fils, etc.).

    Declaration
    public static Money<TCurrency> FromMinorUnits(long minorUnits)
    Parameters
    Type Name Description
    long minorUnits

    The number of minor units in the major unit's smallest denomination.
    Returns
    Type Description
    Money<TCurrency>

    The corresponding monetary amount.
    Remarks

    Ledger storage and wire formats often persist money as integer minor units. FromMinorUnits(long) is the canonical bridge from that representation. For example, Money<USD>.FromMinorUnits(1999) is $19.99; Money<JPY>.FromMinorUnits(1234) is ¥1,234; Money<BHD>.FromMinorUnits(12345) is 12.345 BHD.
