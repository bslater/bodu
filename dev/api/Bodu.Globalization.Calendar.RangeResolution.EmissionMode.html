Controls which occurrences an adjustment policy emits when its trigger is active: the originally calculated (actual) occurrence, the adjusted (observed) occurrence, both, or neither.

Fields

ActualOnly = 0

Emit only the originally calculated occurrence; the adjustment does not change which date is reported.

ObservedOnly = 1

Suppress the calculated occurrence and emit only the adjusted (observed) occurrence.

ActualAndObserved = 2

Emit both the calculated occurrence and the adjusted (observed) occurrence.

[Obsolete("Use ActualAndObserved; ObservedAsAdditional behaves identically and is normalized to it.")] ObservedAsAdditional = 3

Emit the calculated occurrence normally and emit the adjusted occurrence as an additional observance.

This value behaves identically to ActualAndObserved and is normalized to it when an AdjustmentPolicy is constructed. It is retained for document and binary compatibility only.

Suppress = 4

Emit neither occurrence when the adjustment applies.

Remarks

The emission mode makes observed-date behaviour explicit and query-width independent: a single-day query and a range query that both span the relevant dates return the same actual-versus-observed answer because inclusion is decided by the emitted occurrence, not by the query shape.
