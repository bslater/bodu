    Method RoundToMoney

    RoundToMoney(MonetaryContext?)

    Materialises this high-precision amount as a settlement Money, rounding according to context.

    Declaration
    public Money RoundToMoney(MonetaryContext? context = null)
    Parameters
    Type Name Description
    MonetaryContext context

    The monetary context governing rounding and scale; null selects Default.
    Returns
    Type Description
    Money

    The settled Money in this value's currency.
    Remarks

    The scale is resolved from context: CurrencyMinorUnits rounds to the registered currency's minor units and Unrounded falls back to that same natural scale because a settlement value must carry a concrete precision. When the resolved scale differs from the registered minor units (or the currency is unregistered) the result carries the resolved scale explicitly.

    Examples
    using Bodu.Financial;

var calc = new CalculatedMoney(10m, CurrencyCode.USD).Divide(3m);   // 3.3333... USD, unrounded

Money defaultRule = calc.RoundToMoney();                            // 3.33 USD (banker's rounding)
Money awayFromZero = calc.RoundToMoney(MidpointRounding.AwayFromZero);
    Exceptions
    Type Condition
    InvalidOperationException

    This value carries no ISO code (default-initialised).
    ArgumentException

    context is invalid.
    ArgumentOutOfRangeException

    context carries an out-of-range policy.
