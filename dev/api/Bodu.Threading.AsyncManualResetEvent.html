Examples

private readonly AsyncManualResetEvent _ready = new();

// Many callers await the same gate; one Set releases all of them.
async Task UseServiceAsync()
{
    await _ready.WaitAsync();
    CallService();
}

void OnInitialized() => _ready.Set();    // open the gate for everyone
void OnConnectionLost() => _ready.Reset(); // later waiters block again

Remarks

AsyncManualResetEvent is the asynchronous analogue of ManualResetEventSlim. Callers await WaitAsync(); a call to Set() completes all outstanding waits and leaves the event signaled so that subsequent waits complete immediately. Reset() returns the event to the unsignaled state.

The event is backed by a single shared TaskCompletionSource<TResult> created with RunContinuationsAsynchronously, so the thread that calls Set() is never hijacked to run waiter continuations inline.

Cancellation follows the package-wide rule: when the event is already set, WaitAsync() completes immediately even if the supplied token is already canceled. A Set() that races with a Reset() is observed consistently: a waiter that captured the completed task before the reset still completes, while a wait that begins after the reset observes the new unsignaled state.
