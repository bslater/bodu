Remarks

A pair is a strongly typed key intended for use in dictionaries and lookup tables. Compared to a raw tuple of codes, it centralises validation and makes the directional meaning of each currency obvious at the call site.

Remarks

Because CurrencyPair is a value type, default(CurrencyPair) bypasses the validating constructor and leaves both currencies None. Public boundaries that accept an CurrencyPair should reject any instance whose IsValid property is false.
