Remarks

The RBA splits its historical daily exchange-rate data into a small set of multi-year files plus an open-ended "current" file. Each era maps to one downloadable .xls file and the inclusive date range it covers. The default catalogue is exposed through Default and can be overridden via the provider options if the RBA changes its file names.
