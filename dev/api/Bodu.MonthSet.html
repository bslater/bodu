Examples

var selected = new MonthSet(1, 4, 7, 10);
MonthSet parsed = MonthSet.Parse("1,4,7,10");

bool due = selected.Contains(DateTime.Today.Month);
bool same = selected == parsed; // true

Remarks

A MonthSet holds one bit per month, so it never allocates, and testing, adding or removing a month, or combining two sets with |, &, ^ and ~, is a single bitwise operation. Contains(int) answers false for any value outside 1 to 12 rather than throwing, which keeps a membership test against Month to a comparison and a bit test.

The text form lists the months in ascending order, separated by commas, each run of two or more consecutive months written as an inclusive range, so "1,4,7,10" selects the first month of each quarter. The empty set is the empty string. Parse(string) reads any list of values and ranges in that form, in any order, and ToString() writes the canonical one. ToString(string?) also writes every month without ranges, a binary form with one character per month, or a letter mask of the months' initials, such as "JFM________D", and Parse(string) and ParseExact(string, string) read them back. TryFormat(Span<char>, out int, ReadOnlySpan<char>, IFormatProvider?) writes the same text into a span of characters, its other overload into a span of UTF-8 bytes, and the span and UTF-8 overloads of Parse, TryParse, ParseExact and TryParseExact read it.

ToUInt64() and FromUInt64(ulong) expose the bits directly: bit n selects month 1 + n.

Remarks

A text of exactly 12 characters, each 0 or 1, is the binary form, month 1 first. A text of 12 characters, each a month's initial in its place or a placeholder, is the letter mask, January first, such as "JFM________D": the initials are read in either case, and the placeholder may be _, -, * or a space, the same one throughout. Any other text is a comma-separated list of months and inclusive ranges: whitespace around the list and around each value is ignored, an empty or blank string is the empty set, values are unsigned decimal integers, a range a-b needs a no greater than b, and values may repeat or overlap.

The forms are tested in that order, and the binary form and the letter mask read the text as given, so text made only of 0 and 1 is a list only when it is not 12 characters long, and a mask with whitespace around it is not a mask. ParseExact(string, string) with the "G" format reads any text as a list.

Exceptions

ArgumentNullException

Thrown when s is null.

FormatException

Thrown when s is not the binary form, the letter mask, or a list of values and ranges from 1 to 12.

FormatText
G, the default The months in ascending order, separated by commas, each run of two or more consecutive months as an inclusive range: "1-3,12".
