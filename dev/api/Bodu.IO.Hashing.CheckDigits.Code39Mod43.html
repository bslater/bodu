    Class Code39Mod43

    Computes the check character of a Code 39 (also known as Code 3 of 9) symbol string using the modulo 43 scheme. This class cannot be inherited.

    Remarks

    The Code 39 modulo-43 check character is the optional self-checking symbol defined by the Code 39 barcode symbology. Each body character is mapped to its ordinal value in the forty-three-symbol Code 39 alphabet — '0'– '9' as 0–9, 'A'–'Z' as 10–35, and the seven symbols '-', '.', space, '$', '/', '+', and '%' as 36–42. The values are summed, reduced modulo 43, and the result is mapped back to the alphabet to produce a single trailing check character.

    The scheme detects all single-character substitution errors. Because the underlying combiner is a commutative sum, it does not detect every adjacent transposition; payloads that require transposition coverage should prefer Verhoeff or Damm over a decimal body.

    Worked example. For the body "CODE39" the character values are 12, 24, 13, 14, 3, and 9, summing to 75; 75 mod 43 is 32, which maps to 'W'. The resulting string "CODE39W" is therefore valid.

    important

    This algorithm is not cryptographically secure and should not be used for password hashing, digital signatures, or integrity validation in security-sensitive applications.

    Examples
    // Single-call computation against an in-memory body.
char check = Code39Mod43.Compute("CODE39");   // 'W'

// Full-sequence validation.
bool ok = Code39Mod43.IsValid("CODE39W");      // true

// Streaming use when the body is built up incrementally.
var algo = new Code39Mod43();
algo.Append("CODE39");
char d = algo.GetCurrentCheckDigit();          // 'W'
