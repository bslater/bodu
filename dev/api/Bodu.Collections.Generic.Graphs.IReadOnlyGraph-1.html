IReadOnlyGraph{T}.cs

Defines a read-only view over a vertex-and-edge graph: the topology queries the graph algorithms depend on, independent of how the graph is stored.

public interface IReadOnlyGraph<TVertex> where TVertex : notnull

Remarks

Algorithms that do not need edge weights (traversal, topological sort, connectivity) accept this interface so they can run over any graph representation, not only the default Graph<T> adjacency-list implementation.
