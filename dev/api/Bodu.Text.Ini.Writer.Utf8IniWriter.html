Provides a forward-only writer that emits INI text as UTF-8 bytes to an IBufferWriter<T> or a Stream. The writer is a ref struct.

Remarks

INI is line-oriented, so the writer emits progressively: WriteSectionHeader(string) produces a [name] line, WritePropertyName(string) followed by WriteString(string) produces one key=value line, and WriteComment(string) produces one comment line per line of its text.

The writer writes only text that Utf8IniReader reads back unchanged, and throws ArgumentException for the following:

  • a value containing a line break, which a key=value line cannot hold, or beginning or ending with a space or a tab, which the reader trims;
  • a key that is empty, begins or ends with a space or a tab, contains = or a line break, or begins with [, ; or #, which the reader would read as another key, a section header or a comment;
  • a section name that is empty, begins or ends with a space or a tab, contains a line break, or holds a ] that a ; or # follows after optional spaces and tabs, where the reader would end the name;
  • a key or a section name that begins with U+FEFF, which the reader skips as a byte order mark at the start of a document, refused wherever the name is written so that the rule does not depend on position.

Remarks

A carriage return, a line feed, or a carriage return followed by a line feed ends a line of the text, as it ends a line for Utf8IniReader, so each line reads back as a comment of its own; an empty line becomes an empty comment line.

WritePropertyName(string)

Writes a key name, followed by the = assignment. Call WriteString(string) next to write the value.

public void WritePropertyName(string name)

Parameters

name string

The key name.

Remarks

A key beginning with # is refused even though a reader may disallow hash comments, because the writer cannot know the options its output will be read with. A key beginning with U+FEFF is refused wherever it is written, although the reader skips U+FEFF only at the start of a document, where it is a byte order mark, so that the rule does not depend on position.

Exceptions

ArgumentNullException

Thrown when name is null.

ArgumentException

Thrown when name is empty, begins or ends with a space or a tab, contains =, a carriage return or a line feed, or begins with [, ; or #, since the reader would not read it back as this key, or when it begins with U+FEFF.

WriteSectionHeader(string)

Writes a section header line ([name]).

public void WriteSectionHeader(string name)

Parameters

name string

The section name.

Remarks

A name may hold any other ]: the reader ends a section name at the first ] that only whitespace or a comment follows, so foo]bar is written as [foo]bar] and read back unchanged. A # after a ] is refused even though a reader may disallow hash comments, because the writer cannot know the options its output will be read with. A name beginning with U+FEFF is refused, as a key beginning with it is, even though the reader would read it back unchanged, so that keys and section names follow one rule wherever they are written.

Exceptions

ArgumentNullException

Thrown when name is null.

ArgumentException

Thrown when name is empty, begins or ends with a space or a tab, contains a carriage return or a line feed, or holds a ] that a ; or # follows after optional spaces and tabs, since the reader would not read it back as this name, or when it begins with U+FEFF.
