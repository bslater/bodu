Provides a forward-only writer that emits INI text as UTF-8 bytes to an IBufferWriter<T> or a Stream. The writer is a ref struct.

Remarks

INI is line-oriented, so the writer emits progressively: WriteSectionHeader(string) produces a [name] line, WritePropertyName(string) followed by WriteString(string) produces one key=value line, and WriteComment(string) produces one comment line.
