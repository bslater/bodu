    Method TryCreateEncryptor

    TryCreateEncryptor(TweakableSymmetricAlgorithm, out ICryptoTransform?)

    Attempts to create an encryptor using the current Key, IV, and Tweak values of the algorithm.

    Declaration
    public static bool TryCreateEncryptor(this TweakableSymmetricAlgorithm algorithm, out ICryptoTransform? transform)
    Parameters
    Type Name Description
    TweakableSymmetricAlgorithm algorithm

    The tweakable symmetric algorithm to use for encryption. Must not be null.
    ICryptoTransform transform

    When this method returns, contains the created ICryptoTransform if the operation succeeded; otherwise, null.
    Returns
    Type Description
    bool

    true if the encryptor was successfully created; otherwise, false.
    Remarks

    This method wraps CreateEncryptor() in a try/catch block, returning false if the operation fails due to an invalid or uninitialized key, IV, or tweak.

    Use this overload when the algorithm has already been fully configured. To supply keying material explicitly, use TryCreateEncryptor(TweakableSymmetricAlgorithm, byte[], byte[], byte[], out ICryptoTransform?) .

    Exceptions
    Type Condition
    ArgumentNullException

    Thrown if algorithm is null.

    Parameters
    Type Name Description

    The tweakable symmetric algorithm to use for encryption. Must not be null.
    byte[] key

    The encryption key.
    byte[] iv

    When this method returns, contains the created ICryptoTransform if the operation succeeded; otherwise, null.
    Returns
    Type Description
    bool

    Remarks

    This method wraps CreateEncryptor(byte[], byte[]?, byte[]) in a try/catch block, returning false if the operation fails due to an invalid key, IV, or tweak. Use this overload when all keying material must be supplied explicitly.

    Exceptions
    Type Condition
    ArgumentNullException
