Fields

StrictIso = 0

Accept only the canonical "<ISO> <amount>" or "<amount> <ISO>" forms with a registered, uppercase ISO code. This is the default and matches the IParsable<TSelf> surface.

CultureAware = 1

Accept user-facing input, resolving a currency symbol through the configured lookup when no ISO code is present.

LenientImport = 2

Accept loosely formatted import data: surrounding white space is trimmed and a lower-case ISO code is normalised to upper case before resolution.

RoundTripOnly = 3

Accept only the invariant round-trip form produced by the "R" format specifier.
