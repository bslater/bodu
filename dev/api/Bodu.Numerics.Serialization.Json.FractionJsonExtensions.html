    Class FractionJsonExtensions

    Convenience JSON helpers for Fraction<T> that serialize through the Bodu.Numerics converters under a chosen NumericsJsonPolicy.

    Remarks

    These helpers moved here from the core library so that Bodu.Numerics takes no dependency on System.Text.Json. Each call configures a fresh JsonSerializerOptions and registers the numeric converters; for repeated serialization prefer building one JsonSerializerOptions with AddNumericsJsonConverters(JsonSerializerOptions, NumericsJsonPolicy) and reusing it.
