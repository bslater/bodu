    Enum RecurrenceFrequency

    Identifies the base period at which a RecurrenceRule repeats, corresponding to the RFC 5545 FREQ rule part.

    Namespace: Bodu.Globalization.Recurrence
    Assembly: Bodu.Globalization.Recurrence.dll
    Syntax
    public enum RecurrenceFrequency
    Remarks

    The frequency sets the unit that Interval multiplies and that the BY rule parts refine. For example, a Weekly rule with an interval of two and a BYDAY of Monday repeats on Monday of every second week.

    The sub-daily frequencies Secondly, Minutely, and Hourly are recognized by the parser so that a rule round-trips through ToString(), but occurrence enumeration for them is a planned follow-on and currently throws NotSupportedException.

    Fields

    Name Description
    Secondly

    The rule repeats every second (FREQ=SECONDLY). Enumeration is not yet supported.
    Minutely

    The rule repeats every minute (FREQ=MINUTELY). Enumeration is not yet supported.
    Hourly

    The rule repeats every hour (FREQ=HOURLY). Enumeration is not yet supported.
    Daily

    The rule repeats every day (FREQ=DAILY).
    Weekly

    The rule repeats every week (FREQ=WEEKLY).
    Monthly

    The rule repeats every month (FREQ=MONTHLY).
    Yearly

    The rule repeats every year (FREQ=YEARLY).
