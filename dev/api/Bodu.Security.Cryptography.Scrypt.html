    Class Scrypt

    Computes the scrypt sequential memory-hard password-hashing and key-derivation function defined by RFC 7914. This class cannot be inherited.

    Remarks

    scrypt derives a key from a password and salt while deliberately requiring a large amount of memory, raising the cost of large-scale custom-hardware attacks. An instance binds a set of cost ScryptParameters once, then derives keys or PHC password hashes. The static one-shot methods are provided for convenience.

    This implementation is not independently audited and offers best-effort, not guaranteed, side-channel resistance.
