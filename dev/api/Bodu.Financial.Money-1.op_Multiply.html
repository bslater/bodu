    operator *(Money<TCurrency>, decimal)

    Multiplies a monetary value by a scalar, rounding the result to the currency's minor-unit precision using banker's rounding (ToEven).

    The product, rounded to TCurrency.MinorUnits using banker's rounding.
    Remarks

    Every scalar multiplication rounds at the call site, so a chain of multiplications can accumulate rounding error. For chains where the intermediate precision matters (compound interest, tax stacking, rate-conversion percentages), perform the calculation through ToFraction() and snap to Money<TCurrency> only once, at the end, via FromFraction(Fraction<BigInteger>, MidpointRounding) or the MultiplyExact(Fraction<BigInteger>, MidpointRounding) shortcut. To control the rounding rule on a single scalar multiplication, use Multiply(decimal, MidpointRounding) in place of the operator.
