    BiffRowRecord(int, int, int, ushort, ushort, ushort)

    Represents a decoded ROW record: a row's used column extent, height, option flags, and default format.

    Declaration
    public BiffRowRecord(int Row, int FirstColumn, int LastColumnExclusive, ushort HeightField, ushort Options, ushort XfField)
    Parameters
    Type Name Description
    int Row

    The zero-based row index.
    int FirstColumn

    The zero-based index of the first defined cell in the row.
    int LastColumnExclusive

    One past the zero-based index of the last defined cell in the row.
    ushort HeightField

    The raw miyRw field: the height in twips in its low 15 bits.
    ushort Options

    The raw option flags (grbit).
    ushort XfField

    The raw format field: the extended-format index in its low 12 bits.
    Remarks

    The record identifier is Row. The payload is sixteen bytes in both versions; the two reserved words at offsets 8 through 11 are not interpreted. The derived properties mask the raw fields: Height, HasCustomHeight, IsHidden, OutlineLevel, HasFormat, and XfIndex.
