    Class PstNode

    Represents one node of the node database: raw access to its data payload and its subnode tree.

    Remarks

    A node's payload is assembled from its data tree on demand and materialized in memory; the multi-block trees the format uses for large payloads are flattened transparently. Subnodes form the node's private namespace — a message node, for example, keeps its recipient and attachment tables there.
