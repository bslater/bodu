    Performs the RFC 5869 expand stage, stretching pseudoRandomKey into outputLength bytes of output keying material.

    Declaration

    Parameters
    Type Name Description
    HashAlgorithmName hashAlgorithm

    The HMAC hash algorithm to use.
    ReadOnlySpan<byte> pseudoRandomKey

    The pseudorandom key produced by Extract(HashAlgorithmName, ReadOnlySpan<byte>, ReadOnlySpan<byte>).
    int outputLength

    The number of bytes to produce.
    ReadOnlySpan<byte> info

    The optional context and application-specific information.
    Returns
    Type Description
    byte[]

    The output keying material, outputLength bytes long.
    Exceptions
    Type Condition
    ArgumentException
