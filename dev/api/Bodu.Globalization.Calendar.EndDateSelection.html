Fields

FirstOnOrAfterStart = 0

Selects the earliest end anchor on or after the start anchor.

FirstAfterStart = 1

Selects the earliest end anchor strictly after the start anchor.

Remarks

The end strategy is evaluated for the start anchor's civil year and, when no acceptable candidate exists, the following civil year; the earliest candidate satisfying this rule is chosen. This lets a December start strategy and a January end strategy form one cross-year occurrence without an explicit year offset.
