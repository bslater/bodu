Remarks

Instances are immutable once constructed: every property is init-only. Construct a customised instance with an object initialiser, or use Default for the standard configuration.

The same options object is consumed by every rich casing overload - ToCamelCase(string, WordCasingOptions), ToPascalCase(string, WordCasingOptions), ToSnakeCase(string, WordCasingOptions), ToKebabCase(string, WordCasingOptions), ToTrainCase(string, WordCasingOptions), ToConstantCase(string, WordCasingOptions), ToDotCase(string, WordCasingOptions), ToTitleCase(string, WordCasingOptions), and ToSentenceCase(string, WordCasingOptions) - so a single configuration can drive an entire formatting pipeline consistently.

PreserveAcronyms

Gets a value indicating whether all-uppercase tokens and known acronyms keep their acronym spelling in the converters that consult this flag.

public bool PreserveAcronyms { get; init; }

Property Value

bool

Defaults to true.

Remarks

Only ToTitleCase(string, WordCasingOptions) and ToSentenceCase(string, WordCasingOptions) read this flag. The tokeniser used by the other case converters (camel, Pascal, snake, kebab, train, constant, dot) canonicalises tokens that match a Acronyms entry unconditionally, so those converters render known acronyms in their catalogue spelling regardless of this setting.
