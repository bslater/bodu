Provides extension methods for adding a read-only TOML configuration source to an IConfigurationBuilder, mirroring the AddJsonFile / AddJsonStream shape.

Examples

builder.Configuration.AddTomlFile("appsettings.toml", optional: true);

using var stream = new MemoryStream(Encoding.UTF8.GetBytes("[logging]\nlevel = \"Debug\""));
builder.Configuration.AddTomlStream(stream);

Remarks

The resulting provider is read-once and read-only - it attaches no reload-on-change machinery and rejects mutation through IConfigurationProvider, because TomlConfigurationProvider exposes no mutation surface.
