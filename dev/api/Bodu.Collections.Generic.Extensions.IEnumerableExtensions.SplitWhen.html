    Method SplitWhen

    SplitWhen<TSource>(IEnumerable<TSource>, Func<TSource, TSource, bool>)

    Splits the source sequence into consecutive chunks, starting a new chunk whenever a boundary predicate over an adjacent pair of elements returns true.

    Declaration
    public static IEnumerable<IReadOnlyList<TSource>> SplitWhen<TSource>(this IEnumerable<TSource> source, Func<TSource, TSource, bool> shouldSplit)
    Parameters
    Type Name Description
    IEnumerable<TSource> source

    The source sequence to split.
    Func<TSource, TSource, bool> shouldSplit

    A predicate applied to each adjacent pair, receiving the previous and current elements. When it returns true, the current element starts a new chunk.
    Returns
    Type Description
    IEnumerable<IReadOnlyList<TSource>>

    A sequence of chunks, each a stable snapshot, that together preserve every source element in order. The result is empty when source is empty.
    Type Parameters
    Name Description
    TSource

    The type of elements in the source sequence.
    Remarks

    This method uses deferred execution and enumerates the source exactly once in a single forward pass, buffering only the current chunk. This detects transitions between adjacent elements, not separator values.

    shouldSplit is invoked exactly once per adjacent pair — that is, count - 1 times. Each yielded chunk is a stable snapshot and is not modified when the enumerator advances.

    When bounded over an infinite source, a chunk whose boundary never occurs never yields; combine with Take<TSource>(IEnumerable<TSource>, int) only when splits are known to occur.

    Examples
    // Start a new chunk whenever the value drops (a descending transition).
foreach (var chunk in new[] { 1, 2, 3, 1, 2 }.SplitWhen((previous, current) => previous > current))
    Console.WriteLine(string.Join(", ", chunk));
// => 1, 2, 3
// => 1, 2
    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when source or shouldSplit is null.
