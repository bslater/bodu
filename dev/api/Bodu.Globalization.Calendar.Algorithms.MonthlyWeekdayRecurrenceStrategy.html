    Class MonthlyWeekdayRecurrenceStrategy

    Generates an ordinal weekday every fixed number of months, such as the first Monday of every month or the last Friday of every third month.

    Remarks

    The ordinal weekday in each participating month is calculated with NthWeekdayInMonth(int, int, DayOfWeek, WeekOrdinal), so Last selects the final matching weekday and a month without a fifth matching weekday simply produces no occurrence for that month rather than invalidating the recurrence. For a monthly interval an anchor is optional; a multi-month interval requires an anchor whose year and month define month zero. 

    // The last Friday of every month.
var recurrence = new MonthlyWeekdayRecurrenceStrategy(DayOfWeek.Friday, WeekOrdinal.Last);
