    Enum PstCryptMethod

    Identifies how a file's external block data is encoded (the header's bCryptMethod values).

    Namespace: Bodu.IO.Pst
    Assembly: Bodu.IO.Pst.dll
    Syntax
    public enum PstCryptMethod
    Remarks

    The permute and cyclic methods are byte-substitution obfuscation defined by MS-PST §5.1 and §5.2, not cryptography; the reader decodes both transparently. The Windows Information Protection method is real encryption and is not supported.

    Fields

    Name Description
    None

    Block data is stored verbatim (NDB_CRYPT_NONE).
    Permute

    Block data is permuted through a fixed substitution table (NDB_CRYPT_PERMUTE).
    Cyclic

    Block data is encoded with a block-keyed rolling substitution (NDB_CRYPT_CYCLIC).
    WindowsInformationProtection

    Block data is encrypted by Windows Information Protection (NDB_CRYPT_EDPCRYPTED); unsupported.
