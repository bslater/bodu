    Method GetQuarterEnd

    GetQuarterEnd(DateTime)

    Returns the last day of the quarter that contains the specified DateTime.

    Declaration
    DateTime GetQuarterEnd(DateTime dateTime)
    Parameters
    Type Name Description
    DateTime dateTime

    The input DateTime for which to determine the end of the quarter.
    Returns
    Type Description
    DateTime

    A DateTime set to midnight (00:00:00) on the final day of the quarter that includes dateTime. The result preserves the original Kind.
    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown when dateTime cannot be mapped to a recognized fiscal year.

    GetQuarterEnd(int, int)

    Parameters
    Type Name Description
    int quarter

    The quarter number (1–4).
    int fiscalYear

    The fiscal year whose quarter boundary is being requested.
    Returns
    Type Description
    DateTime

    A DateTime set to midnight (00:00:00) on the last day of the specified quarter.
    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown when quarter is not between 1 and 4.
