UseCurrencyResolution(IServiceProvider)

Installs the container's ICurrencyLookup as the process-wide ambient currency resolver. Call once at start-up, after the service provider is built, when a custom lookup should back runtime Money construction and parsing.

public static IServiceProvider UseCurrencyResolution(this IServiceProvider provider)

Parameters

provider IServiceProvider

The built service provider.

Returns

IServiceProvider

The same provider, for chaining.

Remarks

This is a composition-root operation: it mutates process-wide state via SetDefault(ICurrencyLookup). Omitting the call leaves the registry-backed default in place, so existing applications behave identically without it.

IServiceProvider provider = services
    .AddFinancialService(b => b.AddCurrencyLookup<MyCurrencyLookup>())
    .Services
    .BuildServiceProvider();

// Make the container's ICurrencyLookup back runtime Money construction and parsing.
provider.UseCurrencyResolution();

Exceptions

ArgumentNullException

provider is null.
