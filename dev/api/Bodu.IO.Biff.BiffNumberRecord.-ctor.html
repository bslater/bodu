    BiffNumberRecord(int, int, ushort, double)

    Represents a decoded NUMBER record: a cell holding an IEEE 754 double-precision value.

    Declaration

    Parameters
    Type Name Description
    int Row

    The zero-based row index.

    The zero-based column index.
    ushort XfIndex

    The extended-format index of the cell.
    double Value

    The cell value.
    Remarks

    The record identifier is Number. The payload is fourteen bytes in both versions: the row, column, and extended-format index as 16-bit values, then the value as a little-endian IEEE 754 double.
