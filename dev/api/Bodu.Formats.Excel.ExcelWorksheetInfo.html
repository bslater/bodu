    Class ExcelWorksheetInfo

    Describes a sheet within a BIFF workbook: its name, position, visibility, type, and declared used range.

    Remarks

    An instance is produced from the workbook's bound-sheet record and the DIMENSIONS record of the sheet's substream. Sheets of every ExcelSheetType are described; only a Worksheet yields cells when opened.
