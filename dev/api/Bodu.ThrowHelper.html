Remarks

This class is split into per-group partial files following the pattern ThrowHelper.<Group>-CallerExpression.cs (for example ThrowHelper.Array-CallerExpression.cs). Each guard relies on CallerArgumentExpressionAttribute so the compiler automatically captures argument expressions at the call site.

Remarks

This is the canonical implementation. The Span<T> overload ( ThrowIfSpanOffsetOrCountInvalid<T>(Span<T>, int, int, string?, string?, string?) ) converts its argument and delegates here, forwarding all CallerArgumentExpressionAttribute values explicitly so that exception messages always reflect the original call-site expressions.

Unlike the array equivalent (ThrowIfArrayOffsetOrCountInvalid), this overload does not check for null and does not throw ArgumentNullException . ReadOnlySpan<T> is a value type and can never be null; a default ReadOnlySpan<T> is equivalent to an empty span with Length of zero.

Although the index and count validations are expressed as two-part conditions (< 0 || > span.Length ) rather than the single unsigned-cast trick used in SpanExtensions, the explicit form is preferred here because this is a guard method whose primary purpose is clarity of intent. The unsigned-cast form trades readability for a marginal branch reduction that is irrelevant on an error path.
