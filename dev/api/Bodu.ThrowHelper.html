    Class ThrowHelper

    Provides centralized guard clause methods for argument validation, offering consistent and concise exception throwing across the library.

public static class ThrowHelper
    Remarks

    This class is split into per-group partial files following the pattern ThrowHelper.<Group>-CallerExpression.cs (for example ThrowHelper.Array-CallerExpression.cs). Each guard relies on CallerArgumentExpressionAttribute so the compiler automatically captures argument expressions at the call site.
