    Remarks

    Use this typed form when an FX conversion's direction is fixed by the surrounding contract (settlement workflows, ledger-to-ledger transfers, account-currency mappings). Direction errors that ExchangeRate can surface only at runtime (mismatched From / To against the caller's expectation) become compile errors when the typed form is used. Bridge to and from the runtime form via ToRuntime() and FromRuntime(ExchangeRate).
