    Remarks

    This is a pure read with respect to both the capacity policy and time-based expiration — it does not update recency or frequency metadata, does not increment TotalTouches, and does not refresh a sliding expiration deadline (symmetric with Touch(TKey); use TryGetValue(TKey, out TValue) or the indexer getter to slide). When time-based expiration is configured, an expired entry counts as absent: it is lazily removed as an eviction and false is returned. The operation locks only the segment that owns key.
