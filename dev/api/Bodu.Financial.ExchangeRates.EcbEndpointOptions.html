Remarks

This object isolates the network-facing settings from the behavioural options on EcbRateProviderOptions, so the host, transport timeout, and request identity can be pointed at a mirror or proxy of the ECB feeds - or simply tuned - without touching caching, feed-selection, or alias configuration. The absolute URL of a feed is composed from BaseUrl and the feed's relative FileName through ResolveFeedUrl(EcbRateFeed).

Every member carries a working default, so the object binds cleanly through Microsoft.Extensions.Options and requires no configuration for the common case.
