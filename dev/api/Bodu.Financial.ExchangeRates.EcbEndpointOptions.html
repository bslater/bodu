    Class EcbEndpointOptions

    Configures the provider's connection to the European Central Bank's eurofxref endpoints: where the feed files are published and how the HTTP requests that fetch them are shaped.

    Remarks

    This object isolates the network-facing settings from the behavioural options on EcbRateProviderOptions, so the host, transport timeout, and request identity can be pointed at a mirror or proxy of the ECB feeds — or simply tuned — without touching caching, feed-selection, or alias configuration. The absolute URL of a feed is composed from BaseUrl and the feed's relative FileName through ResolveFeedUrl(EcbRateFeed).

    Every member carries a working default, so the object binds cleanly through Microsoft.Extensions.Options and requires no configuration for the common case.

    Properties

    Name Description
    BaseUrl

    Gets or sets the base URL under which the ECB publishes its eurofxref reference-rate files. Should end with a trailing slash so feed file names resolve as relative paths.
    HttpTimeout

    Gets or sets the HTTP request timeout applied to feed downloads by the dependency-injection registration.
    UserAgent

    Gets or sets the User-Agent header applied to feed downloads by the dependency-injection registration.
