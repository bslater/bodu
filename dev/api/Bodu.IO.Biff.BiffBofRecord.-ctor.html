    BiffBofRecord(ushort, BiffSubstreamType, ushort, ushort, uint, uint)

    Represents a decoded BOF record: the version marker, the kind of substream being opened, and the build information of the application that wrote it.

    Declaration
    public BiffBofRecord(ushort RawVersion, BiffSubstreamType SubstreamType, ushort Build, ushort Year, uint FileHistoryFlags, uint LowestSaveVersion)
    Parameters
    Type Name Description
    ushort RawVersion

    The vers field: 0x0500 for BIFF5, 0x0600 for BIFF8.
    BiffSubstreamType SubstreamType

    The kind of substream the record opens.
    ushort Build

    The build identifier of the writing application.
    ushort Year

    The build year of the writing application.
    uint FileHistoryFlags

    The BIFF8 file-history flags; zero under BIFF5.
    uint LowestSaveVersion

    The lowest BIFF version that has saved the file (BIFF8); zero under BIFF5.
    Remarks

    The record identifier is Bof. The payload is eight bytes in BIFF5 (version, substream type, build, year) and sixteen in BIFF8, which adds the file-history flags and the lowest saving version. The reader tolerates any payload of at least four bytes, reporting zero for fields the record omits, and establishes Version from the version marker when the record is read.
