    Method IsFirstDateOfQuarter

    IsFirstDateOfQuarter(DateTime)

    Determines whether the specified DateTime falls on the first day of its calendar quarter, using the standard calendar quarter definition.

    Declaration
    public static bool IsFirstDateOfQuarter(this DateTime dateTime)
    Parameters
    Type Name Description
    DateTime dateTime

    The date and time value to evaluate.
    Returns
    Type Description
    bool

    true if dateTime represents the first day of its quarter; otherwise, false.
    Remarks

    This overload uses the standard calendar alignment defined by JanuaryToDecember: Q1 = Jan – Mar, Q2 = Apr – Jun, Q3 = Jul – Sep, Q4 = Oct – Dec.

    The comparison is performed on the date component only; the time component of dateTime is ignored.
