Fields

Visible = 0

The sheet is visible in the workbook.

Hidden = 1

The sheet is hidden but can be unhidden through the Excel user interface.

VeryHidden = 2

The sheet is very hidden and can be revealed only programmatically.

Remarks

A very hidden sheet is concealed from the Excel user interface and can be revealed only through the object model, so it is distinguished from an ordinarily hidden sheet rather than collapsed into a single hidden state.
