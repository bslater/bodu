Remarks

This type derives from WebRateProviderOptions, which supplies the endpoint base address, the HTTP contract, the synchronous-access and look-back behaviour, and the per-concern log levels. The members declared here are report-specific: the ReportPath and ReportType that address the monthly report, the on-disk cache settings, and the CurrencyNames map that resolves an IMF currency label to its ISO 4217 code. The report is keyless, so no API key is required.

USD-anchored, bulk. The report quotes every reported currency against the US dollar for each business day of the month, so a single download warms the store for all currencies and all business days at once. Only USD/X and X/USD pairs are serviceable; the reverse direction is served by the base inverse-lookup fallback. Every member carries a working default, so the options bind cleanly through Microsoft.Extensions.Options.

CurrencyNames

Gets or sets the map from an IMF currency label (footnote-stripped and trimmed) to its ISO 4217 code, applied while normalizing a report row.

public IDictionary<string, string> CurrencyNames { get; set; }

Property Value

IDictionary<string, string>

The currency-name map; seeded in the constructor with the currencies the report commonly quotes.

Remarks

A label absent from this map is resolved directly against the ISO 4217 catalogue, and a label that resolves neither way is skipped. Extend the map to add labels the IMF publishes that are not seeded here.
