    Struct PstPropertyValue

    Represents one property value of a property context or table-context row: the 16-bit property identifier, the raw wire type code, and the resolved little-endian payload with typed accessors over it.

    Remarks

    This layer carries no MAPI semantics: the wire type is the raw MS-OXCDATA code and the payload is the value's little-endian bytes. Multi-valued and object-typed payloads are surfaced raw — decoding them is a format reader's concern.

    Each typed accessor requires the matching wire type and a payload of at least the type's width; GetString() decodes the UTF-16LE string type (0x001F) only — the code-page string type (0x001E) stays bytes, because resolving its code page is a format-layer concern.

    GetBoolean()

    GetBytes()

    Reads the value's payload as a byte array.
    GetDouble()

    Reads the value as a 64-bit floating-point number (wire type 0x0005, or the floating time 0x0007).
    GetGuid()

    Reads the value as a GUID (wire type 0x0048).
    GetInt16()

    Reads the value as a 16-bit signed integer (wire type 0x0002).
    GetInt32()

    Reads the value as a 32-bit signed integer (wire type 0x0003, or the 32-bit error code 0x000A).
    GetInt64()

    Reads the value as a 64-bit signed integer (wire types 0x0014, 0x0006, and the FILETIME 0x0040).
    GetSingle()

    Reads the value as a 32-bit floating-point number (wire type 0x0004).
    GetString()

    Reads the value as a string (the UTF-16LE wire type 0x001F only).
    ToString()

    Returns a textual form of the value for diagnostics.
