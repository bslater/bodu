Examples

// Single-call computation against an in-memory body.
char check = Damm.Compute("572");   // '4'

// Full-sequence validation - equivalent to checking that the final interim is zero.
bool ok = Damm.IsValid("5724");     // true

// Streaming use when the body is built up incrementally.
var algo = new Damm();
algo.Append("572");
char d = algo.GetCurrentCheckDigit(); // '4'

Remarks

The Damm algorithm was presented by H. Michael Damm in 2004. It evaluates a running interim digit by repeatedly indexing into a carefully chosen 10×10 totally antisymmetric quasigroup - a table with no fixed points on its diagonal and no partial idempotent entries. The final interim is the check digit.

Damm detects all single-digit substitution errors and all adjacent-digit transpositions - the latter without the 09 ↔ 90 exception that Luhn suffers from. Validation is especially clean: a sequence (body followed by its check digit) is valid if and only if its final interim is zero.

Worked example. For the body "572", the computed check digit is '4', and the resulting sequence "5724" is therefore valid under Damm.

important

This algorithm is not cryptographically secure and should not be used for password hashing, digital signatures, or integrity validation in security-sensitive applications.
