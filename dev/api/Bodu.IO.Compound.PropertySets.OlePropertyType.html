    Enum OlePropertyType

    Identifies the scalar value type carried by an OlePropertyValue, corresponding to the COM VARENUM (VT_*) constants used in OLE property sets.

    Namespace: Bodu.IO.Compound.PropertySets
    Assembly: Bodu.IO.Compound.dll
    Syntax
    public enum OlePropertyType : ushort
    Remarks

    These values are the base (scalar) type only; the vector modifier (VT_VECTOR) is surfaced separately through IsVector.

    Fields

    Name Description
    Empty

    An empty value (VT_EMPTY).
    Null

    A null value (VT_NULL).
    Int16

    A signed 16-bit integer (VT_I2).
    Int32

    A signed 32-bit integer (VT_I4).
    Float32

    A 32-bit IEEE floating-point value (VT_R4).
    Float64

    A 64-bit IEEE floating-point value (VT_R8).
    Variant

    A self-describing variant element (VT_VARIANT), used within variant vectors.
    Currency

    A currency value (VT_CY), surfaced as decimal.
    Date

    An OLE automation date (VT_DATE), surfaced as DateTimeOffset.
    BinaryString

    A length-prefixed code-page string (VT_BSTR).
    Boolean

    A boolean value (VT_BOOL).
    Int8

    A signed 8-bit integer (VT_I1).
    UInt8

    An unsigned 8-bit integer (VT_UI1).
    UInt16

    An unsigned 16-bit integer (VT_UI2).
    UInt32

    An unsigned 32-bit integer (VT_UI4).
    Int64

    A signed 64-bit integer (VT_I8).
    UInt64

    An unsigned 64-bit integer (VT_UI8).
    AnsiString

    A length-prefixed ANSI string decoded with the section code page (VT_LPSTR).
    UnicodeString

    A length-prefixed UTF-16 string (VT_LPWSTR).
    FileTime

    A Windows FILETIME (VT_FILETIME), surfaced as DateTimeOffset or TimeSpan.
    Blob

    An opaque length-prefixed binary blob (VT_BLOB).
    ClipboardData

    Clipboard data (VT_CF), surfaced as a byte array.
