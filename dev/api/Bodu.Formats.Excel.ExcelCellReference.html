Remarks

The notation names a column by a bijective base-26 sequence of letters (A..Z, AA..AZ, and so on) followed by a one-based row number. The conversions are culture-independent and accept upper- or lower-case column letters when parsing.

using Bodu.Formats.Excel;

string reference = ExcelCellReference.ToA1(rowIndex: 9, columnIndex: 27); // "AB10"

if (ExcelCellReference.TryParseA1("AB10", out int row, out int column))
    Console.WriteLine($"row {row}, column {column}"); // row 9, column 27
