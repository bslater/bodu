Represents a decoded FORMULA record: the cell's position and format, the cached result of its last calculation, its option flags, and the parsed-expression tokens, which the codec exposes as raw bytes.

Remarks

The eight-byte result field holds a double unless its last two bytes are 0xFFFF, in which case its first byte selects the kind (CachedResultKind) and a string result is carried by the STRING record that immediately follows. The layout is identical in BIFF5 and BIFF8.
