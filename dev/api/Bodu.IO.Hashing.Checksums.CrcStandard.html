    Class CrcStandard

    Immutable parameter bundle that fully describes a CRC variant — width, polynomial, initial value, input/output bit reflection, and final XOR — and serves as the lookup key into the RevEng catalogue used by Crc.

    Remarks

    Every CRC variant in the wild differs from every other along the same five dimensions — the polynomial, the initial register value, whether input bits are reflected as they enter the register, whether the final register is reflected on the way out, and what value the register is XOR-ed with at the end. CRC-32/ISO-HDLC and CRC-32/BZIP2 share a polynomial but disagree on reflection; CRC-16/MODBUS and CRC-16/USB share nearly everything but the initial value. CrcStandard captures one such parameter bundle as an immutable, equatable, serializable value, decoupling the choice of variant from the engine that runs it.

    Three ways to obtain a standard.

    • Catalogue properties CRC32_ISOHDLC, CRC32_ISCSI, CRC16_MODBUS, CRC16_KERMIT, CRC64_XZ, … — direct named accessors for the common entries that return the canonical, cached CrcStandard instance.
    • Get(CrcStandards) Materializes any catalogue entry from its CrcStandards enum value — useful when the choice is data-driven (e.g. read from configuration).
    • FromName(string) Resolves canonical names and published aliases — "CRC-32", "PKZIP", "CRC-32/XZ", "CRC-32/ADCCP" all return the same CRC32_ISOHDLC instance.
    • Direct construction The CrcStandard(string, int, ulong, ulong, bool, bool, ulong) constructor accepts custom parameters for variants that are not in the RevEng catalogue. Width must lie within MinSize.. MaxSize.

    How it pairs with Crc. The hash engine reads Polynomial and ReflectIn to fetch (or build) a precomputed lookup table from CrcLookupTableCache, seeds the running register with InitialValue, and applies ReflectOut + XOrOut when emitting the final digest. Multiple Crc instances configured with the same CrcStandard share the same lookup table, so creating fresh engines for the same standard is inexpensive.

    Equality and serialization. CrcStandard is a value-style type: two instances are equal iff every parameter matches (the Name is informational only and does not affect identity). ISerializable support is provided so a chosen standard can survive process boundaries unchanged.

    Coverage and limits. Sizes are constrained to MinSize..MaxSize bits; any wider variant in the RevEng catalogue (currently only CRC-82/DARC) is intentionally omitted because it will not fit in the ulong-backed register. Instances are immutable and therefore safe to share across threads.

    Examples
    using Bodu.IO.Hashing.Checksums;

// 1. Direct named accessor — most callers want exactly this.
var crc = new Crc(CrcStandard.CRC32_ISOHDLC);

// 2. Data-driven look-up — pick the variant from a configuration value.
CrcStandards configured = Enum.Parse<CrcStandards>(config["CrcVariant"]);
var configuredCrc = new Crc(CrcStandard.Get(configured));

// 3. Look-up by alias — accept legacy or vendor names supplied by users.
CrcStandard pkzip = CrcStandard.FromName("PKZIP");      // same instance as CRC32_ISOHDLC
CrcStandard ccitt = CrcStandard.FromName("CRC-CCITT");  // resolves to CRC16_KERMIT

// 4. Custom variant (not in the RevEng catalogue): a 12-bit CRC with bespoke parameters.
var custom = new CrcStandard(
    name:         "CRC-12/MY-SPEC",
    size:         12,
    polynomial:   0x80F,
    initialValue: 0x000,
    reflectIn:    false,
    reflectOut:   false,
    xOrOut:       0x000);

    Properties

    Name Description
    All

    Gets a snapshot of every supported CRC standard in the catalogue, in declaration order.
    CRC16_ARC

    Gets the CRC-16/ARC CRC standard (aliases include CRC-16, CRC-IBM, CRC-16/LHA). The de-facto generic 16-bit CRC.
    CRC16_IBM3740

    Gets the CRC-16/IBM-3740 CRC standard (aliases CRC-16/AUTOSAR, CRC-16/CCITT-FALSE). The widely-used "CCITT-false" variant.
    CRC16_KERMIT

    Gets the CRC-16/KERMIT CRC standard (aliases CRC-16/BLUETOOTH, CRC-16/CCITT, CRC-CCITT). Used by Kermit and Bluetooth.
    CRC16_MODBUS

    Gets the CRC-16/MODBUS CRC standard (alias MODBUS). Used by Modbus RTU over serial.
    CRC16_XMODEM

    Gets the CRC-16/XMODEM CRC standard (aliases CRC-16/ACORN, XMODEM, ZMODEM). Used by XMODEM and ZMODEM.
    CRC32_BZIP2

    Gets the CRC-32/BZIP2 CRC standard (aliases CRC-32/AAL5, CRC-32/DECT-B, B-CRC-32). Used by bzip2 and AAL5.
    CRC32_ISCSI

    Gets the CRC-32/ISCSI CRC standard (aliases CRC-32C, CRC-32/CASTAGNOLI, CRC-32/NVME, CRC-32/BASE91-C, CRC-32/INTERLAKEN). Castagnoli polynomial used by iSCSI, SCTP, Btrfs, ext4, NVMe, and many modern protocols.
    CRC32_ISOHDLC

    Gets the CRC-32/ISO-HDLC CRC standard (aliases CRC-32, PKZIP, CRC-32/XZ, CRC-32/ADCCP, CRC-32/V-42). The canonical CRC-32 used by zlib, PNG, Ethernet, PKZIP, and the default standard used by Crc().
    CRC64_ECMA182

    Gets the CRC-64/ECMA-182 CRC standard (alias CRC-64). Specified by ECMA-182 for DLT tape formats.
    CRC64_XZ

    Gets the CRC-64/XZ CRC standard (alias CRC-64/GO-ECMA). Used by the XZ compressed file format and the Go crc64 ECMA table.
    CRC8_MAXIMDOW

    Gets the CRC-8/MAXIM-DOW CRC standard (aliases CRC-8/MAXIM, DOW-CRC). Used by Maxim / Dallas 1-Wire devices.
    CRC8_SMBUS

    Gets the CRC-8/SMBUS CRC standard (alias CRC-8). Width 8, polynomial 0x07, initial value 0x00, no reflection, XOR out 0x00.
    InitialValue

    Gets the initial value used in the CRC calculation.
    Name

    Gets the name of the CRC standard.
    Polynomial

    Gets the polynomial used in the CRC calculation.
    ReflectIn

    Gets a value indicating whether the input data is reflected during the CRC calculation.
    ReflectOut

    Gets a value indicating whether the CRC result is reflected before XORing with XOrOut.
    Size

    Gets the size, in bits, of the CRC checksum.
    XOrOut

    Gets the value to XOR the final CRC result with.
