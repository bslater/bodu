    SetFlag<TEnum>(TEnum, TEnum)

    Returns a copy of value with every bit in flags set.

    Declaration
    public static TEnum SetFlag<TEnum>(this TEnum value, TEnum flags) where TEnum : struct, Enum
    Parameters
    Type Name Description
    TEnum value

    The enumeration value to start from.
    TEnum flags

    The flag bits to set.
    Returns
    Type Description
    TEnum

    A new enumeration value equal to value with flags added.
    Type Parameters
    Name Description
    TEnum

    The enumeration type.
    Remarks

    Equivalent to the bitwise OR value | flags. The receiver is not modified; enumerations are value types and the result is returned as a new value.
