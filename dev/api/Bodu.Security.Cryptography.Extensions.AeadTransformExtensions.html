Decrypt(IAeadTransform, ReadOnlySpan<byte>, ReadOnlySpan<byte>)

Verifies and decrypts ciphertextWithTag and returns a new array containing the recovered plaintext.

public static byte[] Decrypt(this IAeadTransform transform, ReadOnlySpan<byte> ciphertextWithTag, ReadOnlySpan<byte> associatedData = default)

Parameters

transform IAeadTransform

The AEAD transform. Must not be null.

ciphertextWithTag ReadOnlySpan<byte>

The ciphertext followed by its authentication tag.

associatedData ReadOnlySpan<byte>

The data that must match what was supplied at encryption time. Defaults to empty.

Returns

byte[]

A new array of length ciphertextWithTag.Length - (transform.TagSize / 8).

Exceptions

ArgumentNullException

transform is null.

CryptographicException

The authentication tag did not match.
