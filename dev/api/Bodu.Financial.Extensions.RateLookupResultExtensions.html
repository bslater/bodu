Remarks

Each member is a thin projection over the result's backing data, its resolved rate, the requested date, and the recorded day offset, carrying no state of its own.

When compiled with a tool-chain that supports C# 14 extension members the helpers are exposed as extension properties (for example result.IsExactDate); otherwise they compile as classic extension methods (for example result.IsExactDate()).

SignedOffsetDays(RateLookupResult)

Returns the signed difference, in days, from RequestedDate to the resolved observation date.

public static int SignedOffsetDays(this RateLookupResult result)

Parameters

result RateLookupResult

The lookup outcome to inspect.

Returns

int

A negative value when the resolved observation predates the request (PreviousOnOrBefore fallback), a positive value when it post-dates the request (NextOnOrAfter fallback), or zero for an exact match.

Remarks

Accounting and tax workflows typically distinguish between historical and forward-looking fallbacks; this member surfaces that distinction without forcing the caller to recompute it from OffsetDays.
