    Struct IniElement

    Represents a single element within an IniDocument — the root object, a section object, or a string value — shaped after System.Text.Json's JsonElement.

    Remarks

    The root object's properties are the document's hoisted global keys (string values) followed by its sections (object values); a section object's properties are its key/value entries.
