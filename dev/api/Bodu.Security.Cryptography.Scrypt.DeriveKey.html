    DeriveKey(SecretBytes, Salt, int, int, int, int)

    Derives a key in a single call from a pinned, disposable password holder and a typed salt.

    Declaration
    public static byte[] DeriveKey(SecretBytes password, Salt salt, int costN, int blockSizeR, int parallelization, int length)
    Parameters
    Type Name Description
    SecretBytes password

    The password material to derive from. Must not be null.
    Salt salt

    The salt, typically produced by Random(int).
    int costN

    The CPU/memory cost parameter N.
    int blockSizeR

    The block-size parameter r.
    int parallelization

    The parallelization parameter p.
    int length

    The derived-key length, in bytes.
    Returns
    Type Description
    byte[]

    The derived key.
    Remarks

    Convenience overload over the span form for callers using the SecretBytes and Salt value types, which keep password material pinned and zeroed on disposal and keep salts distinct from keys and nonces in calling code.

    Exceptions
    Type Condition
    ArgumentNullException

    password is null.
    ObjectDisposedException

    password has been disposed.
