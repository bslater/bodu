Remarks

The framework Mode and Padding properties can only express the members of CipherMode and PaddingMode. This base adds the BlockMode and BlockPadding counterparts over the extended CipherModeKind / PaddingModeKind catalogues (which include, for example, CTR and ISO7816_4) and keeps each pair bidirectionally synchronized: assigning either member of a pair updates the other whenever an equivalent value exists, so consumers inspecting the framework property always observe a consistent configuration.

Transform creation in derived classes reads BlockMode and BlockPadding, so both the framework properties and the extended properties are honoured regardless of which surface the caller configures.

Properties

BlockMode

Gets or sets the block cipher mode of operation used when creating encryptors and decryptors.

public CipherModeKind BlockMode { get; set; }

Property Value

CipherModeKind

One of the CipherModeKind values. The default is CBC.

Remarks

This property replaces the inherited Mode property for use with BlockCipherModeFactory and the extended set of modes it supports, including CTR and OFB, which are not available via the standard CipherMode enumeration.

When the assigned value has a matching member in CipherMode (for example, CBC, ECB, CFB), the inherited Mode is kept in sync so that consumers inspecting the base property observe a consistent mode. Extended modes with no CipherMode equivalent leave the base property unchanged.

public PaddingModeKind BlockPadding { get; set; }

Property Value

PaddingModeKind

One of the PaddingModeKind values. The default is PKCS7.

Remarks

When the assigned value has a matching member in PaddingMode (for example, PKCS7, Zeros, None), the inherited Padding is kept in sync. Extended modes with no PaddingMode equivalent (such as ISO7816_4) leave the base property unchanged.

Mode

public override CipherMode Mode { get; set; }

Property Value

CipherMode

The mode for operation of the symmetric algorithm. The default is CBC.

Remarks

Also synchronizes BlockMode so that encryptor and decryptor creation, which read BlockMode, honour the assigned value. Every CipherMode member has a matching CipherModeKind member, so the synchronization always succeeds.

Exceptions

The cipher mode is not one of the CipherMode values.
