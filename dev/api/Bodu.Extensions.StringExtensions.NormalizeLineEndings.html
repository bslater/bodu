    Method NormalizeLineEndings

    NormalizeLineEndings(string, string)

    Returns value with every CRLF (\r\n), CR (\r), and LF (\n) sequence replaced by newline.

    Declaration
    public static string NormalizeLineEndings(this string value, string newline = "\n")
    Parameters
    Type Name Description
    string value

    The string to normalize. Must not be null.
    string newline

    The replacement line terminator. Defaults to "\n" (LF). May be empty to strip all line endings. Must not be null.
    Returns
    Type Description
    string

    A new string in which every recognised line ending in value has been replaced by newline. When value contains no line endings, the original instance is returned unchanged.
    Remarks

    CRLF pairs are treated as a single line ending and replaced by exactly one newline. Other Unicode line separators (U+2028, U+2029, NEL U+0085) are not touched.

    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when value or newline is null.
