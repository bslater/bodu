    GcmModeTransform(IBlockCipher, Nonce)

    Initializes a new instance of the GcmModeTransform class with a typed 96-bit GCM nonce.

    Declaration
    public GcmModeTransform(IBlockCipher cipher, Nonce nonce)
    Parameters
    Type Name Description
    IBlockCipher cipher

    The 128-bit block cipher used by GCM.
    Nonce nonce

    The 96-bit (12-byte) nonce. Must be unique per key.
    Remarks

    Convenience overload over the span form for callers using the Nonce value type — typically produced by Random(int) — which keeps nonces distinct from keys and tags in calling code.

    Exceptions
    Type Condition
    ArgumentNullException

    cipher is null.
    ArgumentException

    cipher does not have a 16-byte block size, or nonce is not exactly Bodu.Security.Cryptography.GcmModeTransform.NonceSize bytes.
