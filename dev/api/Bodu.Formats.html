Bodu.Formats Namespace

Purpose

Bodu.Formats is a namespace root: it holds no types of its own. It groups the read-only readers for application file formats, which build on the containers and codecs under Bodu.IO:

  • Bodu.Formats.Excel - Excel 97-2003 binary workbooks (Bodu.Formats.Excel.Binary).
  • Bodu.Formats.Outlook - the shared MAPI value model (Bodu.Formats.Outlook) and the .msg and .pst readers built on it (Bodu.Formats.Outlook.Msg, Bodu.Formats.Outlook.Pst).
