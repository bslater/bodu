AddBoeExchangeRates(IServiceCollection, IConfiguration?, string, Action<BoeRateProviderOptions>?)

Registers the core Bodu.Financial services and the Bank of England exchange-rate provider.

public static IFinancialServiceBuilder AddBoeExchangeRates(this IServiceCollection services, IConfiguration? configuration = null, string sectionName = "Financial:Boe", Action<BoeRateProviderOptions>? configure = null)

Parameters

services IServiceCollection

The service collection to register into.

configuration IConfiguration

An optional configuration root. When supplied, FinancialOptions is bound from the Financial section and BoeRateProviderOptions from sectionName.

sectionName string

The Bank of England configuration section name. Defaults to Financial:Boe.

configure Action<BoeRateProviderOptions>

An optional callback applied after Bank of England configuration binding.

Returns

IFinancialServiceBuilder

An IFinancialServiceBuilder for further composition.

Remarks

IServiceCollection services = new ServiceCollection();

// One call wires up the core financial services plus the Bank of England provider.
services.AddBoeExchangeRates(configuration);

IServiceProvider provider = services.BuildServiceProvider();
var rates = provider.GetRequiredService<IDatedRateProvider>();

Exceptions

ArgumentNullException

Thrown when services is null.

ArgumentException

Thrown when sectionName is empty or white space.
