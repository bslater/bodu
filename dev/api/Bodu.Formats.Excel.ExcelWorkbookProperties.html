    Class ExcelWorkbookProperties

    Exposes the flattened document properties of a workbook, read from the compound file's summary-information property sets.

    Remarks

    The values are sourced from the SummaryInformation and DocumentSummaryInformation streams. A workbook that omits a stream, or whose property set cannot be parsed, yields null for the affected members rather than failing the workbook read. The lower-level property-set model is intentionally not exposed here; the Excel surface presents only the flattened document fields.
