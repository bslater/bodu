Remarks

Each instance member is a thin projection over Amount and the public arithmetic surface, carrying no state of its own; the Min, Max, and Clamp helpers are static because they compare two or more operands. Splitting them into this extension surface keeps Money<TCurrency> focused on construction, arithmetic, equality, and formatting.

When compiled with a tool-chain that supports C# 14 extension members the instance helpers are exposed as extension properties (for example money.IsZero); otherwise they compile as classic extension methods (for example money.IsZero()).
