    Enum CurrencyDisplay

    Specifies how MoneyFormatter renders the currency designator alongside the amount.

    Namespace: Bodu.Financial
    Assembly: Bodu.Financial.dll
    Syntax
    public enum CurrencyDisplay

    Fields

    Name Description
    IsoCode

    Render the ISO 4217 code (for example, "USD 1,234.56").
    Symbol

    Render the culture's native currency symbol where it matches the amount's currency.
    EnglishName

    Render the currency's English-language name (for example, "1,234.56 US Dollar").
    None

    Render the bare numeric amount with no currency designator.
