Examples

static string Describe<TSet, TValue>(TSet set)
    where TSet : ICalendarValueSet<TSet, TValue> =>
    set == TSet.All ? "all" : $"{set.Count} selected: {set}";

Describe<MonthSet, int>(new MonthSet(1, 4, 7, 10));       // "4 selected: 1,4,7,10"
Describe<DayOfWeekSet, DayOfWeek>(DayOfWeekSet.Weekdays); // "5 selected: _MTWTF_"

Remarks

DayOfWeekSet, MonthSet, DayOfMonthSet, HourSet, MinuteSet and SecondSet implement it, so generic code can test, combine, write and read any of them. A set is a value: members that change it, such as With(TValue) and the operators, return a new set, and two sets are equal when they select the same values.

The operators are the set operations within the domain: | is the union, & the intersection, ^ the symmetric difference, and ~ the complement, every value of the domain the set does not select.

Each value of the domain has a position, from 0 for the first value to one less than the domain's size for the last. ToUInt64() describes a set as the number whose bit n is set when the set selects the value at position n, and FromUInt64(ulong) creates the set such a number describes, so equal sets give equal numbers.

Each type documents its domain, its text forms and the formats ToString(string?) and ParseExact(string, string) accept. Every text form is ASCII, so the members that write to or read from a span of characters or of UTF-8 bytes handle the same text as the members that take and return a string.
