    Enum PstFileFormat

    Identifies the on-disk PST format variant, discriminated by the header's wVer field.

    Namespace: Bodu.IO.Pst
    Assembly: Bodu.IO.Pst.dll
    Syntax
    public enum PstFileFormat

    Fields

    Name Description
    Unicode

    The Unicode format (wVer 23) — 64-bit structures, the default since Outlook 2003.
    Ansi

    The legacy ANSI format (wVer 14 or 15) — 32-bit structures. Read with 32-bit block identifiers and offsets; strings are typically code-page (PT_STRING8) values.
    Ost4K

    The 4 KiB-page OST variant (wVer 36 and above). Read with 32-bit block identifiers and offsets; strings are typically code-page (PT_STRING8) values.
