    Struct MapiPropertyTag

    Represents a 32-bit MAPI property tag: a 16-bit property identifier in the high word and a 16-bit property type in the low word.

    Remarks

    The tag layout follows MS-OXCDATA §2.11.4. The low word may carry the multi-valued flag (0x1000) in addition to a base MapiPropertyType code; Type always reports the base code and IsMultiValued reports the flag, while Value preserves the raw combination.

    Identifiers at or above 0x8000 denote named properties whose meaning is defined by a MapiNamedProperty mapping rather than by the identifier itself.
