Remarks

SpecVersion selects the grammar the parser enforces. The default, V1_0 , is the most widely deployed released specification; V1_1 additionally accepts the TOML v1.1.0 grammar features.

MaxDepth bounds the nesting of tables and arrays the parser will materialize, guarding against stack-exhausting input. A value of 0 selects the default of 64, and a larger value is clamped to the hard ceiling Bodu.Text.Toml.TomlLimits.AbsoluteMaxDepth; a document that nests deeper than the effective limit throws TomlFormatException rather than risking a StackOverflowException. 

using TomlDocument document = TomlDocument.Parse("value = 1"u8, new TomlDocumentOptions
{
    SpecVersion = TomlSpecVersion.V1_0,   // reject TOML 1.1-only syntax
    MaxDepth = 32,
});
