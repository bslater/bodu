    ReverseBits(byte, int)

    Reverses the order of the least significant bitLength bits in the specified byte value.

    Declaration
    public static byte ReverseBits(this byte value, int bitLength)
    Parameters
    Type Name Description
    byte value

    The 8-bit unsigned value to reflect.
    int bitLength

    The number of least significant bits to reverse. Must be in the range [0, 8]. Bits above the reflected window are discarded.
    Returns
    Type Description
    byte

    A byte whose least significant bitLength bits contain the bit-reversed window of value, with all higher bits set to zero.

    ReverseBits(ulong, int)

    Reverses the order of the least significant bitLength bits in the specified ulong value.

    Declaration
    public static ulong ReverseBits(this ulong value, int bitLength)
    Parameters
    Type Name Description
    ulong value

    The 64-bit unsigned integer to reflect.
    int bitLength

    The number of least significant bits to reverse. Must be in the range [0, 64]. Bits above the reflected window are discarded.
    Returns
    Type Description
    ulong

    A ulong whose least significant bitLength bits contain the bit-reversed window of value, with all higher bits set to zero.
    Remarks

    Commonly used by CRC and other checksum primitives to implement the reflect-in / reflect-out transformations where bitLength matches the hash width.

    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    bitLength is less than 0 or greater than 64.

    ReverseBits(byte[])

    Reverses the bits within each byte of the specified byte array and returns a new array.

    Declaration
    public static byte[] ReverseBits(this byte[] bytes)
    Parameters
    Type Name Description
    byte[] bytes

    The byte array to process. Must not be null.
    Returns
    Type Description
    byte[]

    A new byte array in which the bits of each element have been reversed. The original array is not modified.
    Remarks

    Each byte is reversed independently using ReverseBits(byte). The relative order of bytes within the array is preserved.

    Exceptions
    Type Condition
    ArgumentNullException

    bytes is null.
