    Struct IniDocumentReader

    Provides a forward-only cursor over the normalized token stream of a parsed INI document: a root object whose properties are the hoisted global keys followed by the sections, each section an object of key/value entries. The reader is a ref struct, so it cannot be boxed or captured.

    Remarks

    INI cannot be normalized in a single forward pass when duplicate sections merge — a later [section] appends to an earlier one, declaring structure out of source order. The constructor therefore parses the entire document up front, applying the IniDocumentOptions duplicate policies, and Read() walks the materialized store. A malformed document or policy violation raises IniFormatException from the constructor rather than from Read(). This type walks a normalized document; Utf8IniReader reads the UTF-8 source in document order.

    The stream is StartObject, the global PropertyName / String pairs, then for each section a PropertyName followed by a nested StartObject … EndObject, and a closing EndObject. Comments are not surfaced.
