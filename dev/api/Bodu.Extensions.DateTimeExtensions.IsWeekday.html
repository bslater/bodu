    Method IsWeekday

    IsWeekday(DateTime)

    Determines whether the specified DateTime falls on a weekday, using the default MondayToFriday rule.

    Declaration
    public static bool IsWeekday(this DateTime dateTime)
    Parameters
    Type Name Description
    DateTime dateTime

    The date and time value to evaluate.
    Returns
    Type Description
    bool

    true if dateTime does not fall on Saturday or Sunday; otherwise, false.
    Remarks

    A weekday is any day selected by the working-week pattern. This overload uses MondayToFriday and no custom provider.

    IsWeekday(DateTime, WorkingDaysOfWeek, IWeekendDefinitionProvider?)

    Determines whether the specified DateTime falls on a weekday, using the supplied WorkingDaysOfWeek and an optional custom provider.

    Declaration
    public static bool IsWeekday(this DateTime dateTime, WorkingDaysOfWeek workingWeek, IWeekendDefinitionProvider? provider = null)
    Parameters
    Type Name Description
    DateTime dateTime

    The date and time value to evaluate.
    WorkingDaysOfWeek workingWeek

    The WorkingDaysOfWeek that determines which days are treated as working days.
    IWeekendDefinitionProvider provider

    An optional IWeekendDefinitionProvider that supplies custom weekend logic when workingWeek is Custom.
    Returns
    Type Description
    bool

    true if dateTime is not a weekend under the supplied rule or provider; otherwise, false.
    Remarks

    The method evaluates whether the DayOfWeek of dateTime is included in the working-week pattern supplied by workingWeek and optionally refined by provider.

    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown if workingWeek is not a defined value of the WorkingDaysOfWeek enumeration, -or- workingWeek is Custom and provider is null.
