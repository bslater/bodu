    Method GetValues

    GetValues<TEnum>()

    Returns the values declared by the specified enumeration.

    Declaration
    public static TEnum[] GetValues<TEnum>() where TEnum : struct, Enum
    Returns
    Type Description
    TEnum[]

    A fresh array of the values declared by TEnum.
    Type Parameters
    Name Description
    TEnum

    The enumeration type.
    Remarks

    A new array is returned on every call so callers may mutate the result without affecting the internal cache or other callers, matching the behavior of GetValues<TEnum>(). The underlying reflection result is cached, so repeated calls only pay the cost of a single array copy.
