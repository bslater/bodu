Produces a converter that serializes the enumeration TEnum as a TOML string holding its member name, applying an optional naming policy and honoring StringEnumMemberNameAttribute on individual members.

Examples

[Converter(typeof(TomlStringEnumConverter<Status>))]
public enum Status
{
    Active,
    OnHold,
}

// Status.OnHold serializes as the TOML string "OnHold".

Remarks

Unlike the non-generic TomlStringEnumConverter, this strongly typed factory can be referenced from a ConverterAttribute on a member, property, or the enumeration itself, because it exposes a public parameterless constructor and applies to a single enumeration type.
