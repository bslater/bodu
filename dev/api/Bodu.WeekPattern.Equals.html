    Equals(object?)

    Determines whether the specified object is equal to the current WeekPattern.

    Declaration
    public override bool Equals(object? obj)
    Parameters
    Type Name Description
    object obj

    The object to compare. Only another boxed WeekPattern can be equal; all other types, including a boxed byte and null, return false.
    Returns
    Type Description
    bool

    true if obj is a WeekPattern with the same selected-day bitmask; otherwise, false.
    Overrides
    ValueType.Equals(object)
    Remarks

    A boxed byte is intentionally not considered equal here so that object-level equality stays symmetric: Equals(object) can never recognize a boxed WeekPattern, so treating the reverse comparison as equal would violate the reflexive-symmetric contract of Equals(object) and corrupt hash-based collections. Use the strongly typed Equals(byte) overload to compare against a raw bitmask.
