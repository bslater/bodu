    FromHexString(ReadOnlySpan<byte>)

    Decodes a UTF-8 encoded hexadecimal byte span into a byte array using strict parsing.

    Declaration
    public static byte[] FromHexString(ReadOnlySpan<byte> utf8Source)
    Parameters
    Type Name Description
    ReadOnlySpan<byte> utf8Source

    The UTF-8 hexadecimal source.
    Returns
    Type Description
    byte[]

    The decoded byte array.
    Remarks

    Hexadecimal characters are ASCII, so the UTF-8 representation is bit-identical to the character form. This overload avoids allocating a string when the caller already has the input as bytes.

    Exceptions
    Type Condition
    FormatException

    Thrown when the input is not strict hex.
