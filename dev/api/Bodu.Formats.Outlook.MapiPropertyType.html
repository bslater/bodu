    Enum MapiPropertyType

    Specifies the 16-bit MAPI property type codes (the PT_* constants) carried in the low word of a MapiPropertyTag.

    Namespace: Bodu.Formats.Outlook
    Assembly: Bodu.Formats.Outlook.dll
    Syntax
    public enum MapiPropertyType : ushort
    Remarks

    The values are the base type codes defined by MS-OXCDATA §2.11.1. A multi-valued property combines a base code with the 0x1000 flag, which MapiPropertyTag strips from Type and surfaces separately through IsMultiValued.
