Specifies the converter to use for a property, field, or type, taking precedence over the converters configured on the serializer options.

Examples

public sealed class Package
{
    [Converter(typeof(VersionConverter))]
    public Version Version { get; set; } = new(1, 2, 3);
}

// VersionConverter governs the member.

Remarks

The referenced type must derive from the serializer's converter base type and declare a public parameterless constructor. Applied to a member, the converter governs that member only; applied to a type, it governs every use of the type.
