Remarks

ValueRange<TKey, TValue> pairs a half-open range - [StartInclusive, EndExclusive) - with an associated value, in the spirit of KeyValuePair<TKey, TValue> for keyed dictionaries. It is the element type returned by RangeDictionary<TKey, TValue> enumeration and the natural shape for any API that projects keyed ranges.

The public constructor validates that the start endpoint is strictly less than the end endpoint under Default and rejects degenerate or inverted ranges with ArgumentException. Owning collections that have already validated endpoints during insertion may use an internal unchecked overload to avoid re-validating during projection.
