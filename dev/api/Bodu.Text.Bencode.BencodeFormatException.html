    Remarks

    Raised by Read() — and therefore surfaced by BencodeSerializer while deserializing — when the input cannot be interpreted as a valid bencoded document: for example, when an unexpected prefix byte is encountered, an integer is missing its terminating e, a string's length prefix does not fit the remaining bytes, a dictionary's keys are not in lexicographic order, or the document contains trailing bytes after a complete value.

    Malformed input and binding failures are reported separately: catch BencodeFormatException (a FormatException ) for bytes that are not valid Bencode, and BencodeSerializationException for values or documents that cannot be mapped; catch both when the handling should not distinguish the cause.

    Examples
    try
{
    TorrentInfo info = BencodeSerializer.Deserialize<TorrentInfo>(payload);
}
catch (BencodeFormatException ex)
{
    Console.Error.WriteLine($"Malformed bencode at byte {ex.Offset}: {ex.Message}");
}
