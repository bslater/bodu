    Enum TransformMode

    Defines the direction of a cryptographic transformation.

    Namespace: Bodu.Security.Cryptography
    Assembly: Bodu.Security.Cryptography.dll
    Syntax
    public enum TransformMode
    Remarks

    Used by helper APIs that take a single direction argument rather than separate Encrypt / Decrypt overloads. The lower-level Transform(ReadOnlySpan<byte>, Span<byte>, bool) uses a bool instead because the transform contract predates this enumeration; either representation expresses the same choice.

    Fields

    Name Description
    Encrypt

    Indicates that the transform should encrypt plaintext into ciphertext.
    Decrypt

    Indicates that the transform should decrypt ciphertext into plaintext.
