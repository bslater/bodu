Represents a single read-only value within a TomlDocument. The element is a lightweight view - a pair of the owning document and a row index - so copying it is cheap and never materializes a node.

Remarks

An element is valid only for the lifetime of its owning TomlDocument. After the document is disposed, any member access throws ObjectDisposedException.

TOML defines eight scalar value kinds - string, integer, float, Boolean, and four date/time forms - alongside arrays and tables. Each scalar accessor returns the value decoded once during parsing and throws InvalidOperationException when invoked on an element of a different kind. 

using TomlDocument document = TomlDocument.Parse("""
    name = "orders"
    port = 8080
    tags = ["a", "b"]
    """);

TomlElement root = document.RootElement;
var name = root.GetProperty("name").GetString();       // "orders"
var port = root.GetProperty("port").GetInt64();        // 8080

foreach (TomlElement tag in root.GetProperty("tags").EnumerateArray())
{
    // "a", "b"
}

WriteTo(Utf8TomlWriter)

Writes this element's value to the supplied writer at the writer's current position.

public void WriteTo(Utf8TomlWriter writer)

Parameters

writer Utf8TomlWriter

The destination writer.

Remarks

A scalar element writes its decoded value, an array writes its elements in order, and a table writes its key/value pairs in stored order. The writer's own state machine governs where a value may be written, so a non-table element cannot be written at a TOML document root.

Exceptions

InvalidOperationException

Thrown when this element is the default value and belongs to no document.

ObjectDisposedException

Thrown when the owning document has been disposed.
