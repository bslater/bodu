    Method RotateBitsLeft

    RotateBitsLeft(byte, int)

    Rotates the bits of the specified byte value to the left by the specified number of positions.

    Declaration
    public static byte RotateBitsLeft(this byte value, int count)
    Parameters
    Type Name Description
    byte value

    The 8-bit unsigned value whose bits are to be rotated.
    int count

    The number of positions to rotate. Must be in the range [0, 8]. A count of 0 or 8 is a no-op.
    Returns
    Type Description
    byte

    A byte with the bits of value rotated left by count positions.
    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    count is less than 0 or greater than 8.

    RotateBitsLeft(uint, int)

    Rotates the bits of the specified uint value to the left by the specified number of positions.

    Declaration
    public static uint RotateBitsLeft(this uint value, int count)
    Parameters
    Type Name Description
    uint value

    The 32-bit unsigned integer whose bits are to be rotated.
    int count

    The number of positions to rotate. Must be in the range [0, 32]. A count of 0 or 32 is a no-op.
    Returns
    Type Description
    uint

    A uint with the bits of value rotated left by count positions.
    Remarks

    Delegates to RotateLeft(uint, int) after validation, allowing the JIT to lower the rotation to a single CPU instruction on supported platforms.

    Type Condition
    ArgumentOutOfRangeException
