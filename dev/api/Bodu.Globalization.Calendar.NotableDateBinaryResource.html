Remarks

A pack is written from an already-built resource, so only content that passed the canonical loader's validation is ever encoded, and reading a pack skips parsing and validation entirely - the trim- and AOT-friendly load path. The format is sealed: it enumerates the engine's strategy, recurrence, and duration types exhaustively with one-byte discriminators, carries no type names and no extension points, and the reader rejects unknown versions, unknown discriminators, undefined enum values, out-of-range references, truncation, and payload-digest mismatches with NotableDateBinaryFormatException.

Writing is byte-stable: the same resource always produces the same bytes, so build systems can use pack outputs for up-to-date checks.
