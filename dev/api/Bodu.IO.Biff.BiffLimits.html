    Defines the structural limits of the BIFF record format.

    Remarks

    The per-version maximum payload is enforced by BiffWriter and tolerated, not enforced, by BiffReader, which frames any length the 16-bit field can express. DefaultCodePage is assumed for BIFF5 byte strings until a CODEPAGE record is read, and UnicodeCodePage is the value a BIFF8 CODEPAGE record carries.

    Fields

    Name Description
    AbsoluteMaxPayloadLength

    The largest payload the 16-bit length field can express, in bytes. A reader tolerates declared lengths up to this value; a writer enforces the per-version maximum.
    Biff5MaxPayloadLength

    The largest payload a BIFF5 record may declare, in bytes.
    Biff8MaxPayloadLength

    The largest payload a BIFF8 record may declare, in bytes.
    DefaultCodePage

    The default code page assumed for byte strings when no CODEPAGE record has been read (Windows-1252).
    RecordHeaderSize

    The size, in bytes, of a record header: a 16-bit identifier followed by a 16-bit payload length.
    UnicodeCodePage

    The code page value a BIFF8 CODEPAGE record carries to declare UTF-16LE text.
