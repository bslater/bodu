Provides a high-performance, forward-only reader for delimited (RFC 4180 CSV/TSV) bytes. The reader is a ref struct, so it lives on the stack and cannot be boxed or captured.

Remarks

A delimited document is an array of records. A call to Read() advances to the next token and reports it through TokenType: a document StartArray frames the records; with a header each record is an object (StartObject plus PropertyName / String pairs), and without a header each record is a positional array of String fields.

Fields are decoded on demand through GetString(): surrounding quotes are removed and doubled quotes are collapsed to a single literal. ValueSpan exposes the raw source bytes of a field value.
