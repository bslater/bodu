Examples

DayOfWeekSet fourDayWeek = DayOfWeekSet.Weekdays.Without(DayOfWeek.Friday);

bool working = fourDayWeek.Contains(DateTime.Today.DayOfWeek);
string text = fourDayWeek.ToString(); // "_MTWT__"
bool same = DayOfWeekSet.Parse(text) == fourDayWeek; // true

Remarks

A DayOfWeekSet holds one bit per day, so it never allocates, and testing, adding or removing a day, or combining two sets with |, &, ^ and ~, is a single bitwise operation. Contains(DayOfWeek) answers false for a value outside the seven days rather than throwing, which keeps a membership test against DayOfWeek to a comparison and a bit test.

The text form is a seven-character mask with one character per day, the day's letter when it is selected and _ when it is not, Sunday first: "_MTWTF_" selects Monday to Friday. ToString(string?) can also write the mask Monday first, with another placeholder, or in binary ("0111110"), and Parse(string) reads any of those forms. TryFormat(Span<char>, out int, ReadOnlySpan<char>, IFormatProvider?) writes the same text into a span of characters, its other overload into a span of UTF-8 bytes, and the span and UTF-8 overloads of Parse, TryParse, ParseExact and TryParseExact read it.

ToUInt64() and FromUInt64(ulong) expose the bits directly: bit n selects (DayOfWeek)n, so Sunday is bit 0 and Saturday bit 6.

The presets are Weekdays, Weekend, and one for each of the seven named working weeks of WorkingDaysOfWeek. Its two other values have no preset: AllDays corresponds to All, and Custom has no set.

Remarks

The text has one character per day. A day's letter, in either case, selects the day, and _, -, * or a space leaves it out; one placeholder is used throughout. The letters show whether the mask starts on Sunday or on Monday, the first letter that fits only one of the two orders deciding. A mask that begins with 0 or 1 is the binary form, Sunday first, with 1 for a selected day.

One mask fits both orders: "______S", whose only letter is a final S, is Saturday Sunday first and Sunday Monday first. It is read Sunday first, as ToString() writes it; read Monday-first text with ParseExact(string, string) and the "M" format.

Anything else, an abbreviated list of days such as "MF" included, is not a mask.

Exceptions

ArgumentNullException

Thrown when s is null.

Thrown when s is not a seven-character mask.
