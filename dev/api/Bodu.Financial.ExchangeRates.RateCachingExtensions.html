    Name Description
    AddAggregatedRateProvider(IFinancialServiceBuilder, Action<IAggregatedRateBuilder>, IConfiguration?, string, Action<CachingRateOptions>?)

    Registers an AggregatingRateProvider that groups the cached children added through configure, resolvable as both IDatedRateProvider and the timeless IRateProvider. Each child is also registered as a keyed IDatedRateProvider so a specific source can be resolved by name.
    AddCachedRateProvider<TProvider>(IFinancialServiceBuilder, string, IConfiguration?, string, Action<CachingRateOptions>?, Func<IServiceProvider, string, IRateCache>?)

    Registers a CachingRateProvider that wraps a single source TProvider over its own on-disk cache, resolvable as both IDatedRateProvider and the timeless IRateProvider.
