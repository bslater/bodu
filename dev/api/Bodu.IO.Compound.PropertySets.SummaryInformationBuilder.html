    Class SummaryInformationBuilder

    Authors a standard summary-information property set, producing an OlePropertySet that can be embedded as the \x05SummaryInformation stream of a compound file.

    Remarks

    Each property is optional; only the properties that are set are written. The result reads back through SummaryInformation.
