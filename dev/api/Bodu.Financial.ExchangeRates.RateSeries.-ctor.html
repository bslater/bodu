    Parameters
    Type Name Description
    CurrencyPair pair

    The currency pair this series describes.
    string provider

    The non-empty identifier of the publishing source.
    IEnumerable<(DateOnly Date, decimal Rate)> rates

    The observations to include. Must contain at least one entry and must not contain duplicate dates.
    DateTimeOffset? fetchedAtUtc

    The UTC instant at which the load that produced this series downloaded its source data, or null when not tracked.
    Exceptions
    Type Condition
    ArgumentNullException

    Thrown if provider or rates is null.
    ArgumentException

    Thrown if provider is empty or white-space, if rates is empty, or if it contains duplicate dates.
    ArgumentOutOfRangeException

    Thrown if any rate in rates is zero or negative.
