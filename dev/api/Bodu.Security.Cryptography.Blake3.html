    Class Blake3

    AVX-512 vectorised implementation of the BLAKE3 compression function. The 16-word working state is laid out as four Vector128<T> rows (a, b, c, d), so the four parallel G calls in each column step collapse into a single SIMD G operation. The diagonal step reuses the same kernel by shifting the b, c, d rows by 1/2/3 lanes via PSHUFD, running G, then shifting back — the canonical ChaCha-style vectorisation pattern that BLAKE3 inherits from BLAKE2.

    Remarks

    Gated on IsSupported because the rotations use the AVX-512VL VPRORD variant on Vector128<T>. The SIMD G kernel is identical to Blake2s's because BLAKE3 reuses the same four rotation amounts (16, 12, 8, 7); only the round count, message schedule, and finalization differ.

    Examples
    using var blake3 = new Blake3();
byte[] digest = blake3.ComputeHash(message);
