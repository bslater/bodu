Remarks

This exception reports a binding-level failure and is distinct from TomlFormatException, which reports that the source text was not well-formed TOML. When the failure can be traced to a member, the Path carries the dotted path to it; when it can be traced to a position in the source, the Offset, LineNumber, and ColumnNumber carry the position.
