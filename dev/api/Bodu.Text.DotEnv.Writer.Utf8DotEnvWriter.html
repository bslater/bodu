Struct Utf8DotEnvWriter

Provides a high-performance, forward-only writer that emits DotEnv text as UTF-8 bytes to an IBufferWriter<T> or a Stream. The writer is a ref struct, so it lives on the stack and cannot be boxed or captured.

Remarks

DotEnv is line-oriented, so the writer emits progressively: WritePropertyName(string) followed by WriteString(string) produces one KEY=VALUE line, and WriteComment(string) produces one # comment line. WriteStartObject() and WriteEndObject() frame the document to mirror the reader's token stream but emit no bytes of their own.

A value is emitted unquoted when it is safe to do so; a value that is empty is left after the =, and a value containing whitespace at its edges, an inline-comment sequence, a quote, a backslash, or a line break is double-quoted with the necessary escape sequences so a subsequent read round-trips it exactly.
