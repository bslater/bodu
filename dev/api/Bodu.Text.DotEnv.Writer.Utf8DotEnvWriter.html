    Struct Utf8DotEnvWriter

    Provides a high-performance, forward-only writer that emits DotEnv text as UTF-8 bytes to an IBufferWriter<T> or a Stream. The writer is a ref struct, so it lives on the stack and cannot be boxed or captured.

    Remarks

    DotEnv is line-oriented, so the writer emits progressively: WritePropertyName(string) followed by WriteString(string) produces one KEY=VALUE line, and WriteComment(string) produces one # comment line. WriteStartObject() and WriteEndObject() frame the document to mirror the reader's token stream but emit no bytes of their own.

    A value is emitted unquoted when it is safe to do so; a value that is empty is left after the =, and a value containing whitespace at its edges, an inline-comment sequence, a quote, a backslash, or a line break is double-quoted with the necessary escape sequences so a subsequent read round-trips it exactly.

    Methods

    Name Description
    Dispose()

    Flushes any buffered bytes and releases the writer.
    Flush()

    Flushes any buffered bytes to the destination stream. This method is a no-op in direct buffer-writer mode.
    WriteComment(string)

    Writes a comment line prefixed with #, followed by a line feed.
    WriteEndObject()

    Writes the document object end. DotEnv has no object delimiter, so this method emits no bytes; it exists to mirror the reader's token stream.
    WritePropertyName(string)

    Writes a key name, followed by the = assignment. Call WriteString(string) next to write the value.
    WritePropertyName(string, bool)

    Writes a key name with an explicit export decision, followed by the = assignment. Call WriteString(string) next to write the value.
    WriteStartObject()

    Writes the document object start. DotEnv has no object delimiter, so this method emits no bytes; it exists to mirror the reader's token stream.
    WriteString(string)

    Writes a string value, quoting and escaping it when required, followed by a line feed.
