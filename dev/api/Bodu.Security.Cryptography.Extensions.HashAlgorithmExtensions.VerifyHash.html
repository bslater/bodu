    Method VerifyHash

    VerifyHash(HashAlgorithm, byte[], byte[])

    Verifies that the computed hash of the input data matches the expected hash value.

    Declaration
    public static bool VerifyHash(this HashAlgorithm algorithm, byte[] input, byte[] expectedHash)
    Parameters
    Type Name Description
    HashAlgorithm algorithm

    The HashAlgorithm instance used to compute the hash. Must not be null.
    byte[] input

    The input byte array whose hash will be computed. Must not be null.
    byte[] expectedHash

    The expected hash value as a byte array. Must not be null.
    Returns
    Type Description
    bool

    true if the computed hash equals expectedHash; otherwise, false.
    Remarks

    Comparison is performed using FixedTimeEquals(ReadOnlySpan<byte>, ReadOnlySpan<byte>) to mitigate timing side-channel attacks.

    Exceptions
    Type Condition
    ArgumentNullException

    Thrown if algorithm, input, or expectedHash is null.

    VerifyHash(HashAlgorithm, byte[], string)

    Verifies that the computed hash of the input data matches the expected hash value expressed as a hexadecimal string.

    Declaration
    public static bool VerifyHash(this HashAlgorithm algorithm, byte[] input, string expectedHex)
    Parameters
    Type Name Description
    HashAlgorithm algorithm

    The HashAlgorithm instance used to compute the hash. Must not be null.
    byte[] input

    The input byte array whose hash will be computed. Must not be null.
    string expectedHex

    The expected hash value as a hexadecimal string. Case-insensitive. Must not be null.
    Returns
    Type Description
    bool

    true if the computed hash matches expectedHex; otherwise, false. Returns false if expectedHex is not a valid hexadecimal string.
    Remarks

    expectedHex is decoded to bytes before comparison. The comparison is then performed using FixedTimeEquals(ReadOnlySpan<byte>, ReadOnlySpan<byte>) to mitigate timing side-channel attacks.

    A malformed expectedHex string (one that cannot be decoded) is treated as a non-match and returns false.

    Exceptions
    Type Condition
    ArgumentNullException

    Thrown if algorithm, input, or expectedHex is null.

    VerifyHash(HashAlgorithm, ReadOnlySpan<byte>, ReadOnlySpan<byte>)

    Verifies that the computed hash of the input span matches the expected hash span.

    Declaration
    public static bool VerifyHash(this HashAlgorithm algorithm, ReadOnlySpan<byte> input, ReadOnlySpan<byte> expectedHash)
    Parameters
    Type Name Description
    HashAlgorithm algorithm

    The HashAlgorithm used to compute the hash. Must not be null.
    ReadOnlySpan<byte> input

    The input span of bytes to hash.
    ReadOnlySpan<byte> expectedHash

    The expected hash as a read-only span of bytes.
    Returns
    Type Description
    bool

    true if the computed hash equals expectedHash; otherwise, false.
    Remarks

    This overload uses TryComputeHash(ReadOnlySpan<byte>, Span<byte>, out int) with an ArrayPool<T>-backed output buffer to avoid heap allocation for the computed hash. The buffer is cleared before being returned to the pool.

    Comparison is performed using FixedTimeEquals(ReadOnlySpan<byte>, ReadOnlySpan<byte>) to mitigate timing side-channel attacks.

    Exceptions
    Type Condition
    ArgumentNullException

    Thrown if algorithm is null.
