    Class AdjustmentScope

    Constrains where a reusable adjustment policy may apply: by territory, calendar, category, notable-date concept, or specific rule.

    Remarks

    Each dimension is independent. A dimension with no entries imposes no restriction; a dimension with entries requires the candidate value to be one of them. An empty scope therefore matches every rule, while a populated scope must satisfy every populated dimension.
