    Create(Stream, bool, CompoundBuildOptions)

    Creates a new, empty writable compound file whose staged contents are written to the supplied destination by Commit().

    Declaration
    public static CompoundFile Create(Stream destination, bool leaveOpen = false, CompoundBuildOptions options = default)
    Parameters
    Type Name Description
    Stream destination

    The stream the committed compound file is written to.
    bool leaveOpen

    true to leave destination open when the returned instance is disposed; otherwise false.
    CompoundBuildOptions options

    The build options applied when the staging tree is serialized.
    Returns
    Type Description
    CompoundFile

    A new writable CompoundFile.
    Remarks

    Edits made through RootStorage are staged in memory; nothing is written to destination until Commit() is called. Disposing the file without committing discards the staged edits.

    Examples
    using FileStream output = File.Create("book.xls");
using CompoundFile file = CompoundFile.Create(output);
using (CompoundStream stream = file.RootStorage.CreateStream("Workbook"))
    stream.Write(workbookBytes);
file.Commit();
    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when destination is null.

    Create(string, CompoundBuildOptions)

    Creates a new, empty writable compound file whose staged contents are written to the file at the specified path by Commit().

    Declaration
    public static CompoundFile Create(string path, CompoundBuildOptions options = default)
    Parameters
    Type Name Description
    string path

    The path of the file the committed compound file is written to.
    CompoundBuildOptions options

    The build options applied when the staging tree is serialized.
    Returns
    Type Description
    CompoundFile

    A new writable CompoundFile.
    Remarks

    The returned instance owns the created file and closes it when disposed. Edits are staged in memory until Commit() is called; disposing without committing leaves the file empty.

    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when path is null.
