    Method LastDateOfWeek

    LastDateOfWeek(DateOnly)

    Returns a new DateOnly representing the last day of the week that contains the specified date, using the last day of the week defined by CurrentCulture.

    Declaration
    public static DateOnly LastDateOfWeek(this DateOnly date)
    Parameters
    Type Name Description
    DateOnly date

    The date value used to determine the containing week.
    Returns
    Type Description
    DateOnly

    A DateOnly value set to the culturally defined last day of the week containing date.
    Remarks

    This overload uses CurrentCulture to determine the last day of the week, inferred from FirstDayOfWeek.

    LastDateOfWeek(DateOnly, CultureInfo?)

    Returns a new DateOnly representing the last day of the week that contains the specified date, using the last day of the week defined by the supplied or current culture.

    Declaration
    public static DateOnly LastDateOfWeek(this DateOnly date, CultureInfo? culture)
    Parameters
    Type Name Description
    DateOnly date

    The date value used to determine the containing week.
    CultureInfo culture

    An optional CultureInfo that defines the first day of the week via FirstDayOfWeek. If null, CurrentCulture is used.
    Returns
    Type Description
    DateOnly

    A DateOnly value set to the culturally defined last day of the week containing date.
    Remarks

    This method computes the day offset between date and the culture-specific last day of the week, and adds that offset.

    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown if the resulting date is later than MaxValue.

    LastDateOfWeek(DateOnly, WorkingDaysOfWeek)

    Returns a new DateOnly representing the last day of the week that contains the specified date, using a start-of-week inferred from the specified WorkingDaysOfWeek.

    Declaration
    public static DateOnly LastDateOfWeek(this DateOnly date, WorkingDaysOfWeek workingWeek)
    Parameters
    Type Name Description
    DateOnly date

    The date value used to determine the containing week.
    WorkingDaysOfWeek workingWeek

    A WorkingDaysOfWeek used to infer the last day of the week. For example, MondayToFriday implies a Monday start (and therefore a Sunday end).
    Returns
    Type Description
    DateOnly

    A DateOnly value set to the last day of the week containing date.
    Remarks

    The method infers the start of the week based on the specified workingWeek value, then calculates the last day as six days after the inferred start. If AllDays is supplied, the method defaults to using Monday.

    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown if workingWeek is not a defined WorkingDaysOfWeek value, -or- the resulting date is later than MaxValue.
