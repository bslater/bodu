Represents a decoded FILEPASS record: the protection scheme applied to the records that follow it. The codec reports the scheme and the XOR parameters; it does not decrypt.

Remarks

BIFF5 carries only the XOR key and hash. BIFF8 prefixes a type word: zero selects the same XOR pair, one selects RC4, whose header the codec leaves uninterpreted.
