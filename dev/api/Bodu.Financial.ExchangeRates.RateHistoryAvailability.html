Remarks

A provider advertises its history depth through this value so a caller can know, before requesting an old date, whether the provider can satisfy it. A feed that publishes only the recent past (for example, an anonymous endpoint capped to roughly the last six months) declares a Rolling window; a feed with a fixed inception date declares Since; a feed with no known floor declares Unbounded.

The value is advisory: it describes the provider's published coverage, not a guarantee that every day in range carries an observation (weekends and holidays may still be absent). It bounds only the earliest date worth requesting.
