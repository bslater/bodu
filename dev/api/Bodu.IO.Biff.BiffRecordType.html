Identifies the BIFF record types the codec names. Values are the 16-bit record identifiers defined by the Excel binary file format and are shared by BIFF5 and BIFF8 except where a member's documentation says otherwise.

Remarks

The enumeration is a curated catalogue, not the full record set: a record whose identifier is not listed here is still readable through RecordId and ValueSpan, and can be written through WriteRecord(ushort, scoped ReadOnlySpan<byte>). Encountering an unlisted identifier is never an error.
