    Class DelimitedSerializer

    Provides methods for serializing collections of .NET records to delimited (RFC 4180 CSV/TSV) text and deserializing delimited text into records, shaped after System.Text.Json's JsonSerializer.

    Remarks

    A delimited document is an array of records, so the serializer maps an IEnumerable<T> whose element type is a POCO (mapped column-by-column to the header) or a positional string array. Column names honour PropertyNamingPolicy and the PropertyNameAttribute family.

    The buffered stream overloads mirror the sibling quartet libraries. The DeserializeAsyncEnumerableAsync<TRecord>(Stream, DelimitedSerializerOptions?, CancellationToken) and the IAsyncEnumerable<T> serialize overload are truly incremental: records are parsed and yielded as stream chunks arrive, and written and flushed in bounded batches, so neither surface materializes the document.
