Provides methods for serializing collections of .NET records to delimited (RFC 4180 CSV/TSV) text and deserializing delimited text into records, shaped after System.Text.Json's JsonSerializer.

Remarks

A delimited document is an array of records, so the serializer maps an IEnumerable<T> whose element type is a POCO (mapped column-by-column to the header) or a positional string array. Column names honour PropertyNamingPolicy and the PropertyNameAttribute family.

The buffered stream overloads mirror the sibling quartet libraries. The DeserializeAsyncEnumerableAsync<TRecord>(Stream, DelimitedSerializerOptions?, CancellationToken) and the IAsyncEnumerable<T> serialize overload are truly incremental: records are parsed and yielded as stream chunks arrive, and written and flushed in bounded batches, so neither surface materializes the document.

Remarks

The stream is consumed in segments: only the bytes of records not yet terminated remain buffered, so memory use is bounded by the longest single record rather than the document. A record that ends exactly at the current buffer boundary is held back until the next segment (or the end of the stream) proves it complete, because more fields could still follow. A malformed tail is retried as later segments arrive and only surfaces as a DelimitedFormatException once the end of the stream confirms it.

Returns

ValueTask

A task that completes when all records have been written.

Type Parameters

TRecord

The record type.

Remarks

The sequence is never materialized: each record is encoded as it is produced and flushed to destination in bounded batches, so memory use is independent of the sequence length. The header row (for a POCO record type, unless NoHeader is set) is emitted before the first record.

Exceptions

ArgumentNullException

Thrown when destination or records is null.
