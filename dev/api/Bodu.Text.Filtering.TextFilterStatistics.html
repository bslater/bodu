    Class TextFilterStatistics

    Represents an immutable snapshot of a TextFilter's accumulated evaluation statistics, obtained via GetStatistics().

    Remarks

    Counter totals reconcile: ItemsEvaluated equals ItemsAccepted + ItemsExcluded + ItemsNotIncluded. Under concurrent evaluation the counters may undercount (they are deliberately not interlocked to keep the evaluation path cheap); matching results themselves are always exact.

    Properties

    Name Description
    EvaluationTime

    Gets the accumulated time spent evaluating values.
    ItemsAccepted

    Gets the number of evaluated values that were accepted — the sum of the IncludedByDefault and Included outcomes.
    ItemsEvaluated

    Gets the total number of values evaluated since the filter was built or its statistics were last reset.
    ItemsExcluded

    Gets the number of evaluated values rejected by an exclude pattern (the Excluded outcome).
    ItemsNotIncluded

    Gets the number of evaluated values rejected because include patterns exist and none matched (the NotIncluded outcome).
    Patterns

    Gets the per-pattern statistics, ordered as the patterns were declared.
    RegexTimeouts

    Gets the number of pattern evaluations that timed out in the regular-expression engine and were decided fail-safe (a timed-out include treated as not matching; a timed-out exclude treated as matching).
