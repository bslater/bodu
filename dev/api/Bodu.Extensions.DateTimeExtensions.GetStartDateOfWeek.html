    Method GetStartDateOfWeek

    GetStartDateOfWeek(int, int, CultureInfo?)

    Returns a new DateTime representing the first day of the specified culture-defined week number in the given calendar year.

    Declaration
    public static DateTime GetStartDateOfWeek(int year, int week, CultureInfo? culture = null)
    Parameters
    Type Name Description
    int year

    The calendar year to evaluate. Must be between the Year property values of MinValue and MaxValue, inclusive.
    int week

    The culture-defined week number to evaluate, starting at 1. The maximum valid value depends on the CalendarWeekRule and DayOfWeek used by the supplied culture.
    CultureInfo culture

    An optional CultureInfo used to determine the CalendarWeekRule and starting DayOfWeek. If null, CurrentCulture is used.
    Returns
    Type Description
    DateTime

    An object whose value is set to midnight (00:00:00) on the first date of the specified week in the specified year, using Unspecified.
    Remarks

    This method uses the culture-defined week numbering system. The start of week 1 depends on the culture's CalendarWeekRule: under FirstDay the (possibly partial) first week begins on January 1 itself; under FirstFullWeek it begins at the first occurrence of the culture's FirstDayOfWeek on or after January 1; and under FirstFourDayWeek it begins at the week boundary of the week containing January 1 when at least four days of that week fall in the new year (which may place the start in the previous December), otherwise one week later. Subsequent weeks advance in 7-day intervals from the week-boundary alignment.

    The result is validated by recalculating the week number for the computed date using the internal week-of-year calculation and comparing it to week. Dates that fall in the previous calendar year (such as the start of ISO week 1 in late December) are handled correctly.

    The returned value is normalized to midnight (00:00:00) and uses Unspecified.

    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown if year is less than the Year of MinValue or greater than that of MaxValue, -or- week does not correspond to a valid week number for year under the rules of the supplied or current culture.
