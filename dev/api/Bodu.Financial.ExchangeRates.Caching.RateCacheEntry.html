ObservedAtUtc

Gets or sets the UTC instant the upstream data backing the rate was originally fetched, or null when the source did not supply it.

public DateTimeOffset? ObservedAtUtc { get; set; }

Property Value

DateTimeOffset?

The upstream fetch instant, or null when not tracked.

Remarks

A cache file written before this field was tracked has no ObservedAtUtc key; it deserializes to null with no error, mirroring how a pre-coverage file deserializes its missing [[Coverage]] array, so older caches remain readable.
