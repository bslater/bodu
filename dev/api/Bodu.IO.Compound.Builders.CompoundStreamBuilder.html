Remarks

This is the authoring counterpart of CompoundStream and the compound-file analogue of a JsonValue leaf.

A stream node is either in-memory, holding its bytes directly, or deferred, holding a re-openable source (a file or a stream factory) of a known length. A deferred node lets large payloads be streamed straight to the output during serialization without ever being held in memory; reading Content on such a node materializes it.

Remarks

Reading this property on a deferred node opens and reads its source fully into memory; thereafter the node is in-memory. Setting the property replaces the payload and makes the node in-memory.
