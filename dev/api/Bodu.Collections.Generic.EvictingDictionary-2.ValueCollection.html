Remarks

The collection reflects subsequent mutations to the underlying dictionary. Enumeration order follows the current EvictingDictionaryPolicy. The collection is read-only; Add(T), Clear(), and Remove(T) throw NotSupportedException.

Parameters

array TValue[]

The one-dimensional Array that is the destination of the elements copied from ICollection<T>. The Array must have zero-based indexing.

arrayIndex int

The zero-based index in array at which copying begins.

Remarks

The shared copy loop validates the argument shape before purging expired entries, so a caller error cannot trigger evictions or raise the eviction events; the purge then runs before the range check so the count validated matches the elements written.

ArgumentOutOfRangeException
