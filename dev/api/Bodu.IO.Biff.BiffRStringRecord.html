    Struct BiffRStringRecord

    Represents a decoded RSTRING record: a BIFF5 rich-text label cell — a 16-bit-length code-page byte string followed by a run table of two-byte entries (character index, font index).

    Remarks

    BIFF8 superseded the record with rich runs inside the shared string table; a BIFF8 stream may still carry it for compatibility, in which case the text is still a byte string in the stream's code page.
