Property Value

TextFilterPattern

The deciding pattern, or null when the decision is IncludedByDefault or NotIncluded. In AnyMatch mode, when several patterns could have matched, the reported pattern is one of them (the cheapest to evaluate), not necessarily the first declared; in LastMatchWins mode it is exactly the last matching rule.
