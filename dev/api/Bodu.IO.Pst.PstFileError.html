    Enum PstFileError

    Categorizes the failure a PstFileException reports, so callers can distinguish a missing object from structural corruption without parsing messages.

    Namespace: Bodu.IO.Pst
    Assembly: Bodu.IO.Pst.dll
    Syntax
    public enum PstFileError

    Fields

    Name Description
    None

    No category was recorded.
    InvalidHeader

    The file header is malformed.
    UnsupportedFormat

    The file uses a recognized but unsupported variant.
    InvalidPage

    A B-tree page is malformed or fails validation.
    InvalidBlock

    A block's geometry or trailer is invalid, or a read escapes the file.
    InvalidDataTree

    A multi-block data tree is malformed or references a missing block.
    InvalidSubnodeTree

    A subnode tree is malformed or references a missing subnode.
    InvalidHeap

    A heap-on-node structure is malformed.
    InvalidPropertyContext

    A property context is malformed.
    InvalidTableContext

    A table context is malformed.
    InvalidPropertyValue

    A property value reference does not resolve.
    NodeNotFound

    The requested node does not exist.
    PropertyNotFound

    The requested property does not exist.
    LimitExceeded

    A structure's declared size or fan-out exceeds a resource limit the session was opened with (see MaxNodeDataLength and MaxDataTreeLeaves).
