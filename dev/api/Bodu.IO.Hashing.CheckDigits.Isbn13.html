Examples

// Single-call computation against the 12-digit body.
char check = Isbn13.Compute("978030640615");   // '7'

// Full-sequence validation.
bool ok = Isbn13.IsValid("9780306406157");     // true

// Streaming use when the body is built up incrementally.
var algo = new Isbn13();
algo.Append("978030640615");
char d = algo.GetCurrentCheckDigit();          // '7'

Remarks

The ISBN-13 check scheme, introduced in 2007 by the International ISBN Agency, alternates weights of 1 and 3 across the twelve body digits - the rightmost data digit receives weight 3 - and the check digit is chosen so that the resulting weighted sum is a multiple of ten.

The same algorithm underpins the EAN-13, UPC-A, GTIN-8, and GTIN-14 barcode families - see Ean13 and its siblings for strict-length variants.

Worked example. For the body "978030640615", the computed check digit is '7', and the resulting ISBN-13 "9780306406157" is therefore valid.

important

This algorithm is not cryptographically secure and should not be used for password hashing, digital signatures, or integrity validation in security-sensitive applications.
