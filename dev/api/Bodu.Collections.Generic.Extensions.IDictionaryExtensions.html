IDictionaryExtensions.AddOrUpdate.cs

Provides retrieval-and-mutation helpers for IDictionary<TKey, TValue> - get-or-add and add-or-update operations modelled on the ConcurrentDictionary<TKey, TValue> surface but available on any dictionary implementation.

Remarks

IDictionary<TKey, TValue> exposes only primitive lookup and mutation members, so callers routinely hand-roll the "return the existing value or insert a new one" pattern. This class collects those patterns behind verb-led names.

These helpers perform no synchronization. On a dictionary shared between threads the caller must provide external synchronization; they are not a substitute for ConcurrentDictionary<TKey, TValue> when concurrent access is required.

Inserts value under key, or replaces the existing value when the key is already present.

Remarks

The operation is unconditional: it has the same effect as the indexer assignment dictionary[key] = value, and exists to state the add-or-update intent explicitly at the call site.
