    Method MapAsync

    MapAsync<T, TResult>(Task<Result<T>>, Func<T, TResult>)

    Asynchronously projects the value carried by the awaited result using the specified selector.

    Declaration
    public static Task<Result<TResult>> MapAsync<T, TResult>(this Task<Result<T>> source, Func<T, TResult> selector)
    Parameters
    Type Name Description
    Task<Result<T>> source

    The task producing the result to project. Must not be null.
    Func<T, TResult> selector

    The projection applied to the carried value.
    Returns
    Type Description
    Task<Result<TResult>>

    A task that completes with Success(selector(value)) when the awaited result represents success; otherwise a failure carrying the original error.
    Type Parameters
    Name Description
    T

    The value type of the source result.
    TResult

    The type produced by the selector.
    Remarks

    The selector is not invoked when the awaited result is a failure. The projected value is lifted through the strict Success<T>(T) factory, so a null projection result throws ArgumentNullException, matching Map<TResult>(Func<T, TResult>). Argument validation runs synchronously, so a null argument faults at the call site rather than on the returned task.

    Exceptions
    Type Condition
    ArgumentNullException

    source or selector is null, or the projection returned null.
