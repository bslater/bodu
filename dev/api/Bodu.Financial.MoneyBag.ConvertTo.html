    ConvertTo<TTarget>(IRateProvider)

    Converts the entire bag to a single target currency by applying the supplied rate provider to every non-target balance and aggregating into the destination precision per SumRawThenRound.

    Declaration
    public Money<TTarget> ConvertTo<TTarget>(IRateProvider rates) where TTarget : ICurrency
    Parameters
    Type Name Description
    IRateProvider rates

    The provider that returns the rate for each (from, to) pair.
    Returns
    Type Description
    Money<TTarget>

    The aggregated Money<TCurrency> total.
    Type Parameters
    Name Description
    TTarget

    The destination currency type.
    Exceptions
    Type Condition
    ArgumentNullException

    rates is null.
    KeyNotFoundException

    rates cannot supply a rate for one of the bag's currencies.
    InvalidOperationException

    A rate returned by rates is zero or negative.
