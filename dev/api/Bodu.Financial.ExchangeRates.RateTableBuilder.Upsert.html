    Method Upsert

    Upsert(CurrencyPair, string, DateOnly, decimal, DateTimeOffset?)

    Upserts an observation into the series identified by pair and provider, creating the series if it does not yet exist.

    Declaration
    public void Upsert(CurrencyPair pair, string provider, DateOnly date, decimal rate, DateTimeOffset? fetchedAtUtc = null)
    Parameters
    Type Name Description
    CurrencyPair pair

    The currency pair.
    string provider

    The non-empty identifier of the publishing source.
    DateOnly date

    The observation date.
    decimal rate

    The rate to record.
    DateTimeOffset? fetchedAtUtc

    The UTC instant at which the load contributing this observation downloaded its source data, or null to leave the series' fetch instant unchanged.
    Remarks

    When supplied, fetchedAtUtc is recorded at the series grain — a property of the load, not of the individual observation — and is stamped onto every ExchangeRate the series materializes. A later upsert carrying a fresh instant overwrites it; passing null leaves any previously recorded instant in place.

    Exceptions
    Type Condition
    ArgumentNullException

    Thrown if provider is null.
    ArgumentException

    Thrown if provider is empty or white-space.
    ArgumentOutOfRangeException

    Thrown if rate is zero or negative.
