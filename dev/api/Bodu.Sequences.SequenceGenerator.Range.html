    Method Range

    Range(int, int)

    Yields consecutive integers from start through stop, walking in whichever direction is implied by the two endpoints.

    Declaration
    public static IEnumerable<int> Range(int start, int stop)
    Parameters
    Type Name Description
    int start

    The first value emitted by the sequence.
    int stop

    The final value emitted by the sequence; this value is included in the output when reached exactly.
    Returns
    Type Description
    IEnumerable<int>

    A lazily evaluated, finite sequence of int values inclusive of both endpoints.
    Remarks

    Prefer this overload over Range(int, int) when the natural way to express the range is "from a to b" rather than "n values starting at a", or when a descending sequence is required — Enumerable.Range only walks forwards and rejects negative counts.

    The step direction is chosen automatically: ascending when start is less than stop, descending otherwise. When start equals stop a single-element sequence is returned.

    Both endpoints are inclusive. The result is deferred — no values are produced until the sequence is enumerated — and the underlying iterator allocates only the per-enumeration state object.

    Examples
    foreach (int n in SequenceGenerator.Range(10, 14))
    Console.Write($"{n} "); // => 10 11 12 13 14

foreach (int n in SequenceGenerator.Range(3, -2))
    Console.Write($"{n} "); // => 3 2 1 0 -1 -2

    Range(int, int, int)

    Yields integers between start and stop inclusive, advancing by step at each iteration.

    Declaration
    public static IEnumerable<int> Range(int start, int stop, int step)
    Parameters
    Type Name Description
    int start

    The first value emitted by the sequence.
    int stop

    The endpoint at which iteration terminates; included in the output when reached exactly.
    int step

    The signed delta applied between successive values. Positive values produce an ascending sequence, negative values produce a descending sequence, and zero produces an unbounded sequence that yields start forever.
    Returns
    Type Description
    IEnumerable<int>

    A lazily evaluated sequence of int values; finite when step is non-zero, otherwise infinite.
    Remarks

    Use this overload when the caller needs explicit control over the stride, including descending ranges and non-unit steps that Range(int, int) cannot express. The two-argument Range(int, int) is more convenient when a step of +1 or -1 is sufficient.

    Iteration is bounded by stop: the inclusive endpoint is yielded only when step divides the interval evenly. If the next value would overflow MaxValue or MinValue the sequence terminates cleanly rather than throwing.

    When step is 0 the method returns an infinite sequence — callers must compose it with an operator such as Take or TakeWhile to bound enumeration.

    The result is deferred and allocation-light; no array or list is materialized.

    Examples
    foreach (int n in SequenceGenerator.Range(0, 20, 5))
    Console.Write($"{n} "); // => 0 5 10 15 20

foreach (int n in SequenceGenerator.Range(10, 1, -3))
    Console.Write($"{n} "); // => 10 7 4 1

// Step of zero yields an unbounded sequence — bound it with Take.
var heartbeat = SequenceGenerator.Range(42, 0, 0).Take(3); // => 42, 42, 42

    Range(long, int)

    Yields a fixed number of consecutive 64-bit integers beginning at start.

    Declaration
    public static IEnumerable<long> Range(long start, int count)
    Parameters
    Type Name Description
    long start

    The first value emitted by the sequence.
    int count

    The number of values to produce. Must be non-negative.
    Returns
    Type Description
    IEnumerable<long>

    A lazily evaluated, finite sequence of long values containing exactly count elements.
    Remarks

    Prefer this overload when the desired output is a count-bounded run of contiguous values, particularly for ranges that exceed the addressable region of Range(int, int) (which is restricted to int).

    A count of 0 produces an empty sequence. The endpoint is exclusive in the sense that the final value emitted is start + count - 1.

    Overflow is rejected up-front by the argument validation, so the iterator never throws mid-enumeration. Iteration is deferred, deterministic, and allocation-free apart from the iterator state.

    Examples
    foreach (long n in SequenceGenerator.Range(1_000_000_000_000L, 4))
    Console.Write($"{n} "); // => 1000000000000 1000000000001 1000000000002 1000000000003

var empty = SequenceGenerator.Range(0L, 0).ToArray(); // => empty.Length == 0
    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown when count is negative, or when the inclusive range [start, start + count - 1] would overflow MaxValue.
