Represents an object in a mutable INI document tree: an insertion-ordered map of names to nodes. The document root maps global keys to IniValue leaves and section names to section IniObject instances; a section maps key names to IniValue leaves only.

Remarks

INI is physically two-level, so depth is enforced when the tree is written: an IniObject nested inside a section raises InvalidOperationException from WriteTo(ref Utf8IniWriter).

When the root is written, its IniValue entries are emitted before its section objects regardless of insertion interleave - a key emitted after a section header would be re-read as belonging to that section, so the global entries must precede the first header.
