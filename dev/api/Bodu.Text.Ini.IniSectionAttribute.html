    Class IniSectionAttribute

    Marks a partial section POCO for compile-time INI binding: the Bodu.Text.Formats.Generators source generator emits an IIniSectionFactory<TSection> implementation for the type, exposed through a generated static IniFactory property.

    Remarks

    The generated factory maps the type's public read/write instance properties in declaration order, honouring PropertyNameAttribute for key names and skipping members annotated with IgnoreAttribute. Scalar values convert with the invariant culture.

    The annotated type must be declared partial so the generator can add the factory to it. Passing the generated factory to the IniSerializer section overloads avoids the reflection binder entirely, making the serialization path trimming- and AOT-safe.
