    Method Release

    Release()

    Returns a single permit to the semaphore, releasing the next waiter if one is queued.

    Exceptions

    Release(int)

    Returns the specified number of permits to the semaphore, releasing queued waiters in FIFO order.

    Declaration
    public void Release(int releaseCount)
    Parameters
    Type Name Description
    int releaseCount

    The number of permits to return.
    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    releaseCount is less than one.
    InvalidOperationException

    Releasing would raise the permit count above the configured maximum. The release is atomic: when this exception is thrown, no waiter has been granted and CurrentCount is unchanged.
