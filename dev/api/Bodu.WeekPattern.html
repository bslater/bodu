Remarks

WeekPattern provides a compact bitmask representation of selected days, supporting non-destructive composition, parsing, formatting, comparison, and enumeration.

Because WeekPattern is a value type, all operations that change the selection return a new instance rather than modifying the receiver. Use With(DayOfWeek) and Without(DayOfWeek) to build patterns incrementally, and the bitwise operators to combine or intersect them. 

Build a pattern for Monday, Wednesday, and Friday
var pattern = WeekPattern.Empty
    .With(DayOfWeek.Monday)
    .With(DayOfWeek.Wednesday)
    .With(DayOfWeek.Friday);

Check membership
bool hasFriday = pattern.Contains(DayOfWeek.Friday); // true

Count selected days
int count = pattern.Count; // 3

Enumerate selected days
foreach (DayOfWeek day in pattern)
    Console.WriteLine(day);

Remarks

A boxed byte is intentionally not considered equal here so that object-level equality stays symmetric: Equals(object) can never recognize a boxed WeekPattern, so treating the reverse comparison as equal would violate the reflexive-symmetric contract of Equals(object) and corrupt hash-based collections. Parse(string)

Converts the string representation of selected days into a WeekPattern, automatically inferring the format.

public static WeekPattern Parse(string input)

Parameters

input string

The input string that represents selected days. Must not be null.

Returns

WeekPattern

A WeekPattern corresponding to the selected days in input.

Remarks

The format is inferred from the length and character patterns of the input. For symbol strings the day ordering is resolved from the first position whose letter is valid in only one layout.

One symbol form is genuinely ambiguous: a string whose only day letter is an 'S' in the final position ("______S") is a valid Saturday-only pattern in Sunday-first order and a valid Sunday-only pattern in Monday-first order. Auto-detection resolves it as the Sunday-first reading (Saturday-only), matching the ordering produced by the default ToString(). Strings produced with the explicit Monday-first format should be parsed with ParseExact(string, string) and the "M" format, which is the unambiguous round-trip partner of ToString("M").

Exceptions

ArgumentNullException

Thrown if input is null.

FormatException

Thrown if input is incorrectly formatted or cannot be parsed.

Parameters

format string

A format string determining day ordering and the unselected-day placeholder. Supported values:

  • 'S' or 's' — Sunday-to-Saturday; unselected = '_'.
  • 'M' or 'm' — Monday-to-Sunday; unselected = '_'.
  • 'E', 'U', 'D', 'A' — Sunday-to-Saturday with space, underscore, dash, or asterisk for unselected days respectively.
  • '0', '1', 'B', or "01" — Binary: '1' selected, '0' unselected.
  • Two-character format: first character 'S' or 'M' for day ordering; second character 'E', 'U', 'D', or 'A' for the unselected placeholder.
