    Class CheckValueAlgorithm

    Represents the common root of the check-digit algorithm family, unifying the streaming surface shared by CheckDigitAlgorithm (decimal bodies, single check digit), AlphanumericCheckDigitAlgorithm (alphanumeric bodies, single check character), and MultiCharCheckDigitAlgorithm (multi-character check codes).

    Remarks

    Every algorithm in the family absorbs body characters through Append(ReadOnlySpan<char>), restarts through Reset(), and exposes its current check value non-destructively. This root makes that shared contract polymorphic: GetCurrentCheckValue() returns the check value as a string of length CheckLength regardless of which branch of the family the concrete algorithm belongs to, so callers can validate heterogeneous identifier formats through a single reference type.

    The intermediate base classes retain their more precise result surfaces — GetCurrentCheckDigit() returning a char on the single-character branches and GetCurrentCheckDigits(Span{char}) on the multi-character branch — and implement GetCurrentCheckValue() by delegation.

    Instances are not thread-safe. Each thread that needs a running check should construct its own instance.

    important

    Check-digit algorithms are error-detection primitives, not cryptographic functions. They must not be used for password hashing, digital signatures, or integrity validation in security-sensitive applications.
