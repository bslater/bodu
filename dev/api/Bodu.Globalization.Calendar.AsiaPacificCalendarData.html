Examples

// Query public holidays for Western Australia.
NotableDateService service = AsiaPacificCalendarData.CreateService("AU-WA");
DateRange year = new(new DateOnly(2026, 1, 1), new DateOnly(2026, 12, 31));
IReadOnlyList<NotableDate> holidays = service.Resolve(year, "AU-WA");

Remarks

Each supported country is a self-contained embedded resource. A territory may be a country code (AU) or a subdivision (AU-WA); the subdivision selects the same country resource, and the resolver filters by the full territory at query time.

When to use. Call CreateService(string) for a ready-to-query NotableDateService, or LoadResource(string) when you need the underlying NotableDateResource to compose with custom collaborators or providers.
