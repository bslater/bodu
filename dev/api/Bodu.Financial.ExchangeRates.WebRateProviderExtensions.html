    Remarks

    Each provider's dependency-injection package calls one of the AddWebRateProvider overloads to handle the common plumbing: binding and validating the provider's options, configuring a named HttpClient with a Polly standard-resilience handler, constructing the provider singleton, and exposing it as both IDatedRateProvider and IRateProvider. The provider-specific extension method supplies only the values that differ across providers: the HttpClient name, configuration section, validation predicate, user-agent and timeout selectors, and the factory delegate that invokes the concrete constructor.

    The two public overloads differ by options-type constraint. Use the short overload when TOptions derives from WebRateProviderOptions — it reads UserAgent, HttpTimeout, and TryValidate(out string?) automatically. Use the full overload when the options type does not inherit from WebRateProviderOptions and the caller must supply explicit selectors.
