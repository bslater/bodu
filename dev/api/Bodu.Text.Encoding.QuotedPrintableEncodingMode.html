Fields

Binary = 0

Treats every source byte as arbitrary data. No byte sequence is interpreted as a hard line break; in particular CR (0x0D) and LF (0x0A) are escaped as =0D and =0A. This is the safest mode for round-tripping arbitrary binary payloads.

Text = 1

Recognises a canonical CRLF (0x0D 0x0A) pair in the source as a hard line break, emitted using the configured newline. A lone CR or lone LF is not a canonical break and is escaped as =0D or =0A.
