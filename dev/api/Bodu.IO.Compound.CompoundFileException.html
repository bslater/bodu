Remarks

Catch this type to handle any compound-file failure uniformly. The concrete subclasses narrow the cause: CompoundFileFormatException reports structural failures encountered while reading, CompoundFileSerializationException reports authoring and write-time failures, and CompoundStreamNotFoundException reports a missing named stream or storage.
