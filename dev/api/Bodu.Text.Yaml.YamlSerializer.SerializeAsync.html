    Method SerializeAsync

    SerializeAsync<T>(Stream, T, YamlSerializerOptions?, CancellationToken)

    Asynchronously serializes a value as UTF-8 YAML to the supplied stream.

    Declaration
    [RequiresUnreferencedCode("Reflection-based YAML serialization may require types that trimming cannot statically determine.")]
public static ValueTask SerializeAsync<T>(Stream destination, T value, YamlSerializerOptions? options = null, CancellationToken cancellationToken = default)
    Parameters
    Type Name Description
    Stream destination

    The stream that receives the UTF-8 YAML bytes.
    T value

    The value to serialize.
    YamlSerializerOptions options

    The serializer options, or null for the defaults.
    CancellationToken cancellationToken

    A token that can be used to cancel the write.
    Returns
    Type Description
    ValueTask

    A task that completes when the value has been written.
    Type Parameters
    Name Description
    T

    The type of the value.
    Remarks

    The value is serialized into an in-memory buffer in full and then written to the stream in a single asynchronous operation: the method buffers the complete output rather than streaming it, so peak memory includes the entire rendered document. Cancellation applies to the final write, not to the serialization that precedes it.

    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when destination is null.
    ArgumentException

    Thrown when destination does not support writing.
