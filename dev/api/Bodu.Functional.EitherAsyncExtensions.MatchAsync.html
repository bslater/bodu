    Method MatchAsync

    MatchAsync<TLeft, TRight, TResult>(Task<Either<TLeft, TRight>>, Func<TLeft, TResult>, Func<TRight, TResult>)

    Asynchronously collapses the awaited either to a single value by invoking the branch for the active side.

    Declaration
    public static Task<TResult> MatchAsync<TLeft, TRight, TResult>(this Task<Either<TLeft, TRight>> source, Func<TLeft, TResult> onLeft, Func<TRight, TResult> onRight)
    Parameters
    Type Name Description
    Task<Either<TLeft, TRight>> source

    The task producing the either to collapse. Must not be null.
    Func<TLeft, TResult> onLeft

    The projection invoked with the left value when the left side is active.
    Func<TRight, TResult> onRight

    The projection invoked with the right value when the right side is active.
    Returns
    Type Description
    Task<TResult>

    A task that completes with the value produced by the invoked branch.
    Type Parameters
    Name Description
    TLeft

    The type of the value carried on the left side.
    TRight

    The type of the value carried on the right side.
    TResult

    The type produced by both branches.
    Remarks

    Exactly one branch is invoked. Argument validation runs synchronously, so a null argument faults at the call site rather than on the returned task.

    Exceptions
    Type Condition
    ArgumentNullException

    source, onLeft, or onRight is null.
    InvalidOperationException

    The awaited either is default(Either<TLeft, TRight>) and carries neither side.
