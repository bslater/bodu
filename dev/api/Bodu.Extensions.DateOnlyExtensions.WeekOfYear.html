    Method WeekOfYear

    WeekOfYear(DateOnly)

    Returns the 1-based week number of the year that contains the specified DateOnly, using the CalendarWeekRule and DayOfWeek settings of CurrentCulture.

    Declaration
    public static int WeekOfYear(this DateOnly date)
    Parameters
    Type Name Description
    DateOnly date

    The date value to evaluate.
    Returns
    Type Description
    int

    An integer in the range 1 – 53 representing the week of the year that contains date.
    Remarks

    Week numbering is determined by CurrentCulture, which may follow different conventions:

    • U.S. system: week 1 starts on Sunday and includes January 1.
    • ISO 8601: week 1 starts on Monday and includes the first Thursday of the year.

    WeekOfYear(DateOnly, CultureInfo?)

    Returns the 1-based week number of the year that contains the specified DateOnly, using the calendar rules of the supplied or current culture.

    Declaration

    Parameters
    Type Name Description
    DateOnly date

    The date value to evaluate.
    CultureInfo culture

    An optional CultureInfo that supplies the CalendarWeekRule and DayOfWeek settings. If null, CurrentCulture is used.
    Returns
    Type Description
    int

    An integer in the range 1 – 53 representing the week of the year that contains date.
    Remarks

    This overload allows culture-specific calculation of week numbers (e.g. for Gregorian or ISO 8601 calendars).

    WeekOfYear(DateOnly, CalendarWeekRule, DayOfWeek)

    Returns the 1-based week number of the year that contains the specified DateOnly, using the supplied CalendarWeekRule and DayOfWeek as the week-starting day.

    Declaration
    public static int WeekOfYear(this DateOnly date, CalendarWeekRule weekRule, DayOfWeek weekStart)
    Parameters
    Type Name Description
    DateOnly date

    The date value to evaluate.
    CalendarWeekRule weekRule

    The CalendarWeekRule that defines how the first week of the year is identified.
    DayOfWeek weekStart

    The DayOfWeek on which each week begins.
    Returns
    Type Description
    int

    An integer in the range 1 – 53 representing the week of the year that contains date.
    Remarks

    This overload enables custom calendar logic such as ISO 8601 (FirstFourDayWeek, Monday) or localized U.S./European systems.

    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown if weekRule is not a defined value of the CalendarWeekRule enumeration, -or- weekStart is not a defined value of the DayOfWeek enumeration.
