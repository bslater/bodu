    Remarks

    Under Throw the parser raises ConfigurationParseException on the first recoverable error, so a returned ConfigurationParseResult from ParseWithDiagnostics(string, ConfigurationParseOptions?) always represents a successful parse whose diagnostic list is empty. Under Collect the parser runs to completion and the diagnostic list reflects every recoverable error and warning encountered.
