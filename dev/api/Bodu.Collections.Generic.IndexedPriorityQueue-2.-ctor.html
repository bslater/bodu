    Parameters
    Type Name Description
    IEnumerable<KeyValuePair<TElement, TPriority>> items

    The element-priority pairs used to populate the queue. Element keys must be unique. Must not be null.
    IComparer<TPriority> priorityComparer

    The comparer used to order priorities, or null to use Default.

    The comparer used to test element equality, or null to use Default.
    Remarks

    When items implements ICollection<T> the backing array is allocated up-front to its Count and the heap is built bottom-up in O(n); otherwise the array grows on demand as items are appended.
