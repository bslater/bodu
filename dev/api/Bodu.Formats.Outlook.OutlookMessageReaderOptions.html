    Remarks

    The defaults mirror the underlying CompoundFileOptions: the container is buffered whole and validated at Compatible, under which a malformed property is omitted rather than failing the open. Strict makes structural problems throw OutlookMsgFormatException instead.

    Properties

    Name Description
    DecompressRtf

    Gets a value indicating whether the compressed RTF body is decompressed when read through the body conveniences.
    MaxDecompressedRtfBytes

    Gets the largest decompressed RTF body, in bytes, the reader produces.
    MaxEmbeddedMessageDepth

    Gets the deepest embedded-message nesting the reader opens: the root message is depth zero, a message opened from one of its attachments is depth one, and so on.
    MaxInlineAttachmentBytes

    Gets the largest by-value attachment payload, in bytes, that is decoded into the attachment's Properties; a larger PidTagAttachDataBinary stream is left in the container and served only through OpenContentStream().
    ReadStrategy

    Gets the strategy used to source the container's bytes.
    ValidationLevel

    Gets how strictly the container and the message structures are validated.
