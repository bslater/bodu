Parameters

amount Money

The amount to convert.

provider IDatedRateProvider

The dated provider that resolves the exchange rate.

targetIsoCode string

The destination-currency ISO code.

date DateOnly

The valuation date.

options RateLookupOptions

The lookup rules to apply.

rounding MidpointRounding

The rounding mode applied at the destination precision. Defaults to ToEven.
