Remarks

Implementations are typically emitted at compile time by the Bodu.Text.Formats.Generators source generator for types annotated with DelimitedRecordAttribute, but the interface can equally be implemented by hand when full control over the field mapping is required. Because no member of this contract inspects types at runtime, the factory-based serializer paths are safe for trimming and ahead-of-time compilation.
