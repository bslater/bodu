    Struct IntervalPair<T>

    Represents the result of a binary interval set operation as zero, one, or two disjoint intervals in ascending order — the maximum number of pieces that subtracting or symmetric-differencing two intervals can produce.

    Remarks

    Difference(Interval<T>) and SymmetricDifference(Interval<T>) return this type. Because removing one interval from another leaves at most a left and a right remainder, the result never needs more than two pieces, so this allocation-free value type stores them inline rather than in a heap collection. When fewer than two pieces are present the surplus slots are the empty interval and are not enumerated.

    The pieces are ordered lowest-first and are guaranteed disjoint and non-adjacent. Enumerate with a foreach loop, index them via this[int] (0-based, bounded by Count), or read First and Second directly.

    Examples
    IntervalPair<int> diff = Interval<int>.Closed(0, 10).Difference(Interval<int>.Closed(3, 5));
diff.Count;          // 2
foreach (var piece in diff)
    Console.WriteLine(piece);   // "[0, 3)" then "(5, 10]"
