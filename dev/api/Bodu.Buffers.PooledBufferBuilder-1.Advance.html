    Method Advance

    Advance(int)

    Notifies the builder that count elements were written into the span or memory most recently returned by GetSpan(int) or GetMemory(int).

    Declaration
    public void Advance(int count)
    Parameters
    Type Name Description
    int count

    The number of elements written. Must be non-negative and must not exceed the length of the buffer most recently returned by GetSpan(int) or GetMemory(int).
    Implements
    IBufferWriter<T>.Advance(int)
    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown when count is negative or would advance WrittenCount past the end of the current internal buffer.
    ObjectDisposedException

    Thrown if the instance has been disposed.
