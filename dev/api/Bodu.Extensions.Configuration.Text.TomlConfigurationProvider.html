A read-only IConfigurationProvider that consumes TOML through the Bodu.Text.Toml read-only document model and flattens it into the colon-delimited configuration key model. Because the provider exposes no mutation surface, Set(string, string?) is rejected.

Remarks

The provider implements IConfigurationProvider directly rather than deriving from ConfigurationProvider: omitting the mutable base keeps the configuration bridge on the read-only half of the contract, so configuration loaded from TOML cannot be mutated back through the provider. 

// Built by TomlConfigurationSource; flattens TOML tables into
// colon-separated configuration keys.
IConfiguration configuration = new ConfigurationBuilder()
    .AddTomlFile("appsettings.toml")
    .Build();

var level = configuration["logging:level"];
