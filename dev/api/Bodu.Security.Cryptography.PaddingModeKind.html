    Enum PaddingModeKind

    Specifies a padding scheme for block-cipher operations. Mirrors the standard framework PaddingMode values and extends that surface with additional padding schemes that are not part of the framework enum.

    Namespace: Bodu.Security.Cryptography
    Assembly: Bodu.Security.Cryptography.dll
    Syntax
    public enum PaddingModeKind
    Remarks

    Values 0 through 4 are deliberately aligned with PaddingMode so that the mirrored values can be converted between PaddingModeKind and PaddingMode by cast. The ISO7816_4 value is a Bodu extension and has no framework counterpart.

    Bodu-specific values start at 1 << 10 to avoid colliding with framework-defined values.

    Pass a PaddingModeKind to PaddingFactory to obtain the matching IPaddingStrategy implementation.

    When to use this enum vs the framework PaddingMode. Use PaddingMode for code that must directly interoperate with Padding. Use PaddingModeKind when code should support the framework padding schemes plus Bodu-specific extensions such as ISO7816_4.

    Fields

    Name Description
    None

    Specifies that no padding is applied. The input must already be an exact multiple of the block size. Mirrors None.
    PKCS7

    Specifies PKCS#7 padding. Each padding byte contains the number of padding bytes added. Mirrors PKCS7.
    Zeros

    Specifies zero padding. Zero-value bytes are appended until the input aligns with the block size. Mirrors Zeros.
    ANSIX923

    Specifies ANSI X.923 padding. Padding bytes are zero except for the final byte, which contains the number of padding bytes added. Mirrors ANSIX923.
    ISO10126

    Specifies ISO 10126 padding. Padding bytes before the final byte are random, and the final byte contains the number of padding bytes added. Mirrors ISO10126.
    ISO7816_4

    Specifies ISO/IEC 7816-4 padding, also known as one-and-zeros or bit padding. The first padding byte is 0x80, followed by zero or more 0x00 bytes. This mode extends PaddingMode and has no framework counterpart.
