    Declaration

    Parameters
    Type Name Description
    ReadOnlySpan<byte> source

    The bytes to encode.
    IBufferWriter<char> writer

    The buffer writer that receives the encoded characters.
    Base85Variant variant

    The Base85 variant.
    BaseFormattingOptions options

    Formatting options. See Encode(ReadOnlySpan<byte>, Base85Variant, BaseFormattingOptions).
    Returns
    Type Description
    int

    The number of characters written.
    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when writer is null.
