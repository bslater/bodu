    Method ThrowIfSpanLengthIsInsufficient

    ThrowIfSpanLengthIsInsufficient<T>(Span<T>, int, string?)

    Throws an exception if the specified span has fewer than minimumLength elements.

    Declaration
    public static void ThrowIfSpanLengthIsInsufficient<T>(Span<T> span, int minimumLength, string? paramName = null)
    Parameters
    Type Name Description
    Span<T> span

    The span to validate.
    int minimumLength

    The minimum number of elements that span must contain.
    string paramName

    The name of the span parameter. Supplied automatically by the compiler via CallerArgumentExpressionAttribute.
    Type Parameters
    Name Description
    T

    The element type of the span.
    Remarks

    Span<T> is a value type and cannot be null; no null guard is required or possible. Use this overload when the caller may supply a larger span than required and the excess elements are simply ignored — for example, a buffer that must hold at least a full cipher block but may be larger. When the length must be exact, use ThrowIfSpanLengthIsNotEqualTo<T>(Span<T>, int, string?) instead.

    Exceptions
    Type Condition
    ArgumentException

    Thrown when span.Length is less than minimumLength.
