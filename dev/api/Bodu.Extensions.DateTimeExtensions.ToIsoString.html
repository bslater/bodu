    Method ToIsoString

    ToIsoString(DateTime)

    Returns a string representation of the specified dateTime in ISO 8601 format, using its Kind to determine the appropriate format suffix.

    Declaration
    public static string ToIsoString(this DateTime dateTime)
    Parameters
    Type Name Description
    DateTime dateTime

    The date and time value to convert.
    Returns
    Type Description
    string

    A string representation of dateTime in ISO 8601 format:

    • ends with 'Z' if Kind is Utc;
    • includes the local time zone offset if Kind is Local;
    • omits any offset if Kind is Unspecified.
    Remarks

    Uses the "o" (round-trip) format for Local and Unspecified, and a custom UTC format ("yyyy-MM-ddTHH:mm:ss.fffffffZ") for Utc.
