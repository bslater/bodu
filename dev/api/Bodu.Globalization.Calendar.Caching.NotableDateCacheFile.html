Remarks

The occurrences are stored flat rather than nested under each year — each occurrence row carries its own Year and Version — so the document is a shallow structure that both the TOML and JSON serializers round-trip without nested arrays of tables. A cached year that yielded no occurrences appears only in Entries with no matching occurrence rows.
