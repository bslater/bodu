    Method GetLastDateOfWeekInQuarter

    GetLastDateOfWeekInQuarter(int, int, DayOfWeek)

    Returns a new DateOnly representing the last occurrence of the specified DayOfWeek within the specified calendar quarter and year, using the standard calendar quarter definition.

    Declaration
    public static DateOnly GetLastDateOfWeekInQuarter(int year, int quarter, DayOfWeek dayOfWeek)
    Parameters
    Type Name Description
    int year

    The calendar year of the result. Must be between the Year property values of MinValue and MaxValue, inclusive.
    int quarter

    The quarter number, from 1 (Jan – Mar) through 4 (Oct – Dec).
    DayOfWeek dayOfWeek

    The DayOfWeek to locate within the quarter. For example, Monday returns the last Monday.
    Returns
    Type Description
    DateOnly

    A DateOnly value set to the last occurrence of dayOfWeek within the specified quarter and year.
    Remarks

    This overload uses the standard calendar alignment defined by JanuaryToDecember.

    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown if year is less than the Year of MinValue or greater than that of MaxValue, -or- quarter is less than 1 or greater than 4, -or- dayOfWeek is not a defined value of the DayOfWeek enumeration.

    GetLastDateOfWeekInQuarter(int, int, DayOfWeek, CalendarQuarterDefinition)

    Returns a new DateOnly representing the last occurrence of the specified DayOfWeek within the specified quarter and year, using the supplied calendar quarter definition.

    Declaration
    public static DateOnly GetLastDateOfWeekInQuarter(int year, int quarter, DayOfWeek dayOfWeek, CalendarQuarterDefinition definition)
    Parameters
    Type Name Description
    int year

    The calendar year of the result. Must be between the Year property values of MinValue and MaxValue, inclusive.
    int quarter

    The quarter number, from 1 through 4.
    DayOfWeek dayOfWeek

    The DayOfWeek to locate within the quarter. For example, Monday returns the last Monday.
    CalendarQuarterDefinition definition

    The CalendarQuarterDefinition that determines how quarter boundaries are aligned.
    Returns
    Type Description
    DateOnly

    A DateOnly value set to the last occurrence of dayOfWeek within the specified quarter and year.
    Remarks

    The end of the quarter is computed using definition, and the search proceeds backward to the last date that matches the specified dayOfWeek.

    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown if year is less than the Year of MinValue or greater than that of MaxValue, -or- quarter is less than 1 or greater than 4, -or- dayOfWeek is not a defined value of the DayOfWeek enumeration, -or- definition is not a defined value of the CalendarQuarterDefinition enumeration.
    InvalidOperationException

    Thrown if definition is Custom; use the provider-based overload instead.
