    Remarks

    By default a contributed key that collides with a built-in algorithm key or with a key already present in the target registry is rejected, so a plugin cannot silently take over an existing resolution path. Opting in to AllowOverride permits the replacement; each override is logged at warning level so the takeover is observable.
