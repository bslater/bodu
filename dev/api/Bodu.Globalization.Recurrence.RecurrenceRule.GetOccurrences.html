    GetOccurrences(DateTime)

    Enumerates the occurrences of the rule anchored at the specified start instant.

    Declaration
    public IEnumerable<DateTime> GetOccurrences(DateTime start)
    Parameters
    Type Name Description
    DateTime start

    The series start (DTSTART) the rule is anchored to.
    Returns
    Type Description
    IEnumerable<DateTime>

    The occurrences in ascending chronological order, each preserving the Kind of start. The sequence is bounded when the rule declares Count or Until, and otherwise continues to the end of the representable calendar; use Take<TSource>(IEnumerable<TSource>, int) or the windowed overload to bound it.
    Remarks

    Whether an instant is an occurrence depends only on the rule and start, never on any query window, so the windowed overload and this method agree on membership. The start instant is itself emitted only when it satisfies the rule.

    Exceptions
    Type Condition
    NotSupportedException

    Thrown when the rule uses a sub-daily frequency.

    GetOccurrences(DateTimeOffset)

    Enumerates the occurrences of the rule anchored at the specified start, preserving its UTC offset.

    Declaration
    public IEnumerable<DateTimeOffset> GetOccurrences(DateTimeOffset start)
    Parameters
    Type Name Description
    DateTimeOffset start

    The series start (DTSTART) the rule is anchored to.
    Returns
    Type Description
    IEnumerable<DateTimeOffset>

    The occurrences in ascending chronological order, each carrying the offset of start.
    Remarks

    Expansion is performed on the wall-clock time of start and the fixed offset is reattached to each result; daylight-saving transitions are not modeled (the rule carries no time zone).

    Exceptions
    Type Condition
    NotSupportedException

    Thrown when the rule uses a sub-daily frequency.
