Examples

var selected = new SecondSet(0, 30);
SecondSet parsed = SecondSet.Parse("0,30");

bool due = selected.Contains(DateTime.Now.Second);
bool same = selected == parsed; // true

Remarks

A SecondSet holds one bit per second, so it never allocates, and testing, adding or removing a second, or combining two sets with |, &, ^ and ~, is a single bitwise operation. Contains(int) answers false for any value outside 0 to 59 rather than throwing, which keeps a membership test against Second to a comparison and a bit test.

A leap second (60) is not a value: DateTime cannot represent one.

The text form lists the seconds in ascending order, separated by commas, each run of two or more consecutive seconds written as an inclusive range, so "0,30" selects on the minute and the half minute. The empty set is the empty string. Parse(string) reads any list of values and ranges in that form, in any order, and ToString() writes the canonical one. ToString(string?) also writes every second without ranges, or a binary form with one character per second, and Parse(string) and ParseExact(string, string) read them back. TryFormat(Span<char>, out int, ReadOnlySpan<char>, IFormatProvider?) writes the same text into a span of characters, its other overload into a span of UTF-8 bytes, and the span and UTF-8 overloads of Parse, TryParse, ParseExact and TryParseExact read it.

ToUInt64() and FromUInt64(ulong) expose the bits directly: bit n selects second n.

Remarks

A text of exactly 60 characters, each 0 or 1, is the binary form, second 0 first. Any other text is a comma-separated list of seconds and inclusive ranges: whitespace around the list and around each value is ignored, an empty or blank string is the empty set, values are unsigned decimal integers, a range a-b needs a no greater than b, and values may repeat or overlap.

The binary test comes first and reads the text as given, so text made only of 0 and 1 is a list only when it is not 60 characters long. ParseExact(string, string) with the "G" format reads any text as a list.

Exceptions

ArgumentNullException

Thrown when s is null.
