IAggregatedRateBuilder.cs

Builds the set of named, individually cached children an AggregatingRateProvider groups, together with its default strategy and per-currency-pair routing.

Remarks

Each child is registered as a keyed IDatedRateProvider (and resolvable by name through the service catalog) wrapped in its own CachingRateProvider, so a specific source can be obtained directly while the aggregator applies the configured strategy and routing.

services.AddFinancialService()
        .AddAggregatedRateProvider(agg => agg
            .AddCachedChild<RbaRateProvider>("RBA")
            .AddCachedChild<EcbRateProvider>("ECB")
            .UseDefaultStrategy(new PriorityFallbackStrategy())
            .MapPair(new CurrencyPair(CurrencyCode.AUD, CurrencyCode.USD), "RBA", "ECB")
            .MapPair(new CurrencyPair(CurrencyCode.EUR, CurrencyCode.USD), new AverageStrategy(), "ECB", "RBA"));
