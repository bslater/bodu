    Method DaysInMonth

    DaysInMonth(DateOnly)

    Returns the number of days in the calendar month of the specified DateOnly, using the proleptic Gregorian calendar.

    Declaration
    public static int DaysInMonth(this DateOnly date)
    Parameters
    Type Name Description
    DateOnly date

    The date value whose year and month are used to determine the result.
    Returns
    Type Description
    int

    The total number of days in the specified month and year of date, based on the GregorianCalendar.
    Remarks

    This overload always evaluates the result using the proleptic Gregorian calendar, regardless of the current culture or calendar settings. For culture-specific results, use the DaysInMonth(DateOnly, CultureInfo?) or DaysInMonth(DateOnly, Calendar?) overload.

    DaysInMonth(DateOnly, CultureInfo?)

    Returns the number of days in the calendar month of the specified DateOnly, using the calendar associated with the supplied culture.

    Declaration
    public static int DaysInMonth(this DateOnly date, CultureInfo? culture)
    Parameters
    Type Name Description
    DateOnly date

    The date value whose year and month are used to determine the result.
    CultureInfo culture

    An optional CultureInfo that supplies the calendar. If null, CurrentCulture is used.
    Returns
    Type Description
    int

    The total number of days in the specified month and year of date, based on the calendar of culture.
    Remarks

    This overload retrieves the Calendar from the culture's Calendar property and returns the number of days in the month of that calendar's own year/month reckoning that contains date.

    This is useful when working with cultures that use non-Gregorian calendars such as HebrewCalendar or HijriCalendar. If the calendar supports leap months or eras, this method does not account for them explicitly. For precise control, use the overload that accepts a Calendar directly.

    DaysInMonth(DateOnly, Calendar?)

    Returns the number of days in the calendar month of the specified DateOnly, using the supplied or current culture's calendar.

    Declaration
    public static int DaysInMonth(this DateOnly date, Calendar? calendar)
    Parameters
    Type Name Description
    DateOnly date

    The date value whose year and month are used to determine the result.
    Calendar calendar

    An optional Calendar instance used to evaluate the result. If null, the calendar of CurrentCulture is used.
    Returns
    Type Description
    int

    The total number of days in the specified month and year of date, based on the rules of the supplied or current calendar.
    Remarks

    This overload supports calendar-aware computations for systems such as HebrewCalendar, HijriCalendar, JapaneseCalendar, and others supported by .NET. date is first projected into the target calendar, so the result is equivalent to calendar.GetDaysInMonth(calendar.GetYear(dateTime), calendar.GetMonth(dateTime)) for the DateTime at midnight of date — the length of the calendar's own month containing the date, not the Gregorian month. The current culture's calendar is used if calendar is null.

    This method does not account for leap months. For calendars that support leap months or multiple eras, consider using GetDaysInMonth(year, month, era) instead.
