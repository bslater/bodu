Examples

using Bodu.Financial;

// A minimal static-table implementation of the rate source.
sealed class FixedTable : IRateProvider
{
    public decimal GetRate(string fromIsoCode, string toIsoCode) =>
        (fromIsoCode, toIsoCode) switch
        {
            ("USD", "EUR") => 0.92m,
            ("EUR", "USD") => 1.087m,
            _ => throw new KeyNotFoundException($"{fromIsoCode}->{toIsoCode}"),
        };
}

decimal rate = new FixedTable().GetRate("USD", "EUR");   // 0.92

Remarks

Implementations decide where rates come from: a static table, a daily snapshot, a live ticker, a mid-market computed from bid/ask, and so on. Consumers of ConvertTo<TTarget>(IRateProvider) only need the abstract GetRate(string, string) contract.
