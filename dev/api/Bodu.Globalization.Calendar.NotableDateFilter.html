    Class NotableDateFilter

    Represents a composable predicate over resolved NotableDate occurrences, used to restrict the results returned by INotableDateService to those matching a category, tag, name, duration, or observed-state criterion. This class cannot be inherited.

    Remarks

    Construction. A filter is created through the static factory methods on this class — for example ForCategory(NotableDateCategory), WithTag(string), IsNonWorkingDay(), and InDateRange(DateOnly, DateOnly). There is no public constructor; every factory returns an immutable instance.

    Composition. Filters combine through the instance operators And(NotableDateFilter), Or(NotableDateFilter), and Not(), and the variadic factories AllOf(params NotableDateFilter[]) and AnyOf(params NotableDateFilter[]). Because every instance is immutable, composition always produces a new filter and never mutates an operand, so a filter can be cached and reused across queries and threads.

    Evaluation. A filter is evaluated against each materialized occurrence after resolution: pass a filter to one of the Resolve overloads on INotableDateService (which keeps only the occurrences for which Matches(NotableDate) returns true), or call Matches(NotableDate) directly to test a single occurrence.

    Examples
    INotableDateService service = AmericasCalendarData.CreateService("US");
DateRange year = new(new DateOnly(2026, 1, 1), new DateOnly(2026, 12, 31));

// Non-working public holidays only.
NotableDateFilter publicHolidays = NotableDateFilter
    .ForCategory(NotableDateCategory.PublicHoliday)
    .And(NotableDateFilter.IsNonWorkingDay());

IReadOnlyList<NotableDate> holidays = service.Resolve(year, "US", publicHolidays);

// Religious or cultural dates tagged "Christian", excluding observed substitutes.
NotableDateFilter christian = NotableDateFilter
    .ForAnyCategory(NotableDateCategory.Religious, NotableDateCategory.Cultural)
    .And(NotableDateFilter.WithTag("Christian"))
    .And(NotableDateFilter.WasAdjusted().Not());

IReadOnlyList<NotableDate> observances = service.Resolve(year, "US", christian);
