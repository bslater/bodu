    Method TransformFinalBlock

    TransformFinalBlock(ICryptoTransform)

    Finalizes the transformation without processing any additional input data.

    Declaration
    public static byte[] TransformFinalBlock(this ICryptoTransform cryptoTransform)
    Parameters
    Type Name Description
    ICryptoTransform cryptoTransform

    The cryptographic transform to finalize. Must not be null.
    Returns
    Type Description
    byte[]

    A new byte array containing the final block output, which may be empty or contain padding bytes depending on the transform.
    Remarks

    Use this overload when the transform should be finalized without processing any remaining data.

    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when cryptoTransform is null.

    TransformFinalBlock(ICryptoTransform, ReadOnlySpan<byte>)

    Finalizes the transformation of the specified input span.

    Declaration
    public static byte[] TransformFinalBlock(this ICryptoTransform cryptoTransform, ReadOnlySpan<byte> input)
    Parameters
    Type Name Description
    ICryptoTransform cryptoTransform

    The cryptographic transform to finalize. Must not be null.
    ReadOnlySpan<byte> input

    The input span of bytes to transform.
    Returns
    Type Description
    byte[]

    A new byte array containing the final transformed output.
    Remarks

    This overload writes the input through a CryptoStream and finalizes the block. It avoids array copies for the input data while still producing a new byte array as output.

    Examples
    using var aes = Aes.Create();
byte[] result = aes.CreateEncryptor().TransformFinalBlock(data.AsSpan());
    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when cryptoTransform is null.
