    Method Bind

    Bind<TResult>(Func<T, Result<TResult>>)

    Projects the carried value into another result using the specified result-returning selector.

    Declaration
    public Result<TResult> Bind<TResult>(Func<T, Result<TResult>> selector)
    Parameters
    Type Name Description
    Func<T, Result<TResult>> selector

    The result-returning projection applied to the carried value.
    Returns
    Type Description
    Result<TResult>

    The result produced by the selector when this result represents success; otherwise a failure carrying the original error.
    Type Parameters
    Name Description
    TResult

    The value type of the resulting result.
    Remarks

    The selector is not invoked when this result is a failure.

    Exceptions
    Type Condition
    ArgumentNullException

    selector is null.
