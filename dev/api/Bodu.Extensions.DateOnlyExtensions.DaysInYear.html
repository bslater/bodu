    Method DaysInYear

    DaysInYear(DateOnly)

    Returns the number of days in the calendar year of the specified DateOnly, using the calendar of CurrentCulture.

    Declaration
    public static int DaysInYear(this DateOnly date)
    Parameters
    Type Name Description
    DateOnly date

    The date value whose year is used to determine the result.
    Returns
    Type Description
    int

    The total number of days in the year of date, as defined by the calendar of CurrentCulture.
    Remarks

    This overload uses the calendar defined by CurrentCulture. The result may vary depending on the calendar system (e.g. Gregorian, Hebrew, Hijri).

    DaysInYear(DateOnly, Calendar?)

    Returns the number of days in the calendar year of the specified DateOnly, using the supplied or current calendar.

    Declaration
    public static int DaysInYear(this DateOnly date, Calendar? calendar)
    Parameters
    Type Name Description
    DateOnly date

    The date value whose year is used to determine the result.
    Calendar calendar

    An optional Calendar used to evaluate the result. If null, the calendar of CurrentCulture is used.
    Returns
    Type Description
    int

    The number of days in the year of date, based on the supplied or fallback calendar.
    Remarks

    Use this overload when you want to explicitly calculate based on a specific calendar system (e.g. GregorianCalendar, HebrewCalendar). If calendar is null, the calendar of CurrentCulture is used.

    date is first projected into the target calendar, so the result is equivalent to calendar.GetDaysInYear(calendar.GetYear(dateTime)) for the DateTime at midnight of date — the length of the calendar's own year containing the date, not the Gregorian year.
