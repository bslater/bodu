Remarks

A Trie<TValue> stores keys as paths of characters, so operations cost time proportional to the length of the key rather than to the number of stored keys, and it answers prefix questions (StartsWith(string), KeysWithPrefix(string)) without scanning unrelated keys. Character transitions are keyed by the IEqualityComparer<T> supplied at construction, allowing ordinal or case-insensitive matching.

The empty string is a valid key. Enumeration order — whether through GetEnumerator(), KeysWithPrefix(string), or ItemsWithPrefix(string) — is unspecified in this version. The trie is not thread-safe for concurrent mutation.
