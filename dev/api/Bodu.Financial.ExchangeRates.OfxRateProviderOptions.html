Remarks

This type derives from WebRateProviderOptions, which supplies the endpoint base address, the HTTP contract, the synchronous-access and look-back behaviour, the currency-alias map, and the per-concern log levels. The members declared here are OFX-specific: the HistoryPath template into which the currency codes and the requested inclusive date range (as Unix-millisecond bounds) are substituted, the requested decimal precision, and the reporting interval sent as the ReportingInterval query parameter. The response is additionally range-filtered to the requested dates as a defensive measure.

Every member carries a working default, so the options bind cleanly through Microsoft.Extensions.Options and require no configuration for the common case. The dependency-injection package binds this type from configuration and a configure delegate.

Remarks

OFX publishes multi-decade spot-rate history ("20+ years") but no fixed inception date, so the advertised HistoryAvailability is deliberately Unbounded - there is no known floor worth pre-empting a request for. Set the property when a concrete floor matters for the pairs in use.

Gets or sets the safety margin subtracted from the current instant when capping a request's end bound, guarding against an endpoint clock that trails UTC.

public TimeSpan FutureClampSkew { get; set; }

Property Value

TimeSpan

The clamp safety margin; defaults to Zero.

Remarks

The OFX endpoint rejects a ToDate that lies in its future, so the provider never requests beyond the present. The end bound is capped at the current instant less this margin; the default of Zero keeps maximum recency, and a small positive value compensates for an endpoint clock observed to sit behind UTC.
