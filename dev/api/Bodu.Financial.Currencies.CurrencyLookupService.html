Default ICurrencyLookup backed by CurrencyRegistry. Reverse indexes for numeric code, symbol, and region are built lazily from a snapshot of the registry taken on first use.

Remarks

The reverse indexes reflect the registry contents at the time of first access. Construct a new instance after registering custom currencies that must participate in symbol, numeric, or region lookups.
