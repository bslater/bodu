    Remarks

    Range<T> is an immutable value type used as the element of RangeSet<T> and as a shared building block for the RangeDictionary<TKey, TValue> family. The constructor validates that the start endpoint is strictly less than the end endpoint and rejects degenerate or inverted ranges with ArgumentException.

    Half-open semantics — [start, end) — match the convention used by .NET span slicing, Range, and most database BETWEEN alternatives. They allow adjacent ranges ( [0, 5) followed by [5, 10)) to abut without overlapping, which is the property that keeps RangeSet<T> and RangeDictionary<TKey, TValue> internally consistent.

    Equality is structural: two Range<T> values are equal when both endpoints compare equal under the default endpoint comparer. Range<T> is suitable as a dictionary key when T is itself a well-behaved value type.
