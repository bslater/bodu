Represents a node's property context (PC): the LTP property bag of 16-bit property identifiers with wire-typed values, in the manner the exploration plan sketches - format-agnostic, with no MAPI semantics.

Remarks

The context's records are materialized when the context is read; each value's payload is resolved on access, so a large subnode-resident value costs its read only when it is actually retrieved. Enumeration yields values in property-identifier order (the tree's stored order).

Remarks

The stream is the streaming counterpart of TryGetValue(ushort, out PstPropertyValue): a heap-resident value is served from the heap's decoded bytes, and a subnode-resident value is read block by block on demand - the same stream OpenDataStream() returns - so MaxNodeDataLength, which bounds materialization, does not apply. The stream is bound to the owning session and must be disposed before it.

Inline and fixed-width values are exposed as their raw little-endian bytes for uniformity; the typed accessors on PstPropertyValue remain the natural way to read them.
