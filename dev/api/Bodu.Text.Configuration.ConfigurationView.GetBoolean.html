    Method GetBoolean

    GetBoolean(string)

    Gets the boolean value for key using EditorConfig conventions (true or false, case-insensitive).

    Declaration
    public bool GetBoolean(string key)
    Parameters
    Type Name Description
    string key

    The configuration key.
    Returns
    Type Description
    bool

    The parsed boolean value.
    Remarks

    Accepted: true, True, TRUE, false, False, FALSE and any other case variation. Surrounding whitespace is tolerated by the underlying TryParse(string, out bool).

    Rejected: yes, no, on, off, 1, 0. EditorConfig 0.17.2 uses only the true/false literals; broadening the set would conflict with the spec. Callers who want a relaxed parser should write their own using GetString(string).
