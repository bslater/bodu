    Method TapErrorAsync

    TapErrorAsync<T>(Task<Result<T>>, Action<ResultError>)

    Asynchronously invokes the specified action with the carried error when the awaited result represents failure.

    Declaration
    public static Task<Result<T>> TapErrorAsync<T>(this Task<Result<T>> source, Action<ResultError> onFailure)
    Parameters
    Type Name Description
    Task<Result<T>> source

    The task producing the result to observe. Must not be null.
    Action<ResultError> onFailure

    The side effect invoked with the carried error.
    Returns
    Type Description
    Task<Result<T>>

    A task that completes with the awaited result, unchanged, so calls can be chained.
    Type Parameters
    Name Description
    T

    The value type of the source result.
    Remarks

    The action is not invoked when the awaited result is a success; the result itself is always returned. Argument validation runs synchronously, so a null argument faults at the call site rather than on the returned task.

    Exceptions
    Type Condition
    ArgumentNullException

    source or onFailure is null.
