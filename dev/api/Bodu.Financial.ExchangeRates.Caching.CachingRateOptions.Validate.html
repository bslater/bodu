    Method Validate

    Validate()

    Validates the option values, throwing when a rule is violated.

    Declaration
    public void Validate()
    Remarks

    This throwing form preserves the ParamName of the offending option, which callers rely on. The dependency-injection registration instead wires TryValidate(out string?) into ValidateOnStart, which reports the same invariants without throwing.

    Exceptions
    Type Condition
    ArgumentException

    Thrown when DefaultExpiry or any ProviderExpiry entry is not strictly positive, when ProviderExpiry or DefaultLookupOptions is null, or when any Cache*LogLevel, HistoryClampLogLevel, or RateProvenanceLogLevel is not a defined LogLevel.
