    Method Clear

    Clear()

    Removes all entries present at the time of the call and resets the telemetry counters.

    Declaration
    public void Clear()
    Remarks

    The sweep runs under the maintenance lock: every entry currently in the backing dictionary is removed with a node-conditional remove, and the recency queues are drained of the resulting dead nodes. Entries added concurrently with the sweep may survive it — unlike Clear(), this cache has no global write lock to make the reset atomic against writers.

    A clear is a bulk reset, not an eviction — ItemEvicted is not raised for the removed entries. HitCount, MissCount, and EvictionCount are reset to zero.
