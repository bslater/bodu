Examples

NotableDateServiceOptions options = new()
{
    Algorithms = new NotableDateAlgorithmRegistry().Register("contoso.harvest-moon", new HarvestMoonAlgorithm()),
    Providers = new[] { myProvider },
};

NotableDateService service = new(resource, options);

Remarks

Every property is independently optional. Where a property is null the service uses its built-in behaviour for that concern. Construct an instance with an object initializer and pass it to NotableDateService(NotableDateResource, NotableDateServiceOptions?).
