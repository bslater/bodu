Remarks

The builder is mutable and single-threaded; each By… or With… method returns the same instance so calls chain. Call Build() to produce the immutable rule. A builder can be reused after Build() and each By… setter replaces any previously supplied values for that rule part.

WithCount(int) and WithUntil(DateTime) are mutually exclusive; supplying one clears the other, matching the RFC 5545 rule that COUNT and UNTIL cannot both appear.
