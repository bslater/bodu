Captures the lineage of a single served exchange rate: the provider name it is attributed to, whether it was resolved directly by a provider or served from a cache, the cache backend that served it, and — for a cache serve — the instant the served data was cached together with the derived age at the time of the lookup.

Remarks

Every RateLookupResult carries a populated RateProvenance. A rate resolved directly by a provider reports Live with a null Backend, CachedAtUtc, and Age; a rate served from a cache reports Cache with the serving backend, the instant the data was cached, and the age it had carried at the lookup instant.

Construct instances through Live(string), Live(string, string), and FromCache(string, string, DateTimeOffset?, DateTimeOffset) rather than the positional constructor so the origin-specific invariants — a live serve carries neither a cache instant nor an age — are applied consistently.

FromCache(string, string, DateTimeOffset?, DateTimeOffset)

Creates provenance for a rate served from a cache, deriving its age from the served instant and the lookup instant.

public static RateProvenance FromCache(string provider, string backend, DateTimeOffset? cachedAtUtc, DateTimeOffset asOf)

Parameters

provider string

The provider name the rate is attributed to.

backend string

The runtime identity of the cache backend that served the request.

cachedAtUtc DateTimeOffset?

The UTC instant the served data was cached, or null when no cached row backs the serve.

asOf DateTimeOffset

The lookup instant against which the age is derived.

Returns

RateProvenance

An RateProvenance with Origin set to Cache, carrying cachedAtUtc and the derived age, or no age when cachedAtUtc is null.

Remarks

The age is clamped to Zero so a never-negative value is reported: cache freshness tolerates a row stamped slightly ahead of asOf (a row may be written up to about a minute in the future of the lookup clock), which would otherwise make asOf - cachedAtUtc marginally negative.
