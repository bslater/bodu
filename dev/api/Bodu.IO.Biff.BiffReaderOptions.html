Remarks

Both options seed state the reader would otherwise establish from the stream itself. They exist for the case where the surrounding context already knows the answer - for example a sheet substream read after the workbook globals have fixed the version and code page - so the reader need not see a BOF or CODEPAGE record first.

int

The Windows code page number, or zero (the default) to assume DefaultCodePage until a CODEPAGE record is read.

Version

Gets the BIFF version the stream is known to be encoded in.

public BiffVersion Version { get; init; }

Property Value

BiffVersion

The version, or Unknown (the default) to let the reader establish it from the first BOF record. A BOF record that disagrees with a supplied version is rejected as malformed.
