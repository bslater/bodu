Remarks

Use the builder to capture a reusable display policy once instead of scattering format strings through the code base; the built MoneyFormatter is immutable and safe to share. 

using System.Globalization;
using Bodu.Financial;

MoneyFormatter formatter = new MoneyFormatterBuilder()
    .WithEnglishName()
    .WithCulture(new CultureInfo("en-US"))
    .Build();

var text = formatter.Format(Money.From(1234.56m, CurrencyCode.USD));   // "1,234.56 US Dollar"
