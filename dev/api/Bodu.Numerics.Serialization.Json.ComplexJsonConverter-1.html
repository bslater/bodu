Remarks

The converter shape is selected by NumericsJsonPolicy:

  • Strict — canonical object form { "real": 3, "imaginary": 4 }; rejects duplicate properties and non-object tokens. A finite component is written as a JSON number; a non-finite component is written as one of the JSON strings "NaN", "Infinity", or "-Infinity", since JSON numbers cannot represent those values. Either representation is accepted on read.
  • Lenient — same object shape as Strict, but a top-level JSON string token is accepted and routed through Parse(ReadOnlySpan<char>, IFormatProvider?) as a tolerant fallback.
  • Compact — string form "<3; 4>"; reads delegate to TryParse(ReadOnlySpan<char>, IFormatProvider?, out Complex<T>) and writes call ToString(string?, IFormatProvider?) with the invariant culture.
