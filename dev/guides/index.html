Guides

Recipe-style walk-throughs and conceptual introductions for every library in the Bodu suite, organized by the suite's seven topics. This page has one entry per package: its guide index lists every guide for that package, by namespace, and the links beside it are good first reads. Each topic also has a guides landing page that maps its packages' guides side by side.

If you are new to Bodu, start with the introduction for the project overview, or the getting-started page for install commands.

Hashing & Cryptography

Bodu.IO.Hashing

Non-cryptographic hashing: the FNV, CityHash, MurmurHash3, Pearson, and classic string fingerprints, the CRC engine with 112 named standards (CRC-3 through CRC-64), Fletcher and Adler, and the check-digit schemes.

Guide index Using CRC Check digits

Bodu.Security.Cryptography

Block, tweakable, and stream ciphers, cipher modes and padding, AEAD (the AES modes, ASCON, and the Poly1305 stream AEADs), digests and XOFs, MACs, Merkle trees, X25519, Ed25519, ML-KEM, ML-DSA, and HPKE, the KDFs (Argon2, scrypt, HKDF), one-time passwords, BCL interop, and hardware acceleration.

Guide index Choosing a primitive AEAD modes Security posture

Bodu.Globalization.Recurrence
