Core Foundations - Guides

Recipe-style walk-throughs for the Core Foundations topic - the Bodu.Core, Bodu.Collections, and Bodu.Collections.Concurrent packages, plus the Bodu.Text namespace that ships inside Bodu.Core. These are the building blocks the rest of the suite stands on: bounded collections, eviction-aware caches, pooled buffers, day-of-week and other calendar value sets, argument guards, and character-encoding helpers.

If you have not yet installed the packages, start with the topic overview for the package map and install commands, and the topic concepts page for the shared vocabulary.

Overview

The full guide index for the Core Foundations packages, organized by namespace - every collection, buffer, and root-namespace primitive, which guide covers each, and which package ships it.

Choosing a collection

The decision guide - a quick decision tree plus per-axis tables (access pattern, capacity and lifecycle, concurrency) that map requirements to the correct type.

Circular buffer

Fixed-capacity FIFO ring buffer - single-threaded CircularBuffer<T> (in Bodu.Collections) and thread-safe ConcurrentCircularBuffer<T> (in Bodu.Collections.Concurrent), overwrite mode, peek / dequeue / try-enqueue patterns.

Evicting dictionary

Capacity-bounded key-value store with FIFO, LRU, LFU, MRU, Random, and Second-Chance eviction policies - the drop-in cache primitive. Thread-safe ConcurrentEvictingDictionary<TKey,TValue> (in Bodu.Collections.Concurrent) adds lock-striped segments, TTL, and single-flight GetOrAdd.

Pooled buffer builder

PooledBufferBuilder<T> - ArrayPool-backed building of byte and character spans without allocation, with the ownership and lifetime rules.

DayOfWeekSet

Immutable set of days of the week - set operators, enumeration, working-week presets, and parsing and formatting as a seven-character mask (_MTWTF_).

Calendar value sets

Immutable sets of months, days of the month, hours, minutes, and seconds - set operators, enumeration, a list form (1-3,12), a list without ranges (L), binary (B), a mask of initials for months (J), and the ICalendarValueSet<TSelf, TValue> interface they share with DayOfWeekSet.

Bodu.Text

The Bodu.Text character-encoding helpers (BOM detection, span- and UTF-8-friendly transcoding, preamble handling, validation) have their own guide - Encoding helpers and BOM detection - which walks every surface pattern by pattern. Pair it with the Bodu.Text introduction for the scenario map and the Bodu.Text API reference for the type-by-type docs.
