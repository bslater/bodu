    Globalization & Calendars — Guides

    Recipe-style walk-throughs for the calendar package family — the Bodu.Globalization.Calendar runtime, its companions (Builder, DependencyInjection, Plugins, Caching, Tool, Build), the five regional data packs, and the independent Bodu.Globalization.Recurrence sibling. This page is the topic-level map; the complete guide lists live in the calendar guides index and the Recurrence guides index.

    If you are new to the family, start with the topic overview for the package decision table and the topic concepts for the shared vocabulary, then come back here for the hands-on material.
