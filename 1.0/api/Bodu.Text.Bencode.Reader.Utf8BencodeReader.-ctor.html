    Utf8BencodeReader(ReadOnlySpan<byte>, int)

    Initializes a new instance of the Utf8BencodeReader struct over the supplied bytes.

    Declaration
    public Utf8BencodeReader(ReadOnlySpan<byte> data, int maxDepth = 64)
    Parameters
    Type Name Description
    ReadOnlySpan<byte> data

    The Bencode source bytes.
    int maxDepth

    The maximum permitted container nesting depth.
    Remarks

    The value is clamped to Bodu.Text.Bencode.BencodeLimits.AbsoluteMaxDepth so that an unbounded configured value cannot drive the reader into a StackOverflowException on a deeply nested document.

    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown when maxDepth is not positive.

    public Utf8BencodeReader(ReadOnlySpan<byte> data, BencodeReaderOptions options)
    Parameters
    Type Name Description
    ReadOnlySpan<byte> data

    The Bencode source bytes.
    BencodeReaderOptions options

    The reader options controlling the maximum nesting depth and key leniency.
    Remarks

    A MaxDepth of zero or less selects the default maximum depth of 64, and a larger value is clamped to Bodu.Text.Bencode.BencodeLimits.AbsoluteMaxDepth; a document nested deeper than the effective limit throws BencodeFormatException.
