    Class RateRangeResult

    Represents the outcome of a range exchange-rate lookup: the observations that fall within the requested window, ordered by date, together with the metadata that describes the request and the span actually covered.

    Remarks

    The type implements IReadOnlyList<T> over its Rates, so it enumerates, indexes, and composes with LINQ exactly like a plain sequence (foreach (var rate in result), result[0], result.Where(...)) while still exposing the requested window through RequestedStartDate and RequestedEndDate, and the observed span through FirstObservedDate and LastObservedDate. Comparing the observed span to the requested window lets a caller see how much of the window carried data without re-deriving it from the elements.

    The range lookup does not apply a date-resolution policy and the per-observation provider and inversion flag are carried on each ExchangeRate, so no per-row resolution metadata is repeated here.
