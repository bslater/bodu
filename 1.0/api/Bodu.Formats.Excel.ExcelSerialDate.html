    Remarks

    Excel stores dates as floating-point serial numbers measured from the epoch 1899-12-30, deliberately preserving the historical 1900 leap-year bug so that values round-trip with Excel. The reader never infers that a numeric cell is a date; this helper is provided so a caller that knows a column holds dates can convert its values.
