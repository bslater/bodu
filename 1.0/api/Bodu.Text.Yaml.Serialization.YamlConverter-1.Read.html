    Method Read

    Read(ref Utf8YamlReader, Type, YamlSerializerOptions)

    Reads and converts a value of type T from the reader.

    Declaration
    public abstract T Read(ref Utf8YamlReader reader, Type typeToConvert, YamlSerializerOptions options)
    Parameters
    Type Name Description
    Utf8YamlReader reader

    The reader positioned on the first token of the value.
    Type typeToConvert

    The requested type.
    YamlSerializerOptions options

    The serializer options in effect.
    Returns
    Type Description
    T

    The converted value.
    Remarks

    On entry the reader is positioned on the value's first token. On return it must be positioned on the value's last token, so the caller can advance past the value with a single Read().
