    Class MLKem1024

    Provides the ML-KEM-1024 parameter set of NIST FIPS 203 (module rank 4, NIST security category 5, comparable to AES-256). This class cannot be inherited.

    Remarks

    Key and ciphertext sizes: encapsulation key 1568 bytes, decapsulation key 3168 bytes, ciphertext 1568 bytes, shared secret 32 bytes. See MLKem for the shared algorithm surface and security notes.
