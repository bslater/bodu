    Method ToString

    ToString()

    Returns the default string representation of this interval using ISO 31-11 bracket notation.

    Declaration
    public override string ToString()
    Returns
    Type Description
    string

    "[lower, upper]" for closed-closed intervals, "(lower, upper)" for open-open intervals, "[lower, upper)" for closed-open intervals, "(lower, upper]" for open-closed intervals, or "∅" (the empty-set glyph) for any empty interval.
    Overrides
    ValueType.ToString()
    Examples
    Interval<int>.Closed(1, 5).ToString();        // "[1, 5]"
Interval<int>.ClosedOpen(1, 5).ToString();    // "[1, 5)"
Interval<int>.Open(0, 1).ToString();          // "(0, 1)"
Interval<int>.Empty.ToString();               // "∅"

// The format specifier is applied to each endpoint.
Interval<double>.Closed(1, 5).ToString("F2"); // "[1.00, 5.00]"
