    Class NotableDateDefinitionBuilder

    Provides a fluent surface for authoring a notable-date concept: its identity, default category, duration and non-working flags, concept-level tags, and one or more calculation rules.

    Remarks

    A concept groups the rules that express the same notable date across territories or eras — for example a national rule and a regional variant that calculate the same holiday differently. Set concept-level defaults (category, duration, non-working) once, then add each variant with AddRule(string, Action<NotableDateRuleBuilder>); a rule may override the defaults it needs to. Configure the builder inside AddNotableDate(string, string, NotableDateCategory, Action<NotableDateDefinitionBuilder>) .

    Examples
    document.AddNotableDate("anzac-day", "Anzac Day", NotableDateCategory.PublicHoliday, c => c
    .AsNonWorkingByDefault()
    .AddTag("Remembrance")
    .AddRule("au", r => r.ForTerritory("AU").Fixed(4, 25))
    .AddRule("nz", r => r.ForTerritory("NZ").Fixed(4, 25)));
