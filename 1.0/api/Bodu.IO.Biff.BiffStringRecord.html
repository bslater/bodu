    Struct BiffStringRecord

    Represents a decoded STRING record: the cached text result of the FORMULA record that precedes it. The text is a 16-bit-length Unicode string in BIFF8 and a 16-bit-length code-page byte string in BIFF5.

    Remarks

    The record identifier is String. The payload is the string structure alone. The record has no position of its own: it belongs to the BiffFormulaRecord immediately before it, whose CachedResultKind is String.
