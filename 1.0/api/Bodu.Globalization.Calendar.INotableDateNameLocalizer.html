    Interface INotableDateNameLocalizer

    Supplies a culture-specific display name for a resolved notable-date occurrence, supplementing the invariant DisplayName carried by the concept.

    Namespace: Bodu.Globalization.Calendar
    Assembly: Bodu.Globalization.Calendar.dll
    Syntax
    public interface INotableDateNameLocalizer
    Remarks

    A localizer is applied on demand to resolved occurrences (for example through the Localize extension methods), so resolution itself stays culture-agnostic and a caller can request any culture.
