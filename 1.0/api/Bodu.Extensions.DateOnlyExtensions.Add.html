    Method Add

    Add(DateOnly, int, int, int)

    Returns a new DateOnly obtained by adding the specified number of years, months, and days to the supplied date.

    Declaration
    public static DateOnly Add(this DateOnly date, int years, int months, int days)
    Parameters
    Type Name Description
    DateOnly date

    The date value to which the offsets are applied.
    int years

    The number of calendar years to add. A negative value subtracts years.
    int months

    The number of calendar months to add. A negative value subtracts months.
    int days

    The number of days to add. A negative value subtracts days.
    Returns
    Type Description
    DateOnly

    A DateOnly value adjusted by the specified number of years, months, and days.
    Remarks

    Adjustments are applied in the order years, then months, then days. When the resulting day does not exist in the target month (e.g. February 30), the date is clamped to the last valid day of that month, accounting for leap years and varying month lengths.

    Examples: 

    var d1 = new DateOnly(2023, 1, 31);
var result1 = d1.Add(0, 1, 0); // → 2023-02-28 (non-leap year)

var d2 = new DateOnly(2020, 1, 31);
var result2 = d2.Add(0, 1, 0); // → 2020-02-29 (leap year)

var d3 = new DateOnly(2024, 2, 29);
var result3 = d3.Add(1, 0, 0); // → 2025-02-28 (2025 is not a leap year)
    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown if the resulting date is earlier than MinValue or later than MaxValue.
