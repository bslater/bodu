    Remarks

    Patterns support the EditorConfig glob grammar:

    • * — matches any character except /.
    • ** — matches any sequence of characters including /.
    • ? — matches a single character except /.
    • {a,b,c} — matches any of the comma-separated alternatives (nesting permitted).
    • {n1..n2} — matches any decimal integer in the inclusive range.
    • [seq] — matches a single character in the set; [!seq] matches any character not in the set.
    • \ — escapes the next character so it is matched literally.

    Anchoring follows EditorConfig: a pattern with no / matches at any directory depth; a pattern with / is anchored to the start of the relative path.

    Compilation parses the glob once into a culture-invariant Regex; subsequent IsMatch(string) calls are allocation-free over the compiled state. Cache compiled patterns when the same glob is matched repeatedly against many paths.

    Examples
    // Compile once, match many times.
ConfigurationPattern csFiles = ConfigurationPattern.Compile("**/*.cs");
Console.WriteLine(csFiles.IsMatch("src/Foo.cs"));     // true
Console.WriteLine(csFiles.IsMatch("docs/notes.md"));  // false

// Alternation + numeric range.
ConfigurationPattern markup = ConfigurationPattern.Compile("**/*.{md,mdx,txt}");
ConfigurationPattern logs   = ConfigurationPattern.Compile("logs/run-{1..99}.log");

    Compile(string, StringComparison)

    Compiles the supplied glob expression under the requested string comparison. Case-insensitive comparisons ( OrdinalIgnoreCase, InvariantCultureIgnoreCase, CurrentCultureIgnoreCase) compile the regex with IgnoreCase; case-sensitive comparisons do not.
    IsMatch(string)

    Determines whether the supplied relative path matches this pattern.
