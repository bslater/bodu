    Method Fibonacci

    Fibonacci(long, long)

    Yields Fibonacci numbers that fall within the half-open interval [min, max).

    Declaration
    public static IEnumerable<long> Fibonacci(long min, long max)
    Parameters
    Type Name Description
    long min

    The inclusive lower bound. Fibonacci numbers strictly less than this value are skipped. Must be non-negative.
    long max

    The exclusive upper bound. Iteration stops as soon as the next Fibonacci number is greater than or equal to this value. Must be non-negative and not less than min.
    Returns
    Type Description
    IEnumerable<long>

    A lazily evaluated, finite sequence of long Fibonacci numbers in ascending order.
    Remarks

    Use this generator when only the Fibonacci numbers within a known numeric window are required — building the full sequence up to MaxValue and filtering after the fact wastes iterations. The half-open interval matches the convention used elsewhere in SequenceGenerator, so two consecutive ranges can be stitched together without overlap or gaps.

    Lower bound is inclusive, upper bound is exclusive. If no Fibonacci number lies in the requested range the result is an empty sequence. If the next Fibonacci number would overflow long the iterator terminates cleanly rather than throwing. The traditional seed values 0 and 1 are emitted only when the window includes them.

    Iteration is deferred and deterministic; allocation is limited to the iterator state.

    Examples
    foreach (long f in SequenceGenerator.Fibonacci(10, 1000))
    Console.Write($"{f} "); // => 13 21 34 55 89 144 233 377 610 987

var none = SequenceGenerator.Fibonacci(50, 54).ToArray(); // => empty (no Fibonacci numbers between 50 and 54).
    Exceptions
    Type Condition
    ArgumentOutOfRangeException

    Thrown when min or max is negative.
    ArgumentException

    Thrown when min is greater than max.
