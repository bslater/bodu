    Method AddFinancialService

    AddFinancialService(IServiceCollection, IConfiguration?, string)

    Registers the core financial services — an ICurrencyLookup singleton and the bound FinancialOptions — and returns a builder for further composition.

    Declaration
    public static IFinancialServiceBuilder AddFinancialService(this IServiceCollection services, IConfiguration? configuration = null, string sectionName = "Financial")
    Parameters
    Type Name Description
    IServiceCollection services

    The service collection to register into.
    IConfiguration configuration

    Optional configuration root or section. When supplied, the section named sectionName is bound into FinancialOptions.
    string sectionName

    The configuration section name. Defaults to DefaultConfigurationSection.
    Returns
    Type Description
    IFinancialServiceBuilder

    An IFinancialServiceBuilder for further registration.
    Remarks

    No foreign-exchange provider is registered by default; supply one via AddExchangeRateProvider<TProvider>(IFinancialServiceBuilder) or its dated counterpart. JSON serialization is not registered here either — the financial JsonSerializerOptions registration (AddFinancialJson) ships in the companion Bodu.Financial.Serialization.Json package.

    Exceptions
    Type Condition
    ArgumentNullException

    services is null.
    ArgumentException

    sectionName is empty or white space.

    AddFinancialService(IServiceCollection, Action<IFinancialServiceBuilder>)

    Registers the core financial services and invokes configure for programmatic composition.

    Declaration
    public static IFinancialServiceBuilder AddFinancialService(this IServiceCollection services, Action<IFinancialServiceBuilder> configure)
    Parameters
    Type Name Description
    IServiceCollection services

    The service collection to register into.
    Action<IFinancialServiceBuilder> configure

    A callback invoked with the IFinancialServiceBuilder.
    Returns
    Type Description
    IFinancialServiceBuilder

    The same builder the callback received.
    Remarks
    IServiceCollection services = new ServiceCollection();

services.AddFinancialService(builder => builder
    .AddCurrencyLookup<MyCurrencyLookup>()
    .AddMonetaryContext("invoicing", new MonetaryContext(CurrencyCode.USD))
    .AddDatedExchangeRateProvider<MyRateProvider>());

// Promote the configured lookup to the ambient default after the provider is built.
services.BuildServiceProvider().UseCurrencyResolution();
    Exceptions
    Type Condition
    ArgumentNullException

    services or configure is null.
