    Enum TomlValueKind

    Identifies the concrete type of a TOML value. The members correspond to the value types defined by the TOML specification.

    Namespace: Bodu.Text.Toml
    Assembly: Bodu.Text.Toml.dll
    Syntax
    public enum TomlValueKind

    Fields

    Name Description
    String

    A Unicode string value, expressed in TOML as a basic, multi-line basic, literal, or multi-line literal string.
    Integer

    A 64-bit signed integer value.
    Float

    An IEEE 754 binary64 floating-point value, including the special values inf and nan.
    Boolean

    A Boolean value, expressed in TOML as the lowercase literal true or false.
    OffsetDateTime

    An RFC 3339 date-time that carries an explicit time offset from UTC.
    LocalDateTime

    A date-time without any offset or time-zone relation.
    LocalDate

    A calendar date without any time-of-day, offset, or time-zone relation.
    LocalTime

    A time of day without any date, offset, or time-zone relation.
    Array

    An ordered, heterogeneous array of TOML values.
    Table

    A table of key/value pairs, expressed in TOML as a header-defined table, an inline table, or an array-of-tables element.
