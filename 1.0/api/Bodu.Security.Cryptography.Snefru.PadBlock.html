    Method PadBlock

    PadBlock(ReadOnlySpan<byte>, ulong, Span<byte>)

    Pads the final input block for the Snefru hash algorithm by appending zeros and encoding the total message length.

    Declaration
    protected override int PadBlock(ReadOnlySpan<byte> block, ulong messageLength, Span<byte> destination)
    Parameters
    Type Name Description
    ReadOnlySpan<byte> block

    The final block of unprocessed input, typically containing fewer than BlockSize bytes.
    ulong messageLength

    The total number of bytes processed prior to this block (excluding the current partial block).
    Span<byte> destination

    The span receiving the padded block or blocks; at least two blocks long.
    Returns
    Type Description
    int

    A padded byte array of exactly 2 × BlockSize bytes, containing the input block followed by zeros and an 8-byte big-endian length field. The result is aligned for final compression and ready for use by ProcessBlock(ReadOnlySpan<byte>).
    Overrides
    BlockHashAlgorithm.PadBlock(ReadOnlySpan<byte>, ulong, Span<byte>)
    Remarks

    Snefru's final padding block is double the standard block size to support its dual-block internal buffer design. The method pads the input block with zeros and appends a 64-bit big-endian integer representing the total message length (in bits).
