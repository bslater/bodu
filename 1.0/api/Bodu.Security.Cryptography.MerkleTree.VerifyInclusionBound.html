    Method VerifyInclusionBound

    VerifyInclusionBound(ReadOnlySpan<byte>, long, long, long, ReadOnlySpan<byte>, IReadOnlyList<ReadOnlyMemory<byte>>)

    Verifies an inclusion proof against a length-bound root, so a tree size the publisher did not commit to is rejected even when the unbound walk would accept it.

    Declaration
    public bool VerifyInclusionBound(ReadOnlySpan<byte> boundRoot, long boundValue, long treeSize, long leafIndex, ReadOnlySpan<byte> entry, IReadOnlyList<ReadOnlyMemory<byte>> path)
    Parameters
    Type Name Description
    ReadOnlySpan<byte> boundRoot

    The published bound root.
    long boundValue

    The value the publisher bound — the entry count, or the input's byte length.
    long treeSize

    The number of entries the tree is claimed to hold.
    long leafIndex

    The zero-based index the entry is claimed to occupy.
    ReadOnlySpan<byte> entry

    The entry's bytes, which are hashed as a leaf.
    IReadOnlyList<ReadOnlyMemory<byte>> path

    The authentication path, leaf-upward.
    Returns
    Type Description
    bool

    true when the path carries entry to a head that binds to boundRoot under boundValue; otherwise false.
    Remarks

    This is the overload to use when the tree size comes from the party being examined. Because the bound value is hashed into the commitment, a claimed size that disagrees with the published one produces a different root and the check fails closed.

    Exceptions
    Type Condition
    ArgumentNullException

    path is null.
    NotSupportedException

    This instance's FanOut is not two.
