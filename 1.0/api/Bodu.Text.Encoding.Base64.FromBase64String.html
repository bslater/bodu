    Method FromBase64String

    FromBase64String(string)

    Decodes s as a Standard Base64 string into a byte array, mirroring the lenient whitespace behaviour of FromBase64String(string). ASCII whitespace anywhere in the input is silently ignored; the canonical-padding rule and alphabet are otherwise enforced strictly.

    Declaration
    public static byte[] FromBase64String(string s)
    Parameters
    Type Name Description
    string s

    The Base64 input.
    Returns
    Type Description
    byte[]

    The decoded byte array.
    Remarks

    To reject whitespace strictly, call Decode(string, Base64Variant, BaseFormatStyles) directly with None.

    Exceptions
    Type Condition
    ArgumentNullException

    Thrown when s is null.
    FormatException

    Thrown when the input is not valid Standard Base64.
