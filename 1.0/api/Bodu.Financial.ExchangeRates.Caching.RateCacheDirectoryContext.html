    Struct RateCacheDirectoryContext

    Supplies the inputs a directory resolver needs to choose the folder that holds a currency pair's cache file or files: the configured cache root, the bound provider, and the currency pair.

    Remarks

    Passed to the directory delegate of an RateCacheFileLayout so a consumer can shape the folder hierarchy — for example a flat folder, a per-provider folder, or a per-provider-then-per-pair tree.
