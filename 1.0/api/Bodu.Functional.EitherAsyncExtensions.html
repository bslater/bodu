Remarks

Each operation mirrors its synchronous counterpart - MapLeftAsync pairs with MapLeft<TResult>(Func<TLeft, TResult>), MapRightAsync with MapRight<TResult>(Func<TRight, TResult>), and MatchAsync with Match<TResult>(Func<TLeft, TResult>, Func<TRight, TResult>) - so an asynchronous pipeline over Task<Either<TLeft, TRight>> composes exactly like its synchronous equivalent.

Argument validation runs synchronously, so a null source task or delegate faults at the call site rather than on the returned task.

Every combinator preserves the uninitialized-instance contract of the underlying type: operating on default(Either<TLeft, TRight>) throws InvalidOperationException, matching the synchronous combinators.

The combinators accept no CancellationToken: they perform no I/O of their own, so cancellation belongs to the caller's delegates, which can close over their own tokens.

MapLeftAsync<TLeft, TRight, TResult>(Either<TLeft, TRight>, Func<TLeft, Task<TResult>>)

Asynchronously projects the left value using the specified asynchronous selector, passing a right value through untouched.

public static Task<Either<TResult, TRight>> MapLeftAsync<TLeft, TRight, TResult>(this Either<TLeft, TRight> source, Func<TLeft, Task<TResult>> selector)

Parameters

source Either<TLeft, TRight>

The either to project.

selector Func<TLeft, Task<TResult>>

The asynchronous projection applied to the left value when the left side is active.

Returns

Task<Either<TResult, TRight>>

A task that completes with Left(await selector(value)) when the left side is active; otherwise a right-carrying either with the original right value.

Type Parameters

TLeft

The type of the value carried on the left side.

TRight

The type of the value carried on the right side.

TResult

The left type produced by the selector.

Remarks

The selector is not invoked when the right side is active. The lift is strict: a null awaited projection result is rejected by the Left(TLeft) factory. Argument validation runs synchronously, so a null selector faults at the call site rather than on the returned task.

Exceptions

ArgumentNullException

selector is null, or the awaited projection produced null.

InvalidOperationException

The either is default(Either<TLeft, TRight>) and carries neither side.
