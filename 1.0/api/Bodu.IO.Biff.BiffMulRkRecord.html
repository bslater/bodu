Represents a decoded MULRK record: a run of adjacent RK-encoded number cells in one row, exposed by index without materializing an array.

Remarks

The record identifier is MulRk. The payload is the row and first column, six bytes per cell (a 16-bit extended-format index and a 32-bit RK value), and the declared last column; the layout is identical in BIFF5 and BIFF8. A payload whose cell area is not a whole number of cells is rejected as malformed.
