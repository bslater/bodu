    Method ToResult

    ToResult(ResultError)

    Converts the option to a result, using the specified error when no value is present.

    Declaration
    public Result<T> ToResult(ResultError error)
    Parameters
    Type Name Description
    ResultError error

    The error carried by the failure produced when this option is None.
    Returns
    Type Description
    Result<T>

    Success(value) when a value is present; otherwise Failure(error).
    Remarks

    This is the bridge from the absence-shaped Option<T> onto the failure-shaped Result<T> railway: the caller names the error that absence represents. The inverse direction is ToOption(), which discards the error.

    Examples
    var found = Option<string>.Some("value").ToResult("missing"); // Success(value)
var missing = Option<string>.None.ToResult("missing");        // Failure(missing)
