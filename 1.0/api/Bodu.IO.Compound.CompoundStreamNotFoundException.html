    Class CompoundStreamNotFoundException

    The exception thrown when a named stream is requested from a compound file but no matching directory entry exists.

    Remarks

    Thrown by OpenStream(string) and OpenStorage(string). Callers that prefer a non-throwing lookup should use TryOpenStream(string, out CompoundStream) or TryOpenStorage(string, out CompoundStorage) instead. It derives from CompoundFileException, the common base for all compound-file failures.

    Examples

    Catch the exception when a stream is expected to exist, or switch to the Try pattern when its absence is a normal outcome:

    try
{
    CompoundStream entry = file.RootStorage.OpenStream("Workbook");
}
catch (CompoundStreamNotFoundException ex)
{
    Console.WriteLine($"Missing stream: {ex.StreamName}");
}

// Non-throwing alternative:
if (file.RootStorage.TryOpenStream("Workbook", out CompoundStream? workbook))
{
    // ...
}
