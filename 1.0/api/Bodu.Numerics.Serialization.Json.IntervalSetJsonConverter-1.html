    Remarks

    An IntervalSet<T> serializes as a JSON array of its normalized Interval<T> pieces, each written through IntervalJsonConverter<T> under the same NumericsJsonPolicy. The empty set is the empty array []; a two-piece set under Compact is, for example, ["[1, 3]", "(5, 8]"]. On read the pieces are collected and re-normalized through From(IEnumerable<Interval<T>>), so overlapping or adjacent input coalesces.
