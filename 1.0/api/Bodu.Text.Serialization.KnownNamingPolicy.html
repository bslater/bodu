    Enum KnownNamingPolicy

    Identifies one of the built-in NamingPolicy singletons by name, so a type can select a naming policy declaratively through NamingPolicyAttribute.

    Namespace: Bodu.Text.Serialization
    Assembly: Bodu.Text.Serialization.dll
    Syntax
    public enum KnownNamingPolicy
    Remarks

    Each named value other than Unspecified corresponds to the like-named static property on NamingPolicy.

    Fields

    Name Description
    Unspecified

    No naming policy is selected; the member's CLR name or the options-level policy applies.
