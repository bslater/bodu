    Class NotableDateRule

    Represents one way of calculating a notable-date concept: an applicability scope, exactly one occurrence source (a single-date calculation strategy or a recurrence strategy), an optional duration, and the adjustment policies that transform its occurrences.

    Remarks

    A rule is identified within its notable-date concept by its Id. Optional Category, NonWorking, and Duration values override the inherited defaults of the parent concept; when null the parent value applies.

    A rule declares exactly one occurrence source: either a single-date Strategy that yields at most one occurrence per year, or a Recurrence strategy that yields many occurrences within a window. Exactly one of the two is non-null.
