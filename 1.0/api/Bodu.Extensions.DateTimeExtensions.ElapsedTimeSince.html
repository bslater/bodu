    Method ElapsedTimeSince

    ElapsedTimeSince(DateTime)

    Returns a TimeSpan representing the time that has elapsed between the specified dateTime and UtcNow.

    Declaration
    public static TimeSpan ElapsedTimeSince(this DateTime dateTime)
    Parameters
    Type Name Description
    DateTime dateTime

    The date and time value to compare against UtcNow. Must have a Kind of either Utc or Local.
    Returns
    Type Description
    TimeSpan

    The signed time interval between dateTime and the current UTC time; that is, UtcNow minus dateTime.
    Remarks

    If dateTime is in local time (Local), it is converted to UTC using ToUniversalTime() before comparison. Unspecified values are rejected to avoid ambiguity regarding the time zone context.

    Exceptions
    Type Condition
    ArgumentException

    Thrown if dateTime has a Kind of Unspecified.
