    Class ConfigurationParseOptions

    Controls how a configuration document is parsed: comment handling, duplicate handling, diagnostic routing, length limits, and the key mapping options.

    Remarks

    The options bag is a profile-grouped set of init-only properties. Start from a named preset that matches the hosting flavour — Bodu for the default Bodu Text Configuration semantics, EditorConfigCompatible for strict EditorConfig parity, Strict for fail-fast behaviour, or Relaxed for lenient parsing — and override the specific properties that need to differ. Use For(ConfigurationProfile) when the profile is data-driven (for example, read from configuration).

    DiagnosticMode is the most consequential knob. In Throw the reader raises ConfigurationParseException on the first recoverable error; in Collect the parser drives through the document and reports every recoverable issue via the parse result's Diagnostics list. Pair the latter with ParseWithDiagnostics(string, ConfigurationParseOptions?).

    Key shape is delegated to KeyOptions. Sharing one configured ConfigurationKeyOptions instance between parse and ConfigurationResolveOptions keeps the parsed model and the resolved view's lookups consistent. Instances are safe to cache and share across threads because every property is init-only. 

    // Strict structure, but collect every diagnostic instead of failing fast.
var options = new ConfigurationParseOptions
{
    Profile        = ConfigurationProfile.Strict,
    DiagnosticMode = ConfigurationDiagnosticMode.Collect,
};

ConfigurationParseResult result = ConfigurationDocument.ParseWithDiagnostics(text, options);
foreach (ConfigurationDiagnostic d in result.Diagnostics)
    Console.WriteLine(d);

    Properties

    Name Description
    AllowKeyOnlyProperties

    Gets a value indicating whether key-only properties (lines with no =) are permitted.
    Bodu

    Gets the canonical option set for the default Bodu profile: WhitespaceIntroduced inline comments, LastWins duplicates, Preserve sections, and throw-on-error diagnostics.
    DefaultEncoding

    Gets the encoding to assume when loading a configuration document from a byte stream without a byte order mark. The default is UTF8.
    DiagnosticMode

    Gets the diagnostic routing mode that controls whether recoverable errors throw, are collected on the document, or are silently ignored.
    DuplicateKeyMode

    Gets the duplicate key handling mode used by the reader.
    DuplicateSectionMode

    Gets the duplicate section handling mode used by the reader.
    EditorConfigCompatible

    Gets the canonical option set for the EditorConfig-compatible profile: inline comments disabled, duplicates last-wins, preserve duplicate sections, and throw-on-error diagnostics.
    InlineCommentMode

    Gets the inline comment handling mode used by the reader.
    KeyOptions

    Gets the key options used to split raw keys into segments and map them to the configuration key shape.
    MaxKeyLength

    Gets the maximum permitted length of an individual key, in characters.
    MaxLineLength

    Gets the maximum permitted length of an individual line, in characters.
    Profile

    Gets the behaviour profile this option bag represents. The default is Bodu.
    Relaxed

    Gets the canonical option set for permissive parsing of user-authored files: inline comments enabled, duplicates last-wins, preserve duplicate sections, and collect-on-error diagnostics.
    SectionHeaderMode

    Gets the section-header trailing-content handling mode used by the reader. The default, Lenient, accepts trailing words silently and matches the historical Bodu profile; the EditorConfig-compatible and strict presets use Strict instead.
    Strict

    Gets the canonical option set for strict, deterministic parsing intended for generated files: inline comments disabled, duplicate keys rejected, duplicate sections rejected, throw-on-error.
    TrimKeysAndValues

    Gets a value indicating whether keys and values should be trimmed of leading and trailing whitespace.
